# Sandsphere

로그인·사용자별 클라우드 저장과 Gitea → Cloudflare 운영 릴리즈 설정을 추가했습니다. 계정은 Firebase Authentication, 게임 저장은 개인별 Firestore 압축 저장본과 revision을 사용합니다. 운영 계정 연결 절차와 `sandsphere.app` 배포 흐름은 [운영 문서](docs/OPERATIONS.md), 검증 범위는 [계정 저장 검증](docs/ACCOUNT_VALIDATION.md)에 정리했습니다. 기존 비회원 게임은 별도 슬롯에 보존됩니다.

Babylon.js로 만든 구형 행성 물질 실험 프로토타입입니다. 행성의 주재료·태양과의 거리·초기 대기·중력을 정하고, 물질을 추가하며 변화를 관측합니다.

2026-10-10: 선택 범위를 펼쳐 기반암을 숨기는 단면과 기후·선구 식생 시스템을 구현했습니다. 기온·기압·기류·해류·습도·기단·수분·씨앗 지도를 구면과 단면에서 관찰할 수 있습니다. 유기토양을 먼저 붓지 않아도 씨앗과 환경이 맞는 모래·점토에서 식생이 정착합니다. [과학 근거와 모델 범위](docs/CLIMATE_ECOLOGY_DESIGN.md), [테스트와 실제 제품 검증](docs/CLIMATE_ECOLOGY_VALIDATION.md).

## 실행

Node.js 24에서 검증했습니다.

```sh
npm ci
npm run dev
```

<http://127.0.0.1:5173/>에서 실행합니다. 지원되는 브라우저에서는 WebGPU 렌더러와 WGSL 계산을 사용합니다. 지원되지 않으면 WebGL 렌더러와 CPU 계산으로 전환합니다. `?cpu=1`로 대체 경로를 확인할 수 있습니다.

```sh
npm test
npm run build
npm run preview
```

## 조작과 저장

상단의 차트 아이콘은 **행성 대시보드**를 엽니다. 전체·물질·열 상태·물 순환·대기·생태·수지 검증 화면에서 현재값, 관측 기준값, Δ, Δ%와 시계열을 조회합니다. 온도 분위수와 히스토그램, 모든 H₂O 상, 몰 분율, 생물 질량, 실제 적분된 에너지 채널을 사용합니다. 질량 수지는 낙하 중인 입자와 공급 대기량을 포함합니다. 행성 선택은 분석 대상만 바꾸며 카메라나 물리 상태를 바꾸지 않습니다. 차트는 전체 관측 / 최근 60·300초와 실제값 / 기준 대비 표시를 지원하고, 호버 또는 방향키로 시점을 조회합니다. 강수율은 직전 물리 단계의 실제값을 유지합니다. CSV는 선택한 행성의 수집된 기록을 내보냅니다.

대시보드 우측 상단의 불러오기 아이콘으로 선택한 행성의 이전 CSV 기록을 합칠 수 있습니다. 현재 관측 기준보다 이전에 끝나는 Sandsphere CSV를 사용하며 중복·겹치는 시점은 거부합니다. 합치기 전 자동 저장본은 복구용으로 보관합니다. 최초 CSV 기준부터 변화량을 표시하고, 에너지와 강수 누적량은 각 기록 구간의 증가분을 합산합니다. 기록 사이의 공백은 차트를 끊고 툴팁으로 표시하며 공백을 포함한 전체 에너지 수지는 계산하지 않습니다. CSV에 없는 과거 온도 히스토그램·대기 프로파일 유효성은 추정하지 않습니다. 공백 정보는 자동 저장과 CSV 내보내기에 함께 보존됩니다.

대시보드 기록과 기준값·누적 에너지·강수량은 행성 데이터와 함께 5초마다 이 브라우저의 IndexedDB에 자동 저장합니다. 새로고침·종료 직전에는 마지막 자동 저장 이후의 표본을 추가로 보관하고, 다시 열면 저장된 시계열에 이어서 수집합니다. 종료 직전 기록은 같은 자동 저장본에만 병합해 다른 시점의 물리 상태와 섞지 않습니다. 저장 기능 적용 전의 과거 추이는 새로 만들지 않으며 기본 간격은 시뮬레이션 1초입니다. 행성별 최대 2,048개 표본을 유지하고 초과 시 오래된 구간부터 압축합니다. 초기 기준은 압축과 무관하게 보존합니다. 기준 재설정은 선택한 행성의 현재 측정값으로 새 관측을 시작하며 물리 상태를 바꾸지 않습니다. 닫힌 패널의 차트는 갱신하지 않습니다. 표의 kg와 kJ는 게임 모델 단위이며 대기 프로파일의 유효 범위는 대기 화면 하단에 표시합니다.

기본은 **그랩** 모드입니다. 클릭하거나 드래그해도 물질이 부어지지 않습니다. 재료·작업 도구를 선택하면 활성화되고, 같은 항목을 다시 선택하거나 좌상단 **그랩**·Esc로 해제합니다.

좌측은 자원 선택·인벤토리·작업 도구, 우측 인스펙터는 관측 정보, 하단은 행성·시간·시점 조작을 맡습니다. 하단의 **행성 조정**을 펼치면 자전축(0~180°)과 자전 주기(20~1,200초)를 슬라이더 또는 숫자로 조절할 수 있습니다. 우주 배경은 상단 **설정**에서 변경합니다. **화면 회전 고정**은 표시 방향만 멈춥니다. 실제 자전과 햇빛·날씨 계산은 계속되며, 화면 회전을 재개할 때 위치가 튀지 않습니다. **실제 자전 속도**를 0으로 입력하면 물리 자전만 멈추고 공전은 계속됩니다. 새 행성은 자전 중인 상태로 시작합니다. 동기 자전은 자전 주기 슬라이더의 공전 주기 표시에서 선택합니다. 표시 근처로 드래그하면 정확한 공전 주기에 맞춰지고, 다른 주기로 옮기면 해제됩니다. 대기·구름·강수 레이어는 행성 화면 좌하단에서 항상 전환할 수 있고, 범례는 활성 레이어와 현재 상태에 맞춰 표시됩니다. **강수 지역** 레이어는 실제 강수가 발생한 지점을 비(파랑)·눈(보라)으로 강조합니다. 구름 표시와 독립적이며, 일시정지하면 마지막 계산의 분포가 유지됩니다. 두 종류가 같은 지점에서 발생하면 색을 혼합합니다. 강조의 불투명도는 초당 강수량이 많을수록 높아집니다. 고정된 강도 척도를 사용해 시간 배속이나 다른 지점의 강수량 때문에 색이 바뀌지 않으며, 일시정지 상태의 지형 편집에서도 최근 분포를 유지합니다.

모든 작업은 마우스만으로 할 수 있습니다. 회전·붓기 모드를 전환할 필요가 없습니다.

태양 방향은 원형 공전의 위상에 따라 변합니다. 궤도 거리는 생성할 때 정하며 이후 고정됩니다. 거리가 태양 에너지와 공전 주기를 결정하고, 공전 주기는 게임 시간으로 240 × 거리^1.5초입니다. 플레이 중에는 자전축과 자전 주기를 조절할 수 있습니다. 동기 자전은 한쪽 면이 계속 태양을 보게 합니다. 중력은 지구 표면 중력의 0.01~3배 범위입니다. 주요 물질은 구형 기반 위의 지형과 표면층을 구성하며, 행성 내부 전체의 조성을 계산하지 않습니다.

같은 브라우저의 IndexedDB에 약 5초마다 자동 저장합니다. 페이지를 닫을 때에는 마지막 상태를 로컬 저장소에도 남깁니다. 물질량·온도·구름 물방울·구름 얼음·발견·생성 조건·자전·재생 상태·탈출량이 이어지고, 떨어지는 입자의 질량도 저장에 포함됩니다. 레이어 설정은 별도로 기억합니다. 이전 16·20필드 저장은 셀별 물질량·온도를 보존하며 24필드로 확장합니다. 항성계 v1은 별도 백업 슬롯에 보존합니다. 새 구름 필드는 0에서 시작하고, 과거의 수동 기상 이벤트는 재개하지 않습니다. 새 행성 만들기는 현재 실험을 보존하고 최대 네 행성까지 추가합니다. 얼음·도자기·유리·식생·초식 생물·포식 생물·운철은 회수 도구로 공유 보관함에 넣고 전체 인벤토리에서 잔량만큼 다시 공급합니다. 항성계 전체와 공유 보관함을 함께 저장합니다. 기존 단일 행성 저장은 원본 슬롯을 보존한 채 새 항성계로 이어집니다.

작은 화면에서는 물질 옆 설정 버튼으로 도구를, 관측 옆 설정 버튼으로 환경을 엽니다. 터치는 한 손가락으로 붓고 두 손가락으로 회전·확대합니다. 브라우저 검증은 마우스로 수행했습니다.

행성 화면 좌상단의 편집 툴바에서 **그랩 · 핀 · 재료** 모드를 전환합니다. 핀 모드는 표면을 누를 때마다 관찰 지점을 옮기며, 그랩으로 돌아가도 고정한 지점을 계속 관측합니다. 재료 모드는 마지막으로 선택한 재료를 붓습니다.

핀을 꽂으면 마우스를 옮기거나 다른 곳에 물질을 부어도 인스펙터는 고정한 지점을 계속 관측합니다. 핀은 자전과 시점 회전을 따라가며, 행성 반대편이나 화면 밖에 있으면 가장자리에 방향과 위치 상태를 표시합니다. 가장자리 핀을 누르면 해당 지점이 보이도록 카메라가 가장 짧은 방향으로 부드럽게 회전합니다. 이 가장자리 핀에서도 호버 후 삭제할 수 있으며, ×는 시점 이동 없이 핀만 삭제합니다. 지도 핀에 마우스를 올리면 × 삭제 버튼이 나타나며, 그랩·핀·재료·작업 도구 모드 모두에서 사용할 수 있습니다. 터치 화면에서는 삭제 버튼이 항상 표시됩니다. 행성별 핀은 현재 세션 동안 유지됩니다.

하단 조작부에는 경과 시간을 표시하지 않습니다. 상단 중앙은 행성 전환과 이름 편집에 사용하며, 우측 종 버튼으로 **알림 센터**를 엽니다. 새 발견·탐사 완료·실험 피드백·계산 및 저장 오류를 최근 100개까지 이 브라우저에 보관합니다. 읽지 않음 필터·개별 읽음·모두 읽음을 지원하며, 발견 알림은 해당 기록으로 이동합니다. 기존 발견은 읽은 상태의 ‘이전 발견’으로 가져오며 발생 시각을 추측하지 않습니다. 새 소식은 알림 아이콘에서 잠시 강조합니다.

우측 **설정** 버튼은 인터페이스 테마·우주 배경·넓게 보기·새 알림 강조를 조정하는 모달을 엽니다. 변경은 즉시 적용되고 브라우저에 기억되며, 알림 강조를 꺼도 알림 센터에는 기록이 쌓입니다. 조작 방법도 설정에서 엽니다. 좁은 화면에서는 중앙 상태 줄을 접고 알림·설정 버튼을 유지합니다. 모달은 Esc·닫기 버튼·바깥 클릭으로 닫습니다.

반복되는 조작 안내는 패널 본문에서 제거하고 해당 항목의 툴팁으로 제공합니다. 제목 옆 정보 아이콘은 마우스 호버·키보드 초점·클릭·터치로 설명을 보여주며, 바깥 클릭이나 Esc로 닫을 수 있습니다. 현재 관측 상태와 입력 오류는 필요한 위치에 유지합니다.

슬라이더는 Garden 개발 소스의 Arc Slider(손잡이 안쪽으로 들어간 6px 트랙·20px 원형 손잡이·조작 중 값 표시)를 네이티브 range 입력에 맞게 적용합니다. 자전 주기의 동기 표시와 스냅 판정은 같은 손잡이 크기를 공유합니다. 값 직접 입력·행성 전환·온도 도구 전환도 트랙에 반영합니다. 스크롤바는 Garden ScrollArea의 둥근 얇은 손잡이를 따르며, 기본 휠·터치·키보드 스크롤을 사용합니다. 출처: 로컬 `garden-ui/packages/arc/src/registry/components/slider`, 설치된 Garden `packages/ui/src/components/ui/scroll-area.tsx`.

인스펙터의 **깊이별 분포**는 표면을 0으로 삼아 물층·고체 혼합층·고정 기반을 표시합니다. 가로 띠는 표면에서 기반으로 이어집니다. 구간 너비는 층 두께, 각 구간 안의 색 비율은 해당 층의 물질 질량 비율입니다. 토양에 머금은 물과 녹은 소금도 혼합층에 배분합니다. 고체층 내부는 균일하게 혼합된 현재 모델을 따르며, 미계산 지층을 추가하지 않습니다.

화면 회전을 고정해도 태양과 햇빛은 실제 자전·공전에 맞춰 움직입니다. 태양 방향이 화면 밖에 있을 때만 가장자리 아이콘을 표시하며, 글자는 표시하지 않습니다. 태양이 일부라도 화면에 들어오거나 행성에 가려져 있어도 카메라가 그 방향을 보고 있으면 안내 아이콘을 숨깁니다. 동기 자전에서는 같은 지점이 계속 태양을 향하므로 태양 방향도 고정될 수 있습니다.

키보드는 보조 입력입니다. 1–4 표면 물질 선택, G 가열, C 냉각, X 깎기, Esc 그랩, Space 재생, R 처음 시점, P 관찰 핀 지정을 지원합니다. 핀 지정 중 Esc로 취소하거나 행성에 초점을 두고 Enter로 화면 중앙의 지점을 고정할 수 있습니다. Shift + 드래그로 회전하며, 행성에 초점을 두면 방향키로 회전하고 Enter로 물질을 공급합니다.

## 시각적 반응과 구름

- 대기선은 한 개입니다. 기압이 기준의 0.01배로 낮아지는 높이를 표시하며, 기체가 없거나 그 기압에 못 미치면 선이 없습니다. 조성·기압에 따라 산란층과 연무의 색·불투명도도 달라집니다.
- 표면과 해안은 기하 경계로 표현합니다. 물은 표면 가까이 이어지는 가는 물줄기와 작은 물방울, 모래·소금·생성물은 작은 둥근 알갱이, 점토는 둥글고 불규칙한 덩어리로 떨어지고 쌓인 뒤에는 연속 표면에 합쳐집니다. 기체 공급과 탈출은 가는 흔적으로 표현합니다.
- 뜨거운 표면은 열빛과 작은 열 흔적, 차가운 표면은 냉각 색을 보입니다. 물이 수증기로 이동하는 곳에는 가는 증발 흔적이 올라옵니다.
- 구름은 수증기와 별도로 저장한 공중의 물방울·얼음입니다. 응결 뒤 이동하거나 다시 증발하고, 충분히 모이면 비·눈으로 내려옵니다. 구름이 태양 가열을 일부 줄입니다.
- 구름은 인접한 상층 영역을 묶은 부드러운 밀도 볼륨입니다. 큰 밀도 덩어리 안에서 빛을 적분하며, 고주파 노이즈 없이 실제 응결량으로 크기와 두께를 정합니다. 밀도 텍스처는 지표의 햇빛 차폐에 사용합니다. 비는 가는 낙하 선, 눈은 작은 흰 흔적으로 표시합니다.
- 대기와 구름은 각각 숨겨 표면을 볼 수 있습니다. 숨겨도 시뮬레이션은 계속됩니다. 비·눈의 시각 입자는 질량을 추가하지 않습니다.
- 소나기·한파·열풍을 수동으로 일으키거나 외부에서 물을 생성하는 이벤트는 없습니다. 물이 없는 행성에는 물 구름과 강수가 없습니다.
- 약한 중력에서 기체가 빠져나가거나 충분한 에너지의 입자가 탈출하면 물질 장부에 기록합니다. 새 물질·현상과 구름을 처음 관측하면 발견 알림이 뜹니다.

## 구현 한계

구름은 한 개의 대표 상층이고 열은 지표와 같은 기둥에서 공유합니다. 실제 대기 운동 방정식·압력장·대류·수직 습도 분포·해류의 열 수송은 계산하지 않습니다. 공전은 반지름에 따른 원형 궤도이며 중력 다체 적분은 아닙니다. 낙하 중 재증발은 셀의 건조도·온도를 이용한 즉시 물질 이동이며, 강수 경로 전체를 계산하지 않습니다.

메탄 구름·메탄 비·이산화탄소 응결·광화학 반응·온실효과·기압에 따른 끓는점 변화는 아직 없습니다. 메탄은 기체와 대기 외관에 반영되고 현재 구름은 물로만 구성됩니다. 광물의 세부 반응·결합수 방출·용해열·내부 동굴·체적 유체도 생략했습니다.

생태계는 유기 토양 → 식생 → 초식 생물 → 포식 생물의 생물량 모델입니다. 수분·빛·온도·염분·얼음이 성장에 영향을 주고 죽거나 동화되지 않은 양은 토양으로 돌아갑니다. 토양은 일부 수분을 보유합니다. 광합성의 CO₂·O₂ 수지, 개체별 생리와 행동, 유전·미생물은 계산하지 않습니다. 점토는 유기 토양과 별개입니다.

## 구현과 검증

TypeScript + Vite, Babylon.js, WGSL, IndexedDB를 사용합니다. 이음매 없는 구면의 2,562개 셀에서 질량·온도·이웃 이동을 계산합니다. GPU에서 명령 적용 → 유출량 → 유입·반응을 순서대로 실행합니다. 낙하 입자는 중심 중력으로 이동하고 착지할 때 질량을 추가합니다. 쌓인 표면 전체가 독립 입자로 계산되지는 않습니다.

렌더링은 문명 6의 입체 지도 표현을 참고한 스타일로 조정합니다. 내부에는 육각·오각형 쌍대 격자를 쓰지만 셀 윤곽이나 칸별 색을 표시하지 않습니다. 해안은 수면 높이를 보존하며 보간하고 젖은 경계에서 잘라 연결합니다. 바다는 연속적인 수심 색과 좁은 해안 띠로 표현합니다. 행성의 둥근 윤곽을 위해 지형 높이의 시각적 증폭은 제한합니다. 식생은 낮은 줄기와 옆으로 퍼진 수관의 나무 군락으로 표시합니다. 실제 물질량과 이동 계산은 바꾸지 않습니다.

60개 자동 테스트로 구면 연결, 물질 보존, 광물 반응, 기체 확산·조성·중력·탈출, 구름 형성·증발·이동·비·눈·잠열·가열 차폐, 대기 외관 근사, 생성·자전·태양 좌표, 자동 저장과 이전 형식의 호환성, 쌍대 격자의 닫힌 연결, 구름 청크·수관 메시·밀집 숲의 개수 제한을 확인합니다.

개발 모드의 `window.sandsphere.compareGpu()`는 동일 입력의 CPU·WebGPU 결과를 비교합니다. 구름을 포함한 입력에서 최대 셀 오차는 0.0000573 이내였으며 강수량과 탈출량도 비교했습니다. 개발 인터페이스는 배포 빌드에서 제외됩니다. `?test=1`은 행성과 발견 기록을 별도 슬롯에 저장해 사용자 행성을 보존합니다.

이전 검증은 `artifacts/atmosphere-verification.json`에 있습니다. 이번 구름·입자·레이어 검증은 `artifacts/clouds-verification.json`, 실제 구름 화면은 `artifacts/clouds-visible.png`와 `artifacts/clouds-hidden.png`에 기록합니다.

주요 파일: `src/sim/model.ts`·`physics.wgsl`은 계산, `atmosphere.ts`·`gases.ts`·`orbit.ts`·`clouds.ts`·`optics.ts`는 환경과 대기, `src/render/planet.ts`·`sky.ts`·`weather.ts`·`particles.ts`·`effects.ts`는 렌더링, `src/main.ts`는 조작과 저장을 담당합니다.

## 0.2 게임 구조와 표면 개선

- 이름·작은 색 표시·공급량으로 물질 목록을 단순화했습니다. 생성물은 발견과 실제 재고를 함께 확인합니다.
- 기본 암석 행성은 빈 기반암에서 시작합니다. 기존 저장의 지형은 그대로 유지합니다.
- 비활성 행성은 같은 CPU 규칙을 5Hz로 계산합니다. 멈춘 행성은 보존하고 앱을 닫은 동안의 생산은 임의로 만들지 않습니다.
- 표면 표시와 계산 격자를 분리했습니다. 이후 카툰 렌더링 개편에서도 계산 격자와 질량은 유지합니다.
- 입자는 실제 착지 셀에 합쳐집니다. GPU 결과를 읽는 중 장치가 끊겨도 명령을 두 번 적용하지 않도록 커밋 순서를 수정했습니다.
- 진행 중 계산, 대기 명령, 낙하 중 입자, 회수 재고를 저장·행성 전환 시 함께 정산합니다.

설계 판단은 `GAME_DESIGN.md`, 이번 검증은 `artifacts/system-verification.json`에 기록했습니다.


## 0.3 — 수면, 생태계, 항성계 탐색

- 빠른 선택에는 기본 재료와 발견한 재료만 표시하며, 미발견 재료로 개수를 채우지 않습니다. 전체 인벤토리도 미발견 재료를 숨깁니다. 발견한 재료는 보유량이 0이어도 표시합니다. 사이드바의 편집에서 재료를 제외하고 추가할 수 있으며, 목록은 브라우저에 기억됩니다. 전체 인벤토리는 검색·종류 필터·보유량·고정 기능을 제공합니다. 빠른 선택에 없는 재료를 고르면 사이드바 맨 위에 임시로 표시하고 선택 재료 이름을 보여줍니다. 선택을 바꾸면 임시 항목은 사라지며, 고정한 목록은 유지됩니다. 물질마다 삽화를 만들지 않습니다.
- 관측 패널에 지점별 주요 물질, 일조량, 식생 적합도와 원인, 행성 전체 물·얼음·생물량·온도 범위를 추가했습니다.
- 얼음은 수면의 상 변화로 표시되어 겹친 면의 깜빡임을 피합니다. 최신 개편에서는 강한 수면 반사와 칸별 깊이 색을 없애고 연속 해안과 얕은 물의 색 띠를 사용합니다.
- 항성계는 같은 3D 장면을 축소해 보고 선택한 행성으로 카메라를 이동합니다. 다른 행성의 표면은 간소화한 미리보기입니다. 궤도와 항성·행성의 크기는 조작을 위한 압축된 시각 척도입니다.
- 운석 도구는 열과 36kg의 운철을 더하고, 파낸 고체는 분화구 둘레에 재분배합니다. 충격파·파편·운동량의 정밀 적분은 하지 않습니다.
- 8개 탐사 과제는 자유 실험 위에 놓인 선택적 진행입니다. 최초 식생 8kg, 정원 보상 초식 생물 4kg, 먹이 연결 보상 포식 생물 1kg은 외부 표본입니다. 보상은 한 번만 지급됩니다. 해금된 종을 모두 소진했으면 전체 인벤토리에서 다시 보급받을 수 있습니다.
- 생물 표시는 셀의 실제 생물량에 연결됩니다. 작은 덩어리는 개체 수가 아닌 집단을 나타냅니다. 육상 생태계의 모든 화학 반응을 구현한 것은 아닙니다.

검증 기록: `artifacts/v03-verification.json`.

## 지도 스타일 렌더링 개편

- 큰 반사광·육각 타일 색·미세 얼룩을 없애고 연속적인 물과 해안으로 연결합니다. 지표는 실제 표면 높이와 사면 조명을 사용하며, 전체 행성이 일그러지지 않게 높이 증폭을 제한합니다.
- 식생은 42개 공간 영역의 생물량에 따라 최대 28개의 나무로 나누어 표현합니다. 갈라지는 가지·넓고 낮은 수관·나무 밑의 접촉 음영을 사용하고 구체 수관은 사용하지 않습니다. 실제 개체 수를 뜻하지 않습니다.
- 구름은 최대 세 인접 영역을 한 볼륨으로 묶습니다. 큰 밀도 덩어리를 24단계로 적분해 부드러운 경계와 내부 명암을 만들며, 미세 노이즈는 사용하지 않습니다.
- `tests/render-lab.html`은 저장 데이터를 사용하지 않는 모래·점토·식생·구름·해안·빙결·풍경 검수 장면입니다. `?cpu=1`은 WebGL 검수 경로입니다. 최신 화면은 `artifacts/strategy-*.jpg`에 있습니다.

모래–식생 경계는 색을 넓게 혼합하지 않습니다. 실제 생물량에서 얻은 공통 피복 필드의 등고선을 따라 구분하며, 낮은 빈도의 변화는 경계 모양에만 적용합니다. 식생이 없는 셀에는 풀을 생성하지 않고, 나무는 녹지 안쪽의 충분한 피복 영역에만 배치합니다. 최신 경계 검수 화면은 `artifacts/vegetation-boundary.jpg`입니다.

검수 화면에서 `면이 보이는 로우폴리 / 매끄러운 표면`과 `색 구분 / 약한 혼합 / 색 혼합`을 각각 전환할 수 있습니다. 같은 물질량·조명·카메라를 유지하는 비교용 설정입니다. 선택된 기본 스타일인 작은 육각 타일 + 색 혼합은 본 앱에도 적용합니다.

로우폴리 모드에서는 해안과 식생 경계를 실제 삼각형 면의 모서리에 맞춥니다. 물의 영역과 지표 재질은 면마다 판정하며, 색 혼합도 면 전체에 적용합니다. 매끄러운 모드에서는 연속 수심으로 자른 해안과 식생 피복의 곡선 경계를 사용합니다.

`작은 육각 타일` 비교 모드는 기존 시뮬레이션 셀의 쌍대 격자를 사용합니다. 2,550개 육각형과 12개 오각형이 구를 덮으며, 각 타일의 내부 삼각형은 재질·물 영역·법선을 공유합니다. 해안과 녹지 경계가 타일 가장자리를 따르고 시뮬레이션 해상도나 물질량은 바뀌지 않습니다.

육각 비교 모드에서는 물 표면과 그 아래 지형을 0.045 렌더 단위 낮추고, 고체와 맞닿은 변만 흙 단면으로 연결합니다. 단면의 간접광은 지표 일조량에 비례하며, 밤쪽에서는 주변 지면과 같은 환경광만 사용하고, 수면의 옅은 경계 띠 역시 해안 변에만 표시합니다. 실제 물질량과 물리 고도는 변경하지 않습니다.

타일 크기 비교는 기본 2,562개, 폭 약 ½의 10,242개, 폭 약 ¼의 40,962개를 제공합니다. 두 추가 단계는 표시용 구면 격자만 재귀 세분화하고 기존 시뮬레이션 필드를 보간합니다. 각 크기에서 12개 오각형을 유지하며, 물리 셀 수·저장 데이터·물질량은 변경하지 않습니다. 검수 화면은 크기 전환 시 카메라를 보존하고 이전 장면과 GPU 자원을 해제합니다.

구름 비교는 A 부드러운 입체 구름, B 넓고 낮은 층운, C 로우폴리 구름을 제공합니다. A/B는 24단계 볼륨 적분과 서로 다른 밀도 형태, C는 각 조각이 하나로 연결된 다각형 실루엣을 사용합니다. 같은 대기 영역의 구름량과 배치를 공유하고 전환 시 저장 상태를 변경하지 않습니다. 세 안 모두 태양 반대쪽에서 밝기가 줄어듭니다. 기본 타일 크기는 사용자가 선택한 2,562개입니다.

선택된 로우폴리 구름의 기본 표현은 넓고 낮은 형태(너비 1.45배, 접선 깊이 1.22배, 두께 0.52배)와 불투명도 0.84입니다. 검수 화면에서 기존 두께, 낮고 넓은 불투명 형태, 낮고 넓은 반투명 형태를 전환할 수 있습니다. 본 앱도 로우폴리 구름을 기본으로 사용합니다.

로우폴리 구름 무리는 안정적인 공간 식별자를 기준으로 단독, 큰 구름과 작은 조각, 느슨한 세 조각, 짧은 네 조각 무리를 섞습니다. 여섯 실루엣과 서로 다른 크기·방향·간격을 사용하며 작은 구름은 분할하지 않습니다. 조각의 면적 가중치 합은 1이고 구름량은 바꾸지 않으며, 배치는 업데이트마다 무작위로 바뀌지 않습니다.
