## 물의 과학 기준과 게임 보정

순수 물의 포화 증기압은 [IAPWS 포화 특성 보조식](https://www.iapws.org/relguide/Supp-sat.html)을 사용한다. 과냉각 액체와 얼음은 [Murphy & Koop의 검토](https://doi.org/10.1256/qj.04.94)에 따른다. 액체식 계수는 [ACP의 식 A2](https://acp.copernicus.org/articles/22/65/2022/acp-22-65-2022.html)와도 대조했다. 식의 반환 단위는 Pa, 온도 입력은 °C에서 Kelvin으로 변환한다. 구름 물방울의 과냉각 가능성은 [NOAA/NWS의 착빙 자료](https://www.weather.gov/source/zhu/ZHU_Training_Page/icing_stuff/icing/icing.htm)를 참고했으며 −12°C 자체는 실측 보편 문턱이라고 주장하지 않는다.

기체 질량 `m_g`, 중력 배율 `g`에 대해 `p = 101325 × g × m_g / 0.3` Pa로 둔다. 질소 0.3 게임 kg·중력 1×인 기준 기둥이 1atm이다. 기존 대기 표시도 같은 기준을 공유한다. 수증기 부분압은 `p_v = p × n_v / (n_v + n_dry)`이다. 이 식을 포화 증기압에 맞춰 수증기 질량을 푼다. 독립적인 실제 셀 부피를 만들어 압력식과 충돌시키지 않는다. 예전 20°C의 임의 0.5kg 포화량은 이 기준 질소 기둥에서 약 0.0045kg으로 달라진다. 이전 저장의 물질량을 변환하거나 삭제하지 않으며, 재생하면 새 규칙에 따라 구름·수증기·물 사이에서 이동한다.

NaCl의 희석 이상용액 활동도는 `a_w = 1 / (1 + 2 Mwater/Msalt × salt/water)`로 근사한다. 고농도에서의 비이상성, 온도별 용해도와 용해열은 계산하지 않는다. 기존 용해 한도 0.36kg/kg과 동결점 최저 −18°C도 게임 보정으로 유지한다. 포화 증기압과 비등 경계에는 같은 활동도를 쓴다.

비등 역산 범위는 0–180°C이다. 삼중점 압력 이하의 물은 준안정 액체로 취급하고 증발·승화로 소실시킨다. 높은 유효 압력은 180°C 경계로 제한해 표시한다. 포화식은 임계온도 이상에서 임계값으로 제한하며 초임계 유체 상태식이라고 주장하지 않는다. 반응열은 기존 선언된 `H = C T + Σmℓ` 기준으로 보존한다. 압력별 실제 잠열을 새로 맞췄다는 의미가 아니다.

Float32 동결 평형 근처에서 CPU/GPU가 반대 구름 상을 선택하지 않도록 핵생성에 0.001°C의 수치 여유를 둔다. 지표 승화는 실제 Float32 얼음 감소량을 수증기·열에 함께 반영하고, CPU 이웃 수송은 Float64 합산 후 셀에 한 번 기록해 작은 이동량의 누적 반올림을 줄인다.

## 재료와 단면 계약

유리는 1400°C 위에서 유한 속도로 연화하고, 용융 실리카의 이동률은 1400–1800°C 구간에서 증가한다. 유리/용융 실리카는 같은 비열과 기준 구조 에너지 150을 사용한다. 냉각 시 1400°C 아래에서 유리로 돌아간다. 이 구간·점성·구조 에너지는 제작과 관찰을 위한 근사이며 실제 유리 조성별 점도나 결정화 잠열이 아니다.

소금 801°C, 운철 1538°C, 암석 1200°C, 도자기 1600°C 근처 이상은 미지원 액상 영역으로 표시한다. 암석·세라믹의 문턱은 조성에 따라 달라지는 범위 안내값이다. 저온 메탄·CO₂와 고압·임계온도 아래의 CO₂에는 응축 모델의 범위 제한을 표시한다. 고압 CO₂ 안내는 응축 경계의 정확한 예측이 아니라 보수적인 제외 영역이다. 질소의 임계온도는 −146.96°C로 게임 최저 −100°C보다 낮으므로, −100°C의 질소가 응축한다고 잘못 안내하지 않는다. 기준은 [NIST 질소](https://webbook.nist.gov/cgi/cbook.cgi?ID=C7727379&Mask=6E), [NIST CO₂](https://www.nist.gov/pml/sensor-science/fluid-metrology/database-thermophysical-properties-gases-used-semiconductor-4)다.

구면과 단면은 같은 solver·scene·canvas·물질 상태를 사용한다. 단면은 표면 업로드와 같은 온도·혼합 재료·유동수 높이를 읽는다. 재가열한 실제 용융 재고가 단면 열색과 깊이별 혼합 비율에 들어가는지 검사했다. 회색 내부는 고정 기반이며 맨틀·핵이나 내부 온도장을 그리지 않는다. 기압·비등 기준·상층 진단값·상 모델 제한도 같은 관측 셀을 읽는다.

- `npm test`: **22개 파일, 134개 테스트 통과**. 새 P2 과학 검사는 18개이며 질량·엔탈피, 독립 포화 기준값, 압력별 비등, 염분, 과냉각/융해, 승화, 생태 적합도·이동, 전도, 연속 알베도, 재가열/흐름, 충돌과 단면 반영을 포함한다.
- `npm run build`: TypeScript·프로덕션 빌드 통과. 기존 대형 번들 경고는 남아 있다.
- 독립 수치 기준: 물 20°C 약 2339.19Pa, 물 100°C 약 101418Pa, 얼음 −20°C 약 103.25Pa. 비등 경계는 0.5/1/2atm에서 약 81.6445/99.974/120.625°C. [NIST 물 데이터](https://webbook.nist.gov/cgi/cbook.cgi?ID=C7732185&Mask=4)를 함께 확인했다.
- 시간 수렴: 2초 혼합 실험의 1/120초 기준 대비 1/30초 질량 분포 상대 L1 오차 **0.00012400**, 평균 온도 오차 **0.00069196°C**. 1/60초는 각각 **0.00004131**, **0.00022543°C**로 감소했다.
- 공간 수렴: 동일한 위도 방향 질소 분포를 1초 확산. 42/162/642/2562셀의 큰 규모 모드 감쇠율은 **0.00837418/0.00868139/0.00875867/0.00877514**. 가장 거친/촘촘한 경우 차이는 4.79%, 642→2562셀은 0.19%. 이 시험은 기체 확산의 규모 보정 근거이며 모든 유동·화학의 격자 불변성을 보증하지 않는다.
- 실제 브라우저 WebGPU: **17개 시나리오 모두 통과**, 각 30단계. 기존 8개 경계에 저/고압 물, 승화, 상층 융해, 재가열, 비균일 용융 수송, 고온 소비자, 구름 차폐 생태, 비균일 운철 전도를 추가했다. 최대 온도 차이 **0.00201416°C**, 셀 질량 상대차 **2.81e−6**, 전체 질량 상대차 **2.80e−7**, GPU 엔탈피 상대 잔차 **2.51e−6**. 허용차는 각각 0.003°C/1e−5/1e−6/1e−5. 정지 무명령의 변경 슬롯과 열 잔차는 정확히 0이다. 0.003°C는 30단계의 Float32 누적 오차를 허용하며, 처음 검출한 0.206°C의 상 선택 불일치는 이 허용차로 감추지 않고 핵생성 경계를 수정했다.
- 실제 `PlanetView` 재가열 장면: 얼음·구름·생태와 고온 유리를 함께 실행. 0.2667초에 용융 실리카 **191.52577kg**가 생성되어 단면에 반영됐다. 정지 후 구면↔단면 전환 중 **변경 슬롯 0**, 시간·질량·엔탈피 모두 정확히 일치. 구름과 8개 커스텀 셰이더의 단면 클리핑도 유지됐다.
- 프로덕션 미리보기의 단면에서도 1.000atm, 100.0°C 비등 기준, 상층 진단 온도와 근사 설명을 확인했다. 브라우저 오류·경고 로그는 없었다. 확인은 `?test=1`의 테스트 저장 영역과 저장에 접근하지 않는 전용 fixture에서 수행했다.
