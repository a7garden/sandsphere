# 목성형·토성형 대기 구현과 검증

2026-10-14, 개발 버전 `0.7.0-alpha.4`. 운영 배포는 하지 않았다.

이 문서는 H₂/He만 지원하던 초기 구현의 기록이다. 현재 구름·제트와
저장 버전 8의 범위는 [구름·제트 검증](GIANT_CLOUDS_VALIDATION.md)을 따른다.

## 입력과 확장 구조

`PlanetDefinition` 버전 1의 `gas-giant` / `deep-atmosphere` /
`hydrogen-helium` 조합을 `DeepAtmosphere`로 실행한다. 목성형과 토성형은
같은 수송·복사·저장 코드를 사용한다. `createDefinedPlanet`은 생성한
`state`와 `climate`를 함께 반환하며 호출자는 두 상태를 함께 복원해야 한다.
앱 생성·CPU·GPU·Worker·활성/배경 전환이 이 규칙을 따른다.

| 입력 | 목성형 | 토성형 |
|---|---:|---:|
| 1bar 평균 반지름 | 69,911km | 58,232km |
| 같은 기준의 평균 중력 | 25.92m/s² | 11.19m/s² |
| 공전 거리 | 5.203AU | 9.537AU |
| 공전 주기 | 4,332.59일 | 10,759.22일 |
| 초기 자전 주기 | 35,730초 | 38,362초 |
| 초기 기울기 | 3.13° | 26.73° |
| 지원 H₂/He 몰분율 | 89.8% / 10.2% | 96.7% / 3.3% |
| 기준 압력 / 초기 하단 압력 | 1bar / 30bar | 1bar / 30bar |
| 초기 연속 프로파일의 1bar 온도 | 165K | 134K |
| 초기 상층 온도 하한 | 110K | 82K |
| 지정한 내부 열 플럭스 | 5.4W/m² | 2.0W/m² |

기본 행성 수치는 [NASA 목성 수치표](https://nssdc.gsfc.nasa.gov/planetary/factsheet/jupiterfact.html)와
[NASA 토성 수치표](https://nssdc.gsfc.nasa.gov/planetary/factsheet/saturnfact.html)를
참조했다. 구면 모델이므로 적도 중력 대신 평균 1bar 반지름의 평균 중력을
사용한다. 토성 조성은 표의 H₂ 96.3%·He 3.25%를 지원 성분으로 정규화한
근사다. 미량 기체는 없다. 내부 열 5.4/2.0W/m², 하단 30bar, 상층 온도
하한과 초기 제트는 감도 실험 입력이며 관측 기후에 맞춘 교정 결과가 아니다.

현재 지원 범위는 H₂/He, 기준 압력 1kPa 이상, 하단 기준 압력의 2배 이상·
100bar 이하이다. 얼음 거대행성·암모니아·다른 복사 조합은 생성·실행·
저장에서 거부한다. 새로운 성분·응결 과정은 종별 질량·비열·복사와 저장
검증을 함께 확장해야 한다.

## 유한한 대기층과 경계

12층을 위에서 아래 순서로 저장한다. 초기 압력 면은 맨 위 0Pa, 다음
100Pa, 이후 30bar까지 로그 간격이다. 각 층의 초기 질량은 압력 차이와
중력에서 구한다. 성분 몰분율을 몰질량으로 환산해 H₂/He 질량을 나눈다.
온도는 고정 비열의 건조 단열 프로파일과 상층 온도 하한으로 초기화하며
위도별 ±2°C 변동을 더한다. 초기 동서 제트의 진폭은 목성형 100m/s,
토성형 180m/s의 실험 조건이다.

실행 중 압력은 실제 위쪽 누적 질량의 무게로 계산한다. 기준 높이는 초기
정역학 프로파일로 정한 뒤 고정한다. 질량 변화에 따라 격자면이 움직이는
압력 좌표나 비정역학 수직 운동 모델은 아니다. 가장 가까운 1bar 표본 층의
초기 중심은 약 1.255bar이다. 관측 패널은 이 층의 실제 압력과 온도를
표시하며 온도를 1bar 정의 값으로 계속 고정하지 않는다. 전체 열평균
온도는 따뜻한 심부 층까지 포함하므로 관측 층 온도와 구별한다.

상·하단 모두 질량은 통과하지 않는다. 수소·헬륨을 재공급하거나 탈출시키지
않으며 고체 지표·기반 열용량·심부 온도 저장소도 없다. 셀 사이에는 두
성분, 열과 접선 운동량을 같은 플럭스로 운반한다. 구면의 운동량은 평행
수송하고 층간에는 같은 질량의 교환과 불안정 혼합을 사용한다. 압력·열
구배, 코리올리 회전, 감쇠와 혼합에 따른 운동에너지 변화는 온도로 돌려
에너지 수지를 닫는다. CFL과 최대 물리 5초로 하위 적분한다. 범위 이탈은
기체나 열을 잘라내는 대신 오류와 체크포인트 롤백으로 처리한다.

## 복사와 에너지 장부

H₂ 고정 비열은 14.3, He는 5.193kJ/(모델 kg·K)이며 이상기체 근사다.
수소 충돌 유도 흡수는 다음 회색 광학 깊이로 근사한다. `x`는 H₂ 몰분율,
`p`는 Pa이다.

```text
τLW = 0.25 × x × (x + 0.5 × (1 − x)) × [(pbottom / 10⁵)² − (ptop / 10⁵)²]
τSW,abs = 0.006 × Δp / 10⁵
τSW,Rayleigh = 0.05 × x × Δp / 10⁵
```

이 계수는 스펙트럼 표나 관측값 교정이 아닌 압력·조성 의존 감도 근사다.
기존 두 방향 복사 전달을 사용하되 하단 장파는 `up = down + intrinsic`
으로 지정한다. 입사 장파를 다시 돌려보내면서 지정한 내부 순 열만 더하며,
고정 온도의 검은 지표를 두지 않는다. 하단까지 내려온 단파는 마지막
대기층에 흡수한다. 전체 대기 가열은 상단 순 복사와 내부 열의 합이다.

```text
H = Σlayer [(mH₂ CpH₂ + mHe CpHe) TC + m (g z + |v|² / 2) / 1000]
ΔH = QTOA + Qintrinsic + Qtool
ΔmH₂ = ΔmHe = 0
```

온도 기준은 기존 앱과 같은 0°C이며 에너지는 모델 kJ다. `COLUMN_KG`로
물리 기둥 질량과 모델 질량을 환산한다. 각 셀의 `energyChanges[0]`은 상단
순 복사, `[1]`은 내부 열과 도구 열이다. 탈출·수치 보정은 이 경로에서 0이다.
보존 시험은 Float64 층 정본을 합산하며 Float32 셀 합계의 반올림을 실제
질량 변화로 해석하지 않는다. 모델 단위의 수지이며 행성 전체 SI 질량이나
관측 에너지 수지를 인증하는 결과는 아니다.

가열·냉각은 관측 층에 직접 열을 넣고 빼며 정지 상태에서도 같은 장부를
사용한다. 지표 재료 공급·삭제·회수·운석·단면 도구는 제한한다. 심부 경계에
질량·엔탈피 교환을 추가할 경우 별도 외부 플럭스와 장부가 필요하다.

## 저장 호환

- 행성 스냅샷 버전 7, 셀 32필드. 0–26의 기존 필드는 그대로 두고 27은
  예약 0, 28은 H₂, 29는 He, 30/31은 예약 0이다. WGSL 구조도 32필드다.
- 가스형 기후 봉투는 버전 3, 심부 대기는 버전 1이다. 층별 성분 질량·
  온도·속도·기준 높이 및 반지름·중력·기준/초기 하단 압력·내부 열을 저장한다.
  체크포인트와 Worker는 모든 Float64 버퍼를 함께 복사·전송한다.
- 가스형 셀의 H₂/He 합계와 열평균 온도는 Float32 표시 거울이다. 층 정본과
  불일치, 고체/다른 기체 재고, 정의/대기 메타데이터 불일치, 손상 배열은
  저장에서 거부한다. 가스형에 고체 구성 `Snapshot.planet`을 넣지 않는다.
- 기존 1–6 버전과 16/20/24/28필드 입력을 읽고 새 필드를 0으로 확장한다.
  기존 물질·기후·먼지 누적·복사 캐시·시간·궤도 규칙과 원본을 보존한다.
  기존 암석형 저장을 가스형으로 바꾸거나 H₂/He를 자동 생성하지 않는다.
- 항성계 봉투 버전 3은 유지하며 암석형·화성형·가스형을 함께 저장한다.
  옛 대시보드/CSV의 미기록 H₂/He 지표는 미관측 값으로 읽는다.

공식 가스형 저장은 층 상태가 필수다. 내부 테스트의 합계 배열만 있는
초기화 경로는 합계 현열을 유지하면서 위치에너지를 열에서 보정하며 새
지표나 열 저장소를 만들지 않는다. 앱 생성은 이 경로가 아닌 완전한
프리셋 기후를 사용한다.

## 검증 결과

`tests/deep-atmosphere.test.ts`의 13개 검증은 두 프리셋 압력·몰분율,
미지원 경계 거부, 고체/열 저장소 없는 초기화, 하단 순 열과 상단 복사
수지, 광학 깊이의 압력 제곱·조성 반응, 성분별 수송과 운동에너지 전환,
정지 가열·저장 그림자 상태·롤백, 손상/합계 불일치 거부, 기존 28필드
화성 저장과 혼합 항성계 활성/배경 계산을 검사한다.

42셀에서 120 × 0.5게임초, 즉 물리 한 시간을 계산한 결과다. 잔차는
외부 열 장부를 뺀 값이며 비교 허용값은 질량 10⁻⁹kg, 에너지 10⁻⁵kJ다.

| 프리셋 | 질량 잔차 (모델 kg) | 에너지 잔차 (모델 kJ) |
|---|---:|---:|
| 목성형 | −5.12×10⁻¹³ | −3.49×10⁻¹⁰ |
| 토성형 | +9.66×10⁻¹³ | +9.30×10⁻¹⁰ |

JSON 저장 후 5단계의 전체 상태·층별 기후는 원래 실행과 정확히 일치한다.
기존 화성 버전 6 / 28필드를 버전 7로 확장했을 때 재고·먼지 누적·기후와
열 장부는 유지되고 새 H₂/He 필드는 0이다.

개발 서버 `/tests/deep-atmosphere-lab.html`에서 각 프리셋을 42셀·30단계로
실제 Worker CPU, WebGPU, Worker WebGPU와 비교했다. 6가지 모두 합계
상태 차이 0, 전체 기후 일치, 저장 재개 일치를 통과했다. 목성형 질량/
에너지 잔차는 −5.40×10⁻¹³kg / −5.65×10⁻¹⁰kJ, 토성형은
+1.02×10⁻¹²kg / −5.41×10⁻¹⁰kJ다. **가스형은 GPU 선택에서도 같은
호스트 또는 Worker의 대기 계산기를 사용한다. 독립 GPU 대기 방정식을
비교한 결과는 아니다.** GPU는 상태 전달과 기존 표시 경로를 유지한다.

기존 `/tests/mars-processes-lab.html`도 새 WGSL 셀 구조로 재실행했다.
Worker/CPU 일치, 실제 WebGPU 상태 차이 0, 저장 재개 차이 0, 질량 잔차
−1.04×10⁻⁹kg / 에너지 잔차 −0.04565kJ로 기존 Float32 검증을 통과했다.

실제 앱에서 기존 행성·화성을 보존한 채 목성형과 토성형을 추가하고 실행·
일시정지·새로고침 복원, 압력·조성·내부 열, 12층 표와 지표 도구 제한을
확인했다. 전체 테스트 424개 통과, 조건부 18개 건너뜀. 버전 검사와
TypeScript/Vite 빌드도 통과했다. 브라우저 결과와 화면은 로컬
`artifacts/giant-planets/`에 남긴다.

## 남은 범위

이번 검증은 계산 경로·저장 호환·모델 보존 수지 검증이다. 관측 제트와
기후의 정량 일치는 아직 검증하지 않았다. 분광 CIA, 온도 의존 비열,
메탄·NH₃·H₂O 구름, 헬륨 비, 금속수소·내부 구조, 편평도·자기장·고리,
동적인 압력 좌표와 자기중력은 포함하지 않는다. 물질 지도 색은 열평균
온도의 정성 표시이며 목성 띠나 토성 구름의 실측 영상이 아니다.
