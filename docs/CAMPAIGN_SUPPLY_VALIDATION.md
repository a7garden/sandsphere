# 캠페인과 재료 수급 점검

2026-10-12, 개발 버전 `0.7.0-alpha.1`의 캠페인 변경을 기록합니다. 캠페인의 완료 ID와 보관함 구조는 유지합니다. 기존에 완료한 과제는 취소하지 않고 보상을 재지급하지 않습니다.

## 캠페인 흐름

| 단계 | 과제와 완료 조건 | 진행 방법 |
| --- | --- | --- |
| 1 · 물질 실험 | 물의 여정: 같은 행성에 수증기 1kg + 구름 물·얼음 0.1kg | 물을 여러 셀에 공급하고 현재 기압의 비등 기준보다 높게 가열. 대기에서 응결하는 구름 관찰 |
| 1 · 물질 실험 | 흙을 굽다: 행성들과 보관함의 도자기 합계 1kg | 점토를 말리고 850°C 이상에서 행성 시간 30분 동안 가열 |
| 1 · 물질 실험 | 녹이고 식히다: 행성들과 보관함의 유리 합계 1kg | 모래를 1,700°C보다 높게 가열하고 용융 규사를 1,400°C 아래로 냉각 |
| 2 · 살아 있는 땅 | 첫 정원: 한 행성의 식생 9kg | 시작 식생 8kg, 빛·수분·온도·기질·성장 재료 관리. 초식 생물 4kg 지급 |
| 2 · 살아 있는 땅 | 먹이의 연결: 첫 정원 완료 + 한 행성의 초식 생물 4.2kg | 식생 옆의 촉촉한 육지에서 성장. 포식 생물 1kg 지급 |
| 2 · 살아 있는 땅 | 함께 사는 세계: 먹이의 연결 완료 + 한 행성의 식생 2kg·초식 1kg·포식 0.2kg | 포식 생물 소량 공급. 세 목표를 다른 행성의 값으로 합치지 않음 |
| 3 · 행성을 잇는 탐사 | 우주에서 온 금속: 캠페인 운석 충돌 + 보관함 운철 1kg | 충돌 지점에서 회수 |
| 3 · 행성을 잇는 탐사 | 행성을 잇다: 첫 행성 이외의 행성에 보관함 공급 | 회수 생성물이나 생물 표본을 공급. 기본 재료의 무제한 공급은 제외 |

물질 실험과 행성 탐사는 독립적으로 진행할 수 있습니다. 생물 보상을 받는 과정만 선행 과제가 있습니다. 화면에는 가장 먼저 남은 수행 가능 과제와 모든 과제의 실측 수치·방법이 표시됩니다. 공동 목표는 한 행성의 값을 표시합니다.

## 선택 가능한 15종과 공급 경로

| 재료 | 캠페인 공급 | 확보 방법 |
| --- | --- | --- |
| 모래 | 무제한 | 기본 공급, 유리 원료와 기질 |
| 물 | 무제한 | 기본 공급, 얼음·수증기·구름의 원료 |
| 점토 | 무제한 | 기본 공급, 도자기 원료와 기질 |
| 소금 | 무제한 | 기본 공급, 용해·증발 후 결정화 |
| 질소 | 무제한 | 대기 공급 |
| 메탄 | 무제한 | 대기 공급 |
| 이산화탄소 | 무제한 | 대기 공급, 식생 탄소원 |
| 유기물 | 무제한 | 기본 공급 또는 생물 잔해. 보수력과 성장 재료 |
| 얼음 | 보관함만큼 | 물을 얼려 회수하거나 얼음 행성에서 회수 |
| 도자기 | 보관함만큼 | 마른 점토 소성 후 회수 |
| 유리 | 보관함만큼 | 모래 용융·냉각 후 회수 |
| 운철 | 보관함만큼 | 운석 충돌당 36kg 공급 후 회수 |
| 식생 | 보관함만큼 | 시작 표본 8kg, 성장·회수·소진 재보급 |
| 초식 생물 | 보관함만큼 | 첫 정원 보상 4kg, 성장·회수·소진 재보급 |
| 포식 생물 | 보관함만큼 | 먹이의 연결 보상 1kg, 성장·회수·소진 재보급 |

수증기·구름 물·구름 얼음·용융 규사·용액 속 소금·휴면 씨앗은 시뮬레이션 상태이며 직접 선택하는 공급 재료가 아닙니다. 회수 도구는 위 표의 보관함 대상 7종만 모읍니다. 질소·메탄·CO₂는 회수할 수 없습니다. 샌드박스에서는 선택 가능한 15종 모두 무제한입니다.

재보급은 해금된 종의 **보관함 + 모든 행성의 해당 생물량**이 0.01kg 미만일 때만 허용합니다. 정확히 0.01kg일 때 Float32 변환으로 값이 조금 작아지는 오차를 허용합니다. 소량이 남은 보관함은 0.0kg으로 표시하지 않습니다.

## 검증 범위

- `tests/campaign.test.ts`: 목표 경계값·구름 얼음·행성 간 합계 방지·보상 선행/중복·기존 완료 기록·셋째 행성 운반·운철 회수·비활성 행성까지 포함한 재보급.
- CPU 시뮬레이터에서 실제 제작과 성장으로 목표 도달: 건조 점토 소성 후 도자기 회수, 모래 용융 후 유리 회수, 시작 식생 8kg → 식생 9kg, 보상 초식 4kg → 초식 4.2kg, 포식 생물 도입 후 먹이망.
- 층별 대기 사용/미사용 양쪽의 생태 성장 확인. 물 순환은 162셀·기본 질소 대기·셀당 물 5kg을 가열하는 통제된 층별 대기 실험에서 수증기와 구름의 공동 목표를 달성합니다. 모든 초기 조건이나 한 셀에만 붓는 플레이에서 같은 시간 안에 달성된다는 뜻은 아닙니다.
- `tests/campaign-ui.test.ts`와 `tests/i18n.test.ts`: 미발견 재료 포함 15종, 수급 조건 검색, 화면 갱신 중 포커스 유지, 샌드박스 무제한, 한국어·영어 제작/과제 안내, 소량 표시와 최종 완료 화면.
- 브라우저의 데스크톱·390px 모바일에서 재료 목록·과제 표시·수급 안내 스크롤 접근 확인. 실제 휴대폰에서 캠페인 전체를 조작해 완주하는 검증은 포함하지 않습니다.

행성 유형·저장 호환 작업이 같은 체크아웃에서 병행되므로 해당 변경의 검증은 별도로 기록합니다. 운영 배포나 릴리즈 발행은 이 작업에 포함하지 않습니다.

## 통합 버전 재확인

2026-10-13, 행성 정의·저장 호환 작업이 통합된 `0.7.0-alpha.2`에서 캠페인 관련 4개 파일의 36개 테스트를 다시 실행해 모두 통과했습니다. 새 행성 정의와 저장 버전을 포함한 상태에서도 캠페인 목표·보상·수급 판정 및 다국어 UI 검증을 유지합니다.

최종 통합 검증은 전체 테스트 **394개 통과, 조건부 테스트 18개 건너뜀**으로 완료됐습니다. 버전 일치 검사·TypeScript·Vite 빌드와 diff 공백 검사도 통과했습니다. 저장 업그레이드 회귀 시험의 버전 기대값을 새 Snapshot v5 계약에 맞췄으며, 물질·온도·진행 시간·자전 보존 검증은 유지했습니다.
