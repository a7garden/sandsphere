# P1 수정과 실시간 단면 구현 검증

2026-10-10. [셀 상태 감사](CELL_STATE_SCIENCE_AUDIT.md)의 P1 C01–C05를 수정하고, 기존 시뮬레이션 패널에 단면 카메라를 연결했다. 이 문서는 수정 후 구현·실행 근거이며, 기존 감사의 재현 JSON은 수정 전 기록으로 보존한다.

후속 P2 C06–C11의 구현과 현재 검증은 [P2 수정과 단면 검증](P2_IMPLEMENTATION_VALIDATION.md)에 있다. 아래 P1 실행 수치와 당시 후속 목록은 역사적 기록이다.

## 수정한 과학·게임 규칙

| 감사 항목 | 구현 결과 | 검증 |
|---|---|---|
| C01 시간·정지 | 활성/배경 행성, CPU/GPU, 공급 및 낙하가 1/30 게임초 공통 단계 사용. 큰 dt는 분할하고 명령은 첫 단계에 한 번 적용. dt=0은 명시적 편집만 적용. 과부하 시 미처리 시간을 보존. | 동일 시간의 배치/개별 단계 일치, 정지 무명령 상태 완전 일치, 15/30/144fps 공급·착지·셀 상태 일치 |
| C02 점토 소성 | `점토량 × 소성 시간`을 운반·충돌 재분배. 새 점토는 이력을 질량 비율로 희석. 850°C, 상대 수분, 평균 소성 30초의 게임 제작 조건 유지. | 신규 혼합, 이동, 충돌 이력 및 정지 경계 |
| C03 염수 평형 | 명시한 엔탈피를 보존하면서 얼음/물과 농축 후 동결점을 함께 풀고 과포화 용해염을 석출. 이미 녹은 염의 평형만 보정하고 결정염의 용해 속도는 유지. | −10°C 농축 염수, −1°C 강수 염수, 질량·열수지 |
| C04 물 순환 | 100°C에서도 증발률이 이어지고, 과열 현열 항을 추가. 강수 후 지표 평형을 계산한 뒤 실제 착지 상을 비/눈 진단에 반영. | 100°C 경계, 저온 담수·염수 강수, 처리 순서 |
| C05 에너지 기준 | 재료별 비열과 기준 상 에너지, 외부 환경/명령/탈출/수치 보정 4채널 기록. 소성의 비열 변경과 유리화 시 선언된 엔탈피 보존. 목표 가열은 대기 중인 명령과 도착 물질까지 고려. | 공급·삭제·회수·충돌·보호 클램프, 광물 변환, CPU/GPU 경계 시험 |

열 검증 기준은 `H = C T + Σ(m ℓ)`이다. C는 고정 기반 열용량 28과 재료 비열의 합이다. 단위는 게임 kg에 대응한 kJ 계열 에너지이며, 실제 행성 규모로 보정한 열역학 모델은 아니다. 기준 ℓ은 액체 물 0, 얼음/얼음구름 −334, 수증기 2475, 용융 규사/유리 150이다. 소성 반응열은 0인 게임 보정이다. 유리의 150은 구조 에너지 오프셋이며 결정의 응고 잠열이라는 주장을 하지 않는다. 엔탈피 장부에는 운동·위치 에너지를 포함하지 않는다. 비열은 모든 재료에 동일한 값을 쓰지 않는다.

정지 중 재료 클릭은 `공급률 × 1/30초`의 한 번 분량이다. 계속 누른 채 시간을 보내도 더 들어오지 않는다. 드래그는 일정 화면 간격의 편집 샘플을 추가한다. 가열/냉각은 목표 온도 편집을 적용하되, 상변화와 낙하는 다음 물리 단계까지 기다린다. UI도 ‘kg/번’, ‘다음 단계에서 반응’을 표시한다. 한 단계 버튼은 정확히 1/30초 진행한다.

## 단면의 구현 범위

같은 `PlanetView`, Babylon scene/canvas/camera, solver, 명령 큐와 물리 낙하 입자를 유지한다. 구면↔단면은 0.35초 연속 자세·투영 전환이며 중간에 역전할 수 있다. 모션 감소 설정에서는 즉시 전환한다. 단면의 이동·확대, 절단 방향·띠 폭, 시점 복귀와 관측 핀을 지원한다.

지형·물·얼음·물질 기둥, 모든 공급 재료, 생태, 대기·세 가지 구름 표현, 비·눈·강수 셀 레이어, 증기·기체·열·탈출·운석 효과를 기존 렌더에 연결했다. 볼륨 대기/구름은 직교 카메라의 실제 ray origin과 절단 띠 교차 구간으로 적분한다. 일반 재질·입자 시스템과 별도 셰이더 모두 같은 절단 평면을 적용한다. 붓기·가열·냉각·깎기·회수·기체 공급·운석은 공통 도구 경로를 사용한다. 빈 공간 공급 위치는 화면 위치를 물리 좌표로 역변환한다.

단면은 실제 렌더 삼각형의 교차로 생성한다. 렌더 보간 셀은 원래 계산 셀에 매핑하며 계산 격자를 늘리지 않는다. 회색 내부는 편집 불가능한 고정 기반이다. 셀 안의 혼합 물질을 보여주며 맨틀/핵, 지하 온도장, 물질 층 순서, 공동을 만들어 그리지 않는다. 물 높이에서 토양 보유수를 제외하며 얼음은 고체에만 포함한다.

물리 진행은 30Hz, 카메라·입자·효과는 렌더 프레임마다 진행한다. 표면 업로드는 현재 성능 정책인 최대 15Hz로 합친다. 단면 높이·재료색·온도는 그 표면 업로드에 사용한 동일 상태를 읽는다. 공급 입자의 물리 좌표와 화면 좌표는 분리하며 카메라 전환이 착지 시간을 바꾸지 않는다. 설계의 미래 `ObservationFrame/commitId` 및 유량 화살표 API 전체를 구현했다고 주장하지 않는다.

## 실행 검증

- `npm run build`: TypeScript와 프로덕션 빌드 통과. 기존 대형 번들 경고는 남아 있다.
- `npm test`: 18개 파일, 106개 테스트 통과. 물리·저장·GPU 장애 복구·렌더·단면·공통 시간·관측 등 포함.
- 시간 간격 수렴: 2초 혼합 물/구름/이동 실험을 1/120초 기준과 비교. 1/30초의 질량 분포 상대 L1 오차 0.00013326, 평균 온도 오차 0.01139°C. 1/60초는 각각 0.00004590, 0.00386°C로 감소. 이는 해당 실험의 수렴 근거이며 모든 조건의 정확도 보증은 아니다.
- 실제 브라우저 WebGPU 계산: 정지 무명령, 농축 염수, 100°C 증발, 점토 소성, 규사 용융, 유리 냉각, 저온 강수, 염수 강수 총 8개 경우 모두 통과. 각 경우 30단계, CPU/GPU 온도 허용차 0.002°C, 셀 질량 상대차 1e−5, 전역 질량 상대차 1e−6, 엔탈피 잔차 상대 1e−5. 정지는 상태와 에너지 잔차 모두 정확히 0. 최대 온도 차이 0.00048828125°C.
- 별도 혼합 세계의 실제 CPU/GPU 2초 대조 최대 슬롯 차이 0.00017357. 이 값은 서로 다른 단위 슬롯의 탐지용 최대값이며 온도/질량 검증을 대신하지 않는다.
- 실제 앱 테스트 저장 영역(`?test=1`): 카메라 왕복·급반전 중 정지 셀 해시/게임 시간 보존, 단일 단계, 붓기·착지·가열·냉각·깎기·고정 기반 편집 차단 확인. 정지 중 1초 눌러도 2.6667kg만 공급하고 시간 보존. 단면 운석은 정확히 한 번, 공급 +36kg, 게임 시간 보존, 외부 열 +64800 기록. 가열 도구 950.0°C와 다음 단계 안내 확인. 단면 회수로 행성 질량 −2.177275kg, 운철 재고 +2.177275kg, 게임 시간 불변 확인.
- 실제 렌더 시험 장면: 12개 공급 재료의 비행 상태를 유지한 채 구면/단면·각도·띠 폭·세 구름 표현 전환. 셀 해시, 시간, 입자 수·위치 불변 확인. 이 fixture는 실제 `PlanetView`를 사용하며 앱 저장에는 접근하지 않는다.
- 프로덕션 미리보기(`npm run preview -- --port 5195`, `/?test=1`)에서도 단면 가열 950°C, 정지 시간 보존, 관찰 핀 지정 및 구면↔단면 왕복 후 같은 관측 상태 유지 확인. 최종 제품 화면은 이 빌드에서 저장했다.
- 390px 화면 DOM 폭과 공통 조작 막대의 화면 내 배치 확인. 실제 터치 장치와 200% 확대의 최종 수동 검증은 수행하지 않았다.

## 남아 있는 과학적 단순화와 후속 과제

P2의 압력에 따른 상 경계, 생태의 온도 문턱, 얼음 승화, 용융 유동·재용융·확장 광물 반응망은 이번 P1 수정으로 해결되지 않았다. 셀 평균 온도와 확산성 물 흐름, 대표 온도를 쓰는 구름은 게임 근사로 유지한다. 보존과 시간·조건의 일관성을 먼저 확보하면서 전문 CFD나 3차원 지질 격자는 도입하지 않았다.

카메라 전환 자체는 물리 상태를 보존한다. 기존 저장·행성 이동·운석 명령 경계의 표면 스냅샷은 비행 중 공급을 표면에 합칠 수 있으며, 비행 상태·난수·명령 큐까지 정확히 복구하는 전체 checkpoint/replay와 저장된 단면 시점은 별도 후속 과제다. 장기간 에너지 이력과 실제 경계 유량 화살표, 과학 그래프 A/B 실험도 설계 확장으로 남는다.
