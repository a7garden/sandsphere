# 안정화 및 워크트리 통합 작업

2026-10-18. 구현과 최종 통합 검증 완료. 결과와 적용 범위는 아래 검증 기록에 남긴다.

## 범위와 완료 조건

- 열 전달의 Float32 손실을 측정하고 작은 교환을 실제 저장 가능한 상태로 처리한다. 수치 보정 장부만 맞추는 방식은 통과로 보지 않는다.
- 지형·물·고체 경계의 에너지 출입을 검사하고 누락된 교환을 수정한다. 고정 바닥, 과감쇠 근사와 미구현 운동 자유도는 명시한다.
- 극저온·고온·반응·해류·간소화 모드의 시간 간격/격자/저장 재개 검증을 추가한다. 개별 수지 허용오차와 현상 판정은 검사에 명시한다.
- 등록된 프로젝트 워크트리의 커밋 및 미커밋 변경을 비교하고 미통합 내용을 정본에 보존하여 통합한다.
- 최종 후보에서 전체 테스트, 버전, 빌드, 백엔드 비교와 실제 앱 입력 경로를 확인한다. 배포는 범위에 포함하지 않는다.

항성 물리, 완전한 천수 방정식 및 모든 조건에서의 수학적 안정성 증명은 이번 안정화의 완료 조건이 아니다.

| 물·고체 경계 | boundaries | 완료 | 위치에너지·반응량 제한·마찰열·그을음 보존 |

## 검증 기록

- `artifacts/stabilization/verified-tests.log`: 최종 소스를 새 프로세스에서 실행한 전체 검사. 앞선 `final-tests.log`는 실행 도중 코드 변경이 있어 최종 판정에 사용하지 않는다.
- `verified-source-manifest.json`: 최종 소스·검사 파일 SHA-256.
- `verified-build.log`: TypeScript와 프로덕션 빌드 통과. 버전 검사와 diff 공백 검사 통과.
- `browser-report.json`: Worker CPU/WebGPU/Worker WebGPU와 실패 롤백 97건 통과.
- `methane-resume-report.json`: 원본 2,562셀 메탄 저장 60단계 및 JSON 분기 재개 통과.
- `actual-game.png`: 실제 앱 재료 투입·발견·저장 불러오기·한 단계 실행 확인.
- [워크트리 감사](WORKTREE_INTEGRATION.md): 정본과 등록된 glass-ui 워크트리 모두 검사. 누락된 고유 변경 없음. 기존 통합과 후속 교체를 파일별로 확인했으며 백업을 보존했다.
- [공통 법칙 검증](COMMON_LAWS_VALIDATION.md)의 alpha.16 항목에 큰 재고에서의 절대 질량 오차 등 남은 한계를 명시했다. 보존 장부의 작은 잔차를 모든 물리 현상의 정확성으로 해석하지 않는다.

최종 전체 회귀: 84개 파일 통과·조건부 8개 파일 건너뜀, 636개 검사 통과·조건부 19개 건너뜀. 366.85초 실행 후 exit 0. 검사 뒤 소스 매니페스트의 모든 해시가 일치했다.
