# 구면에서 선택하는 표면 단면

구면에서 **단면**을 누르면 절단선과 실제 선택 셀의 윤곽이 나타난다. **양 끝 셀**을 드래그해 방향과 길이를 정하고 **선택한 단면 열기**를 누른다. 끝점은 글자 없이 해당 물리 셀의 실제 오각형·육각형 윤곽과 화면 크기로 표시한다. 드래그는 셀 중심에 맞춰 이동하며 방향키는 이웃 셀 하나씩, Shift+방향키는 네 셀씩 이동한다. **구면**으로 돌아오면 같은 절단선과 선택 셀을 표시한다. 다시 단면을 눌러 수정할 수 있고, **취소/Esc**는 편집을 시작하기 전의 선택을 복원한다. 작은 화면에서는 선택 패널을 행성 아래로 옮기고 재료 패널을 잠시 숨긴다.

## 셀과 과학 모델

- 두 끝점 사이의 짧은 대권 경로를 사용한다. 경로 길이는 최대 120°이며, 일치하거나 대척점인 끝점도 유한한 방향으로 처리한다.
- 미리보기와 실제 단면은 `buildSectionMesh`의 동일한 절단·범위 클리핑·렌더 샘플→물리 셀 매핑을 사용한다. 양 끝 셀도 원래 물리 셀 ID를 유지하며 전체 단면을 펼친다. 보기 범위는 끝 셀의 가장자리까지 확장하므로 셀 중심 간 120° 제한보다 약간 넓을 수 있다. 셀 중심 근처의 부동소수점 좌표 오차는 교차 판정에서 일관되게 처리한다.
- 선택은 **중앙 절단 평면**에서 계산한다. 관찰 띠의 앞면 오프셋으로 셀을 고르면 높이 변화에 따라 셀 하나가 빠질 수 있어, 가운데 평면에서 계산한 단면을 표시할 때만 카메라 쪽으로 옮긴다. 표면 높이가 변해도 선택 목록을 유지한다.
- 시뮬레이션 상태를 복사하거나 다른 세계를 만들지 않는다. 공급 입자, 도구 명령, 기후 계산은 기존 구면 솔버의 셀을 사용한다. 선택된 단면에서는 브러시를 해당 셀 목록에 제한하고 가중치를 재정규화한다. 이후 자연적인 물질 이동은 기존 이웃 셀과 계속 일어난다.
- 선택 편집 중에는 화면 자전만 잠시 고정하고 원래 설정으로 복원한다. 물리 자전·햇빛·기후 계산은 계속된다. 전환 도중에는 불완전한 투영을 편집하지 않도록 포인터 판정을 잠시 막는다.
- 기반암을 숨기고 기존 표면 혼합물과 물을 확대한다. 입자 무늬의 작은 칸마다 독립적인 세로 물리 상태를 추가한 기능은 아니다.
- 셀 상태는 기존 저장 경로를 사용한다. 절단선은 현재 보기의 상태이며 새로고침하거나 다른 행성으로 이동하면 다시 선택한다.

## 검증

재현용 화면: `/tests/selection-lab.html`, WebGL 비교: `?cpu=1`. A·B를 실제로 드래그하고 단면을 연 뒤 동일 셀 실험 검증을 실행한다. 초기 검증 결과는 `artifacts/section-selection/`, 셀 모양 끝점 수정 후 결과와 제품 화면은 `artifacts/section-cell-handles/`에 보존했다. 아래 표의 제품 넓은 브러시와 CPU/GPU 교차 재개 수치는 초기 검증 기록이다. 이번 수정은 렌더·선택·카메라 복귀 경로에 한정되며 솔버는 변경하지 않았다.

| 검사 | 결과 |
|---|---|
| 끝점·극점·경도 경계·범위 클리핑·렌더 샘플 소유권·높이 변경 | 단위 테스트 통과 |
| WebGPU / WebGL 선택 단면 | 각각 15셀 미리보기와 단면 ID 전체 일치 |
| 실질적인 면의 포인터 판정 | 각각 86/86 일치 |
| 낙하 공급 | 2 kg이 선택된 셀 415에 도달, 질량 수지 오차 0 kg |
| 깎기 / 재전환 | 표면 모래 5 kg 제거, 기반암 보존, 편집 후 선택 셀 유지, 구면 복귀 및 재진입 일치 |
| 저장 상태 재개 | 상태 정확히 복원, CPU 30단계 재개 결과 일치 |
| 실제 제품의 넓은 브러시 | 21셀 중 11셀 편집, 선택 밖 변경 없음, 단면 21셀 유지, 구면 복귀 상태 정확히 일치 |
| 기후 레이어 | 두 렌더러 × 두 보기 × 10레이어 = 40조합 통과 |
| 기존 단면 | 확대·범위·회전·이동·공중 역투영·상태 보존·구면 카메라 복원 회귀 통과 |
| CPU/GPU 깎기·저장 재개 | 최대 온도 차 0.00000954°C, 질량 필드 차 0.000000119 kg, 재개 후 최대 필드 차 0.00006294 |
| 셀 단위 끝점 | 같은 셀 내 이동은 선택 유지, 다른 셀로 드래그, 이웃 셀 방향키 이동, 취소 복원 통과 |
| 미세 회전 | 두 렌더러에서 작은 회전 60회가 누적되어 셀 선택 이동, 18셀 단면과 미리보기 일치, 양 끝 셀 포함 |
| 390px 화면 | 실제 셀 윤곽에 따라 약 19–21px 표시 영역, 방향키 이동, 가로 넘침 없음 |
| 브라우저 콘솔 | 세 검증 화면에서 오류 없음 |

끝점에서 생기는 폭 0.75 CSS 픽셀 미만의 삼각형 2개는 실질적인 클릭 면 검사에서 제외하고 별도로 기록했다. 면 소유권 목록에는 그대로 포함한다. 초기 검증에서 모바일 크기의 실제 드래그와 키보드를 검증했고, 이번 수정에서는 390px 셀 윤곽과 키보드 이동을 확인했다.  네이티브 터치 입력은 브라우저 테스트 도구가 지원하지 않아 검증하지 못했다.

전체 테스트 **256건 통과, 14건 제외**, 빌드 성공(기존 큰 청크 경고 유지). 전체 테스트와 빌드 로그: `unit-tests.log`, `targeted-tests.log`, `build.log`. 기본 테스트에서 제외되는 계정 규칙/장시간 실험 14건은 이 작업에서 별도로 실행하지 않았다.

셀 중심 절단에서 교차점 중복으로 끝 셀이 빠지는 경우와, 회전 후 구면 복귀에서 `setPosition`의 같은 좌표 생략 때문에 방향 계산이 갱신되지 않는 경우를 수정했다. 후자는 복귀 시 궤도 각도를 다시 계산하며 단위 테스트로 고정했다. 브라우저 기존 단면 검사는 렌더 준비를 최대 120프레임 기다린 후 동일 장면·캔버스·투영을 확인한다. 최종 재현 기록은 `renderers.json`, `regressions.json`, `flat-final.json`이다.
