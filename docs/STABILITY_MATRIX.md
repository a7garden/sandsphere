2026-10-18. 이 문서는 `tests/stability-matrix.test.ts`의 범위·판정 기준과
실행 증거를 기록한다. 공통 법칙의 실제 생산 API를 호출하며, 관측 자료에 대한
정량 검증이나 모든 초기 조건의 무한 시간 안정성은 이 검사의 범위가 아니다.

에너지 장부 잔차는 `최종 에너지 − 초기 에너지 − 물리 경계 채널 − 수치 채널`이다.
이를 물리 추세의 정확도로 해석하지 않는다. 수치 채널 절댓값 누적과 물리 경계
채널 절댓값 누적의 비율도 따로 출력한다. 비율이 5%를 넘으면 작은 장부 잔차와
별개로 물리 에너지 추세의 정밀도 한계를 명시한다. 상태 에너지는 생산 함수
`totalEnthalpy`로 읽고, 대기는 Float32 표면 표시 합계 대신 정본 층별 재고를 센다.
질량·원소 잔차의 분모는 각각 `max(1, 초기 질량)`, `max(1, 초기 해당 원소 질량)`이며,
에너지 잔차와 수치 채널 누적의 분모는 `max(1, |초기 에너지|)`다.

물 상변화, 연료 소비/생성물, 메탄 대기의 이동과 기존 −150°C 경계 통과도 함께
검사한다. 물리 과정이 멈춘 채 장부만 닫힌 상태를 안정화 증거로 사용하지 않는다.
장시간 실행의 전체 재고·숨은 배열·수지는 1,000단계마다 검사하고 저장 검증을
수행한다. 온도 극값과 바람 극값·에너지·탈출 누적은 매 단계 측정한다. 매개변수
조건은 120단계 뒤 같은 상태·수지와 실제 한 단계 재개를 검사한다.

## 재현 명령과 증거

```sh
npx vitest run tests/stability-matrix.test.ts --maxWorkers=1 --disableConsoleIntercept
```

테스트는 각 실행의 입력·통계·수지와 반복 재개 수를
`artifacts/stability-matrix/<UTC 실행 시각>/`의 JSON에 남기고 같은 이름의 최상위
JSON을 최신 실행으로 갱신한다. 모든 `src/sim/*.ts`, WGSL과 검증 도우미의 SHA-256도
함께 기록한다. 장시간·매개변수 실패는 `status: failed`와 마지막 단계·오류·관측치·
다시 실행할 수 있는 스냅샷을 남긴다.
동시 실행에서는 최상위 최신 파일이 서로 다른 실행을 가리킬 수 있으므로 비교는
반드시 같은 UTC 실행 폴더 안에서 한다. 최종 증거는 모든 관련 소스가 고정된 뒤
새 Vitest 프로세스로 시작한 실행을 사용한다. 실행 중 읽은 파일 해시만으로
이전 변환 캐시를 읽지 않았다고 증명할 수는 없다.

## 이 행렬로 판단할 수 있는 범위

여기서 직접 호출하는 실행 경로는 `CpuSolver`다. Worker/WebGPU·브라우저의
실제 앱 통합 증거는 별도 실행 기록을 따른다. 깊은 H₂/He 대기, 모든 상변화,
생태계의 장기 평형, 실제 행성 기후 재현까지 이 16개 조건에서 검증했다고
해석하지 않는다. 기존 고온 4000°C·극저온 −260°C 검사는
`tests/surface-energy-domain.test.ts`에 별도로 남아 있다.
브라우저의 고재고 스트레스에서 측정한 절대 질량 잔차 한계는
[공통 법칙 엔진 검증](COMMON_LAWS_VALIDATION.md)의 별도 결과를 따른다.
이 행렬의 정규화 수지 통과를 그 절대 오차 기준의 통과로 확대하지 않는다.

격자 검사는 같은 부드러운 온도·셀별 물성을 다른 구면 격자에 배치하고 평균
모드 진폭을 비교한다. 각 셀의 재고를 같은 값으로 두므로 셀 수와 함께 전역
장부의 크기도 바뀐다. 서로 다른 격자의 셀끼리 점별 비교하거나, 이 작은 진폭
차이만으로 대기·구름·해류 전체의 정량적인 공간 수렴을 주장하지 않는다.

시간 간격 비교에서 물 조건의 재고·지표 온도 오차는 미량 Float32 재고와
상분할 영향으로 단조롭지 않을 수 있다. 정한 작은 오차 바닥 이하에서는
감소율을 계산하지 않고 절대 한계와 실제 대기 온도 감소를 함께 보고한다.
장기 혼돈 궤적의 점별 일치와 같은 격자·같은 시간 간격의 저장 재개 완전 일치는
서로 다른 검사다.

직접 Vitest 실행의 기본 5초 제한으로 층별 격자 검사 한 번이 6.556초에
시간 초과했다. 계산된 물리 판정은 통과했지만 실행 자체는 실패로 보존했다.
해당 검사의 실행 제한만 저장소 `npm test`와 같은 20초로 지정한 재실행은
2개 격자 조건을 모두 통과했다. 질량·원소·에너지·온도 허용 오차는 바꾸지 않았다.
