# 공통 행성 정의와 암석형·가스형 지원

2026-10-14, 개발 버전 0.7.0-alpha.5.

## 정의와 실행 범위

`src/sim/planetDefinition.ts`의 `PlanetDefinition` 버전 1이 초기 물리 입력을
정의한다. 반지름(m), 기준 중력(m/s²), 궤도 거리(AU)·주기(s), 초기 자전
주기(s)·기울기(°), 초기 대기압(Pa)·몰분율·복사 모델을 갖는다.
`Environment.body`에 저장하며 기존 `gravity`·`orbitDistance`는 실행 경로의
호환 필드다. 저장 검증은 정의와 이 두 값의 불일치를 거부한다.
현재 자전 각도·주기·일시정지는 기존 `Snapshot.spin`에 남는다. 정의의
초기 조성과 압력은 생성 입력이며 편집·탈출 이후의 실제 대기량은 셀과
대기층에서 읽는다.

하단 경계는 다음 두 형태로 나뉜다.

- `solid-surface`: 암석형 지표의 주요 물질.
- `deep-atmosphere`: 계산 대기 아래의 기준 압력과 내부 열 플럭스(W/m²).

`gas-giant`와 `hydrogen-helium` 복사 모델은 별도의 12층 `DeepAtmosphere`로
실행한다. 목성형·토성형 프리셋이 같은 계산기에 반지름·중력·조성·내부
열·초기 온도 입력을 공급한다. 기준 압력은 1kPa 이상, 아래 경계는 기준
압력의 2배 이상·100bar 이하이며, H₂·He가 90% 이상인 대기와 NH₃·H₂O 성분을 지원한다. 상단과 하단의 물질
경계는 밀폐하며 하단은 지정한 순 내부 열 플럭스를 전달한다. 고체 지표,
기반 열용량, 온도 고정 저장소와 기체 보충은 없다.

`ice-giant`와 추가 성분·화학은 정의의 확장 지점으로 남는다. 생성·CPU·GPU·Worker·
저장 검증은 미지원 조성·복사·경계를 변경 전에 거부한다. 정의에 성분이
있다는 사실은 그 종의 수송·응결 지원을 뜻하지 않는다. 가스형의 식·수지·
저장과 한계는 [거대행성 검증](GIANT_PLANETS_VALIDATION.md)에 기록한다.

## 저장 호환

행성 스냅샷은 버전 8이며 항성계 봉투 버전 3은 유지한다. 셀은 36필드다.
원래 24필드 뒤의 CO₂ 얼음·지표 먼지·대기 먼지와 예약 필드 0을 유지하고,
28/29번에 H₂/He, 30/31/32번에 NH₃ 기체/액체 구름/얼음,
33/34/35번에 예약 필드 0을 붙인다. 물 구름의 기존 위치도 유지한다.
1–7 버전 및 16/20/24/28/32필드 저장은 계속 읽으며 없던 새 필드는 0이다.
업그레이드는 복사한 상태에
`sandbox` 정의를 붙이며 원본과 질량·온도·진행 시간을 보존한다. 기존에
허용된 작은 음수 상변화 반올림의 복구 정책은 그대로다.

기존 행성은 반지름 1,000km, 기존 지구형 분광 복사와 압축 공전
`240 × distance^1.5` 게임초를 유지한다. 메타데이터 추가를 실제 화성으로의
전환으로 해석하지 않는다. 대기층의 반지름·온도 하한·복사 모델·복사 캐시도
저장·체크포인트·Worker에서 함께 전달한다. 재개 시 기체를 다시 생성하지
않는다. 11층 대기는 버전 3에 먼지량·복사 캐시·소량 비산 누적값을 함께
저장한다. 이전 대기 버전 1/2의 먼지는 0으로 시작한다. 서로 다른 정의/대기
메타데이터를 가진 저장은 거부한다. 옛 대시보드와 CSV도 계속 읽으며
기록되지 않은 새 지표는 미관측 값으로 남긴다.

가스형만 기후 봉투 버전 3과 심부 대기 버전 2를 사용한다. 층별 8개 성분의
질량·온도·속도·기준 높이가 Float64 정본이며 셀 배열은 질량·열평균 온도의
Float32 표시용 합계다. 저장에서 두 상태와 행성 정의의 일치를 검사한다.
고체 구성 필드 `Snapshot.planet`은 가스형 저장에 넣지 않는다. 기존
암석형 기후 버전 1/2와 화성형 먼지 캐시는 그대로 읽는다. 심부 버전 1의
H₂/He·바람·온도·높이는 유지하고 새 구름 성분을 0으로 확장한다.

## 화성형의 현재 범위

생성 화면에서 **행성 유형 → 화성형**을 선택한다.

| 초기 입력 | 값 |
|---|---|
| 기준 반지름 / 중력 | 3,389.5km / 3.71m/s² |
| 거리 / 공전 주기 | 1.524AU / 약 687일 |
| 자전 주기 / 기울기 | 약 24시간 37분 / 25.19° |
| 대기압 / 지원 성분 근사 | 636Pa / CO₂ 97%, N₂ 3% 몰분율 |
| 초기 지표 | 암석 기반, 모래·점토, 소량의 지표 먼지, 극지 물얼음 |
| 초기 온도 | 위도에 따라 −50∼−85°C |

기본 수치는 [NASA 화성 수치표](https://nssdc.gsfc.nasa.gov/planetary/factsheet/marsfact.html)
및 [NASA 화성 설명](https://science.nasa.gov/mars/facts/)을 참조한다. 아르곤은
아직 수송하지 않으며 조성을 지원 기체로 근사한다. 지형·얼음량·초기 온도
분포는 관측 지도를 재현한 자료가 아닌 실험 초기 조건이다.

한 게임초는 대기와 표시 시계에서 모두 물리 60초다. 화성형의 공전은 이
같은 시간 변환을 사용하며, 기존 자유 구성의 압축 공전과 구분한다. 자전
설정은 화성의 하루가 잘리지 않도록 최대 48시간을 허용한다. 정지 중
명령이 없는 상태는 변환·적분 없이 유지한다.

지표 하한은 −200°C, 대기 하한은 −220°C다. 화성형 복사는 지구 ecCKD
표를 그대로 사용하지 않고 회색체 두 방향 전달을 사용한다. 층별 장파
광학 깊이는 `COLUMN_KG × (0.0015 × CO2 + 0.01 × vapor + 30 × dust)`이며 구름은
기존 수분 질량의 소광 근사를 사용한다. 이 계수는 명시적인 게임 근사이고
화성 분광 흡수나 관측 기후에 대한 교정 결과가 아니다. 지구 오존·N₂O
프로파일은 이 경로에 넣지 않는다. 바람 수송 거리, CFL, 각속도↔m/s,
탈출 결합과 대기 외곽선에 정의의 반지름을 사용한다.

온도 지도는 −150∼30°C, 기압 지도는 0∼1,200Pa를 사용한다. 얇은 대기의
표시 외곽선은 약 1Pa이며, 화면 높이는 압축한다. CO₂ 지표 상변화는 현재 분압과
일정 승화열의 Clausius–Clapeyron 곡선을 사용한다.
[NIST WebBook](https://webbook.nist.gov/cgi/cbook.cgi?ID=C124389&Mask=4)의
삼중점 216.58K·5.185bar와 승화열 26.3kJ/mol을 기준으로 한다. 화성형은
최하층 CO₂와 지표 얼음 사이의 질량을 교환하고 잠열·위치·운동 에너지를
전달한다. 액체 CO₂와 대기 중 CO₂ 구름은 지원하지 않는다.

먼지는 바람 응력으로 유한한 지표 먼지·모래에서 발생하고 대기 질량
플럭스와 함께 11층을 이동하며 침강한다. 같은 먼지량이 단파 흡수·산란과
장파 흡수에 사용된다. **대기 먼지 / CO₂ 얼음** 지도와 관측 패널·대시보드로
분포와 재고를 확인한다. 발생 임계값·입자 크기·광학 계수는 감도 실험용
입력이다. 상세한 보존 식·저장 배치·검증은 [화성 과정 검증](MARS_PROCESSES_VALIDATION.md)에 기록한다.

## 목성형·토성형의 현재 범위

생성 화면의 **행성 유형 → 목성형 / 토성형**으로 만든다. 목성형은
건조 H₂/He 비율 89.8/10.2%, 토성형은 96.7/3.3%를 유지하며 NH₃와
물의 유한한 재고를 포함한다. NH₃/물 전체 재고 몰분율은 목성형
300/3,000ppm, 토성형 200/2,000ppm의 감도 실험 입력이다. 두 프리셋 모두 초기 하단 30bar까지 계산하며 내부 열은
각각 5.4/2.0W/m²의 감도 실험용 값이다. 1bar 기준 반지름·평균 중력,
실제 자전·공전 시간과 서로 다른 초기 열 프로파일을 사용한다.

초기 압력 간격으로 층의 질량과 기준 높이를 정한다. 실행 압력은 실제
누적 질량에서 계산하며 높이는 고정한다. 8성분의 수평 질량·열·운동량 수송, 층간
교환과 불안정 혼합, 코리올리 회전·감쇠, 회색체 복사, NH₃·물의
응결·증발·융해·침강을 계산한다. 현열·잠열·위치·운동 에너지를 같은
장부에 넣는다. 처음 지정한 띠·제트는 실험 조건이며 이후 수송 상태를
원래 패턴으로 강제 복구하지 않는다. 가열·
냉각 도구는 1bar에 가장 가까운 층에 열을 넣거나 뺀다. 12층 표에서 실제
온도·압력·구름량·동서풍을 관측한다. 동서 제트와 NH₃ 구름 지도 및
위도별 평균으로 띠와 바람 방향을 확인한다. 초기 표본 층의 중심은 약 1.255bar이므로
표시 온도는 정확히 1bar의 정의 온도와 다르다.

온도 지도·기압 지도·대기 조성·기류·열 장부를 사용할 수 있다. 고체 재료
공급·삭제·회수·운석·지표 단면은 제한한다. 표시 구면은 기준 압력의 위치를
뜻하며 암석층을 추가하지 않는다. 물질 지도 색은 실제 구름 광학 깊이와 보이는 구름층의 압축 표현이다.
관측 착색 물질·띠의 정량 재현은 아직 검증하지 않았다.
식·저장·초기화·보존 수지는 [구름·제트 검증](GIANT_CLOUDS_VALIDATION.md)을 따른다.

## 남은 물리와 후속 순서

현재 11개 대표 고도 층과 이상기체·고정 비열 근사를 유지한다. 지중 열
확산, 지형에 따른 정역학 압력 차이, 관측 극관·먼지 폭풍의 계절 주기 교정,
여러 입자 크기·먼지 악마·액체 CO₂·대기 CO₂ 구름, 이심률과 관측
온도·기압·바람 검증은 남아 있다. 보존하는 지표 상변화와 먼지 과정의
존재를 실제 화성 상평형·폭풍의 정량 재현으로 해석하지 않는다.

다음은 질량 변화에 따라 움직이는 압력 좌표와 고도·지중 열 경계를 보완할
수 있다. 가스형에는 분광 충돌 유도 흡수·입자 크기 분포·NH₄SH/용액 화학·헬륨 분리 및
관측 제트 검증을 연결할 수 있다. 토성 고리는 독립 모듈로 다룬다.
금속수소 심부나 행성 형성의 자기중력 계산은 현재 대기층 확장의 범위 밖이다.

## 검증

`tests/planet-definition.test.ts`는 정의 검증·미지원 경계 거부, 몰분율과
636Pa 초기화, 옛 저장의 상태/계산 유지, −125°C 지표, 한 시간 보존 수지,
JSON·항성계 저장 후 정확 재개 및 활성/동기·비동기 배경 계산을 검사한다.

브라우저 시험은 개발 서버의 `/tests/planet-model-lab.html`에서 실행한다.
42셀·30단계·−125°C 초기 조건의 실제 Worker/CPU 상태와 기후는 정확히
일치했다. 실제 WebGPU의 CPU 대비 최대 지표 온도 차이는 0.00042725°C,
질량 잔차는 0, 모델 에너지 장부 잔차는 −0.029846kJ였다. GPU→CPU 저장
재개 한 단계의 전체 상태 최대 차이는 0.00001526이었다. GPU와 CPU는
동일한 호스트 대기 코드를 사용하므로 별도 GPU 대기 방정식 검증은 아니다.

실제 생성 화면·화성형 실행·새로고침 후 재개·기압/조성·반지름/공전 정보도
확인했다. 이 검증은 보존·실행·호환 검증이며 관측 화성 기후의 정량 재현을
인증하지 않는다. 전체 회귀 결과는 `CHANGELOG.md`의 Unreleased를 따른다.

이번 버전은 목성형·토성형 한 시간 질량·에너지 보존, JSON 정확 재개,
기존 28필드 화성 저장, 활성/배경 계산과 Worker 전송을 추가 검증했다.
실제 CPU·Worker·WebGPU 실행 경로의 상태와 기후가 일치했다. 가스형의
모든 실행 경로는 같은 호스트/Worker 대기 식을 사용하며 독립 GPU 대기
방정식 검증은 아니다. 상세 수치는 [거대행성 검증](GIANT_PLANETS_VALIDATION.md)을 따른다.

암모니아·물 구름, 층별 제트, 기존 버전 7의 무보충 변환 및 새 관측값의
미관측 호환과 8개 전체 해상도 거대행성 gzip 저장도 추가 검증했다.
현재 결과와 실행 경로의 공통 호스트 물리 범위는
[구름·제트 검증](GIANT_CLOUDS_VALIDATION.md)을 따른다.
