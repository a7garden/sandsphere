# 공통 법칙과 창발적 시뮬레이션

2026-10-14에 확정한 설계 방향이다. 이 문서는 앞으로의 구현 기준이며,
현재 엔진이 모든 기준을 이미 충족한다는 검증 보고서가 아니다.

## 게임의 출발점

Sandsphere는 **구형 파우더 토이**다. 재료를 놓고 열·조성·중력·회전 조건을
바꾸며, 그 재료들이 같은 국소 법칙으로 어떻게 반응하고 이동하는지 관찰하는
게임이다. 행성과 항성은 이 실험이 확장될 수 있는 대상이다. 먼저 정해진 행성
풍경을 재생하는 데 맞춰 예외를 늘리지 않는다.

기반 구축의 우선순위는 유한한 재고 → 공통 물성·수송·반응 → 에너지의 재분배
→ 다른 반응과 거시 현상의 연결이다. 새 조합의 결과를 미리 이벤트로 지정하지
않고 실제 생성물이 다음 과정의 재료가 되게 한다. 새로운 반응 종류 자체는
원소 수지와 에너지 기준을 갖춘 선언으로 추가한다. 등록되지 않은 화학식을
엔진이 스스로 발견한다는 의미는 아니다.

항성까지의 확장은 장기 설계 방향이며, 현재 핵반응·플라스마·자기장·자기중력
붕괴는 구현 범위 밖이다. 이 단계의 숯·그을음은 공통 재고를 이동시키고 다시
반응시키는 기반이다. 실제 구현과 검증 범위는 아래 검증 문서에 기록한다.

## 중심 원칙

**같은 상태와 같은 외부 조건에는 같은 법칙이 적용되고, 작은 상호작용이
누적되어 행성 규모의 현상을 만들어야 한다.**

비, 구름 띠, 사막, 숲 같은 결과를 각각 만들어 내는 기능을 늘리기보다
물질의 이동, 에너지 교환, 상변화와 반응이 서로 연결되도록 만든다.
새 물질이나 행성은 가능한 한 이 과정에 물성과 초기 조건을 공급한다.
이는 설계 선택이다. 실제 세계의 모든 물리가 단 하나의 식에서 유도된다는
주장이나, 현재의 게임 근사가 실제 행성을 정량적으로 재현한다는 뜻은 아니다.

단순함은 함수 개수나 파일 개수가 아니라 독립적인 가정과 예외의 수로 판단한다.
고체·액체·기체에 서로 다른 구성식이나 수치해법이 필요할 수 있다.
그 경우에도 상태의 의미, 단위, 교환 수지와 외부 경계는 일관되어야 한다.

## 공통 상태와 변화의 규칙

각 계산 영역은 물질별 재고, 에너지와 필요한 운동 상태를 소유한다.
온도·압력·상태별 비율은 그 재고와 물성에 맞게 계산한다. 계산 효율 때문에
온도 등을 직접 저장할 수 있지만, 다른 저장량과 모순되는 독립적인 권위를
부여하지 않는다. 표시용 합계와 캐시는 원래 재고를 다시 계산에 더하지 않는다.

모든 변화는 다음 형태로 설명할 수 있어야 한다.

```text
다음 상태 = 현재 상태
          + 이웃 및 다른 영역과의 교환
          + 내부 변환
          + 명시한 외부 유입·유출
```

| 과정 | 공통 요구사항 |
| --- | --- |
| 수송 | 보내는 쪽의 유한한 재고를 넘기지 않는다. 받는 쪽과 같은 양을 교환하고 물질이 운반하는 에너지·운동량을 함께 처리한다. |
| 열 교환 | 온도·복사·물성으로 교환량을 구한다. 내부 전달은 양쪽의 에너지 변화가 상쇄되어야 한다. |
| 상변화·반응 | 같은 물질의 상변화는 해당 성분 총량을 보존한다. 화학 반응은 선언한 화학량론과 원소 수지를 따른다. 잠열·반응열을 에너지에 반영한다. |
| 힘·소산 | 추적하는 운동량과 운동에너지의 변화 및 반작용을 설명한다. 마찰로 사라지는 운동에너지는 열이나 명시한 외부 경계로 전달한다. |
| 외부 작용 | 항성 복사, 내부 열, 탈출, 도구 공급·회수 등의 출입을 경계와 장부에 기록한다. |

닫힌 영역의 내부 교환은 전체 합에서 사라져야 한다. 열역학적으로 금지된
교환을 보존 수지만 맞춰 허용해서는 안 된다. 전체 질량·에너지 보존과 함께
흐름의 방향, 평형, 유한한 반응물, 필요한 비가역성도 검증한다.

격자·시간 간격·적분 순서는 공통 실행 계약이다. 빠른 재생, 백그라운드 계산,
CPU·GPU·Worker는 같은 물리를 실행해야 한다. 병렬 계산과 정밀도 차이에 따른
허용 오차는 별도로 명시한다. 무작위 과정이 필요하면 시드와 재개에 필요한
상태를 관리한다. 계산 불안정에 대한 온도 제한이나 재고 보정은 물리 법칙으로
취급하지 않고 발생량을 드러낸다.

## 현상이 생기는 경로

비는 이름 붙은 날씨 이벤트가 셀에 물을 생성해서 발생하지 않는다.
공급된 물이 열을 받아 증발하고, 수송된 수증기가 국소 조건에서 응결하고,
응결물이 성장·침강하며, 내려오는 동안 증발하거나 지표에 도달하는 과정의
결과여야 한다. 사용자가 실험용 강수를 직접 넣는 기능은 외부 물질·에너지
공급으로 따로 설명할 수 있다.

구름 띠는 대기의 수송·회전·가열·상변화가 만드는 분포여야 한다.
초기 띠나 제트를 실험 조건으로 넣을 수 있지만, 그 모양으로 계속 복구하는
처방과 자발적으로 형성·유지된 띠를 구별한다. 초기 무늬를 보존하거나
움직였다는 결과만으로 창발성을 주장하지 않는다.

생태도 같은 물질·에너지 계통에 속한다. 장기적으로 성장은 필요한 자원과
에너지를 소비하고, 섭식·대사·죽음은 다른 저장고로 재고를 돌려보내야 한다.
서식 적합도는 반응 속도를 조절할 수 있으나 존재하지 않는 자원을 대신할 수
없다. 생태를 간소화할 때에는 묶어 표현한 자원과 생략한 수지를 명시한다.

## 행성·게임·표시의 역할

- 행성 프리셋은 반지름·중력·조성·자전·궤도·초기 상태·경계 조건을 정한다.
  행성 이름 자체는 진화 방정식의 입력이 아니다. 복사 근사 등 모델 선택은
  조성·압력·온도의 적용 범위로 설명하며 미지원 범위는 명시한다.
- 캠페인 과제는 발생한 상태를 판정한다. 과제 달성을 위해 반응률이나 날씨를
  몰래 바꾸지 않는다. 보관함 보상과 행성에 투입한 물질은 구분하여 기록한다.
- 도구는 명시적인 물질·에너지·운동량 입력 또는 외부 조건의 변경이다.
  중력이나 경계 자체를 편집해 생긴 수지 변화도 일반적인 내부 진화와 구분한다.
- 렌더링과 관측은 같은 정본 상태를 읽는다. 시각적 보간·색·표시 축척은
  허용하지만 화면에서 만든 구름·동물이 물리 재고를 따로 생성하지 않는다.

상평형·재고 반응과 CPU/GPU 반응 경로를 통합했다. 완료 범위와 남은 근사는

## 구현 순서와 완료 조건

1. 각 과정의 읽기·쓰기 상태, 단위, 물성, 적용 범위, 외부 경계와 보정량을
   정리한다. 동일한 물질의 잠열이나 열용량이 경로마다 달라지지 않게 한다.
2. 기존 동작을 검사하면서 보존 교환과 국소 변환을 하나씩 공통 연산으로
   옮긴다. 유출 총량을 계산한 뒤 제한해 여러 이웃이 같은 재고를 중복 소비하지
   않게 한다. CPU·GPU의 구현 차이도 같은 입력·기대 수지로 검사한다.
3. 지표·대기·깊은 대기를 명시적인 교환 경계로 결합한다. 경계에 물질과
   에너지를 한 번만 기록하고 표시용 합계는 재고로 사용하지 않는다.
4. 생태의 자원·에너지 계통을 보완하고 처방된 거시 패턴에 의존하는 부분을
   줄인다. 새 상태가 필요하면 별도의 저장 호환 설계와 재개 검증을 수행한다.

각 변경은 영향을 받는 범위에서 다음 증거를 갖춰야 한다.

- **국소 법칙:** 무재고·평형에서는 불필요한 변화가 없고, 교환은 유한한
  재고와 물성의 적용 범위를 지킨다. 닫힌 수지와 열린 경계 수지를 각각 검사한다.
- **구현 독립성:** 행성 이름·카메라·캠페인 진행만 바꾸면 물리 결과가 바뀌지
  않는다. 활성/배경과 저장 재개, CPU/Worker/GPU의 차이를 허용 오차와 비교한다.
- **수치 안정성:** 더 작은 시간 간격·다른 해상도에서 주요 통계가 수렴하는지
  확인하고 수치 보정이 결과를 지배하지 않는지 측정한다. 혼돈적인 장기 궤적의
  점별 일치와 통계적 일관성은 구별한다.
- **창발성:** 거시 패턴을 주입하지 않은 초기 상태에서도 해당 현상이 형성되는지,
  원인으로 제시한 과정이나 구동을 제거하면 예상대로 약화되는지 검사한다.
  질량·에너지 보존 검사와 관측 데이터에 대한 정량 검증은 별도로 보고한다.

기존 저장이나 실행 경로를 일괄 교체하지 않는다. 개별 통합 작업의 완료 여부는
검증 기록으로 판단하며, 이 원칙의 채택만으로 모든 현상이 검증되었다고 보지 않는다.
