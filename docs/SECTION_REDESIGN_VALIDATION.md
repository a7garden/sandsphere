# 단면 표면 확대·회전·경계 개선 검증

2026-10-10. 사용자 승인한 추천안을 구현했다. 전체 자동 시험 **28파일·180개**, TypeScript 및 프로덕션 빌드, 실제 WebGPU 과학 경계 **20종**과 혼합 세계·저장 교차 재개 **6종**이 통과했다.

## 적용한 동작

- 단면 진입 시 선택 지점 주변 표면을 확대한다. 큰 원의 중심을 기본 작업 영역으로 두지 않는다. 회전하면 해당 방향의 표면 높이를 따라간다.
- 화면의 회전/이동 버튼으로 드래그 동작을 선택한다. 기본 그랩·오른쪽 드래그·조이스틱·방향키는 두 축 절단면 회전이며, Shift+드래그는 이동이다. 두 손가락 중심 이동과 핀치는 공통 입력 경로를 사용한다. 행성 조정에 방향·기울기·띠 폭 슬라이더를 제공한다.
- 표면 확대/전체 버튼으로 framing을 부드럽게 바꾼다. 홈은 현재 절단 방향의 표면 확대를 복원한다. 구면 복귀 시 원래 카메라 위치·대상·투영을 복원한다.
- 기반 경계는 교차 변의 공유 정점 높이를 보간한다. 액체 바닥은 실제 지형 단면과 교차시킨다. 셀마다 한 반지름으로 채우던 계단 경계를 제거하되 실제 해안 단차와 물질 소유권은 유지한다.
- 깊은 내부는 편집 불가 고정 기반으로 채운다. 중립 색과 약한 정적 질감을 사용하며 맨틀/핵, 지하 온도, 대류를 만들어 표시하지 않는다.

## 과학 모델과 게임 단순화

계산 격자·24필드 상태·중력·열·상 변화·물질 흐름·CPU/WGSL 공식을 변경하지 않았다. 단면은 기존 기둥의 혼합 물질을 관측하는 표시다. 렌더 높이의 로그 과장과 구면의 표현용 보간을 공유하며, 깊이별 재료 순서나 독립 지하 셀을 암시하지 않는다. 경계 연결 때문에 질량·엔탈피·저장값을 보정하지 않는다. 실제 내부 시뮬레이션은 별도 모델 확장으로 남겨 둔다.

## 검증 근거

| 검증 | 결과 |
|---|---|
| 빌드 호환성 | CSV 원본 회귀 시험은 Vite의 `?raw` import로 읽어 기존 TypeScript 타입 구성에서 빌드. 원본 CSV·검증 기대값은 보존 |
| `tests/section.test.ts` 신규 4개 | 다른 owner 사이 기반 공유 변 연결, 경사진 실제 지형 위의 액체 바닥, 극점·root 회전·두 축 정규직교 기저, 이동과 회전 분리, 표면/전체 framing 보간·부분 역전환 통과 |
| 실제 WebGPU 단면 카메라 회귀 | 절단 법선과 표시 owner 변경, 이동 시 법선 보존, 전체 중심/표면 복귀, 구면 카메라 복원, 동일 canvas 유지, 유한 메시·scene ready, 셀 상태·질량·엔탈피 정확히 보존 |
| 단면 picking | 표면 편집 가능, 공기 공급 가능, 기반은 편집 대상에서 제외 |
| 강수 회귀 | 비/눈 색상 속성, 정지 분포 유지, 숨김 중 초기화, 구면 왕복 후 상태 보존 통과 |
| 실제 제품 입력 | 재료 선택 중 오른쪽 드래그는 회전만 하며 공급량/셀 상태 불변. 왼쪽 클릭은 2.6667kg 공급 입자 생성. 기울기 슬라이더 ArrowRight는 1° 적용 |
| 합성 터치 입력 | 두 손가락 중심 30px/10px 이동이 각각 −7.8131°/−2.6044°로 한 번만 적용. 공급·상태 변화 없음. 가상 pointer capture만 임시 대체하고 즉시 복원 |
| 320/375/414/768px | 새 조작 버튼 화면 내 배치, 모두 44px 이상, 문서 가로 넘침 없음 |
| UI 테마·우주 배경 4조합 | 새 단면 버튼 텍스트 대비 최소 8.40:1, 포커스 대비 최소 3.12:1. 흰 배경에서는 단면 조작부의 배경을 UI 테마와 분리해 읽기 어려운 조합을 수정 |
| GPU 과학 경계 20종 | 기존 허용차(온도 0.003°C 등) 이내 모두 통과 |
| 혼합 세계 6종 | 저온·고온·생태·약한 중력·정지 명령·완전 동결. 최대 300단계, 150단계 저장 후 CPU→GPU/GPU→CPU 재개 및 유효 저장 검증 모두 통과 |

터치는 합성 이벤트로 입력 경로를 검증했으며 실제 휴대기기 시험은 수행하지 않았다. 카메라 표시 설정 저장과 독립 지하 시뮬레이션을 구현했다고 주장하지 않는다. 빌드의 기존 대형 번들 경고는 유지된다.
