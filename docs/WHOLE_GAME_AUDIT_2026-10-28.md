# 전체 게임 검수 — 2026-10-28

기준: `docs/SIMULATION_PRINCIPLES.md`의 구형 파우더 토이. 이 기록은 구현,
조작, 테스트와 배포 상태를 분리한다. 보존 장부 통과는 실제 기후 관측이나
창발성의 검증을 뜻하지 않는다.

## 원래 재현과 개선

- 순수 수증기 0.03 kg·엔탈피 36의 상평형은 종전 79.128975를 반환했다.
  비등·승화 잠열 구간에 유한한 상 재고를 할당하도록 수정했다. 순수 물,
  혼합 기체, 두 구름 closure의 집중 검사와 생산 CPU 감사 재현을 수행했다.
  독립 검토에서 극미량 건조 기체의 잔차와 유효 입력의 미수렴을 추가로 발견해
  수정했으며, 원래 실패를 포함한 960조건을 재검사했다. 0°C 융해 근사와
  실제 삼중점의 차이는 0°C 부근의 좁은 온도 범위에서 포화압 식을 연결하는
  물성 근사로 처리하고, 연결부의 상 순서와 연속성을 검증한다. 접합 범위는
  −0.01…+0.01°C이며 얼음의 0°C 이하와 범위 밖 원식은 유지한다. 물의 포화압
  차이는 원식 대비 0.011% 미만이다. 이는 실제 물 상태방정식 전체의 검증이 아니다.
- 1 K 미만 기체의 결합값·관측이 1 K로 대체되던 것을 정본 온도로 계산한다.
  탈출량은 실제 저장된 재고 차이이며 같은 온도·속도의 물질이 운반하는 열,
  잠열, 위치·운동에너지를 외부 장부에 기록한다. 수치 표현 잔차는 별도다.
- 운석의 지표 열용량은 대기 합계에서 빼지 않고 정본 지표 재고에서 구한다.
  거친 격자에서 반경 안에 셀이 없어도 최근접 셀로 실제 운철을 공급한다.
- 생성에서 허용한 행성 거리·주기와 저장 검증 범위를 일치시키고, 초기 띠의
  수소·헬륨 분배에서 없는 재고가 음수가 되는 반올림을 수정했다. 저장 형식
  버전은 바꾸지 않았다. 기존 저장과 JSON 재개, 범위 밖 입력 거절을 검사했다.
- 극저온 액체 구름은 기존 상수 비열 외삽에서 동결이 흡열이 될 수 있다.
  완전 평형에 필요한 에너지가 없으면 사용 가능한 재고 내에서만 변환한다.
  이는 극저온 실제 물성의 검증이 아니다.
- 모바일 단면 선택 중 선택 버튼이 카메라 바에 가려지던 문제와 수정 후보에서
  발생한 바 양끝·패널 버튼 겹침을 각각 확인하고 수정했다. 실제 터치 및 선택
  영역 회귀는 격리된 데스크톱 Chrome 에뮬레이션으로 수행했다.

## 남은 문제와 범위

- 이번 재현에서 `REAUDIT19_*` 감사 스크립트가 고정 이름으로 쓰는 기존
  `artifacts/reaudit19/air`, `tools`, `surface`, `execution` 일부 파일을
  덮어썼다. 이 디렉터리는 Git에서 제외되어 있으며 확인한 보존 복사본과
  Time Machine에서 원문을 찾지 못했다. 10월 19일 감사 문서의 수치와 로그는
  남지만, 위 경로의 현재 JSON을 당시 원본 증거로 취급하면 안 된다. 이후
  감사 시험은 실행별 `artifacts/reaudit19/reruns/` 경로에 기록하도록 바꿨다.
  재실행 전후 기존 `tools` JSON의 SHA-256이 변하지 않는 것을 확인했다.
- 일반 기후 검사의 고정 경로 `artifacts/climate-reference/column-observations.json`과
  `radiation-observations.json`도 이번 재실행으로 덮어썼다. 두 파일을 과거 기후
  진단의 원본으로 취급할 수 없으며, 본 검사와 RCE 결과는 이후 실행별
  `artifacts/climate-reference/reruns/`에 기록하도록 변경했다.
- 첫 전체 회귀는 851건 통과·70건 조건부 제외, 1건 실패였다. 실패한 시험은
  최적화 이전의 공유 물리 소스 해시를 현재 생산 소스와 동일하게 요구한다.
  이번 상평형 등 의도된 변경이 원본 고정 조건과 충돌했다. 당시 원본 34개와
  의존 관계를 별도로 고정해 SHA와 기존 golden을 그대로 유지했고, 독립 비교
  12건을 통과했다. 첫 전체 실행은 전체 통과로 간주하지 않으며 최종 전체
  회귀를 별도로 실행한다.
- 뒤이은 전체 회귀는 858건 통과·70건 조건부 제외·5건 실패였다. 새 상평형
  수렴 검사에서 일반 대기와 장시간 재개가 중단됐다. 0°C의 물·얼음 포화압
  경험식이 현재 융해 기준과 맞지 않는 경계를 확인하고 수정했다.
- 접합 수정 후 전체 회귀는 868건 통과·70건 조건부 제외였다. 버전 검사,
  운영 설정을 포함한 빌드와 Java 21을 사용한 보안 규칙 5건도 통과했다.
  전체 실행 중 기후 진단의 결과 파일 경로만 변경했으며, 변경된 출력 경로는
  기존 파일 해시 비교와 집중 검사로 별도 확인했다. 이후 독립 검토에서 지적한
  비유한 압력 거절을 추가한 뒤 관련 6파일 82건과 습한 수소·순수 헬륨
  거대행성의 1,500단계·반복 저장 재개 검사를 별도로 통과했다. 작은 반경의
  별도 조건은 기존에 명시된 온도 적용 범위를 벗어나 중단됐다.
- 비유한 압력 거절과 진단 출력 경로 수정을 모두 포함한 최종 후보에서 전체
  `npm test`는 869건 통과·70건 조건부 제외였다.
- 별도로 생산 기둥의 RCE 경계 조건 295/300/305 K에서 각 1,000일을 적분해
  실행·유한 재고·건조 질량 검사 3건이 통과했다. 마지막 두 100일 평균 온도
  차이는 각각 0.1063/0.1416/0.1303 K로 프로젝트의 0.2 K 평균 기준 안이었다.
  마지막 하루 최대 변화는 각각 0.9283/0.8017/2.6042 K로 별도 일 변화 기준
  0.01 K/day를 넘었다. 실측 기후 검증이나 RCEMIP 앙상블 합격은 아니다.
- 수증기 0.0001 kg이 있는 약 −273.139°C의 유효한 12셀 행성은 1/30 단계에서
  수직 CFL 오류가 난다. 응결로 가열된 진단 parcel을 기존 단계 예측이 반영하지
  못한다. 더 작은 간격에서는 진행되지만 모든 내부 단계의 안전성을 보장하지
  않는다. 시험한 수직 subcycle 후보는 일부 입력에서 계산 비용이 과도해 철회했다.
  실제 층의 상조정을 수송 전에 실행하고 전체 단계를 재시도한 격리 실험은
  12셀 최소 조건 6개를 통과했지만, 과포화 일반 조건의 상태도 달라졌다.
  시간·격자 수렴, 장시간 재개, 단계별 수지와 실제 성능 검증이 남아 있어
  이 순서 변경을 제품에 적용하지 않았다.
- 젖은 해안 2,562셀의 10월 24일 단독 Node 계측은 평균 405.3 ms/단계로,
  1× 목표 33.3 ms/단계에 미달했다. 이번 동시 부하 측정은 비교 기준이 아니다.
  이번 작업에서 이 성능 격차를 해결했다고 주장하지 않는다.
- 실제 브라우저의 기본 행성 생성, 모래 투입, 일시정지, 단면 진입을 점검했다.
  실행 환경은 WebGPU 초기화 시간 초과 후 WebGL로 전환됐다. 에뮬레이션은 실제
  휴대기기, 모든 GPU·브라우저, 장시간 사람의 플레이 경험을 대신하지 않는다.
- 기본 암석 표면에는 육각 명암이 보인다. `GAME_DESIGN.md`는 셀 구분을 드러내지
  않는 연속 표면을 지향하지만 `docs/DEVELOPMENT_KO.md`의 후속 기록은 육각 타일을
  기본으로 명시한다. 현재 렌더는 후속 설정을 사용한다. 시각 기준의 충돌을
  해결된 것으로 간주하지 않고 현 스타일을 유지한다.
- 격리된 headless Chrome WebGL/CPU에서 한·영 레이아웃, 터치·카메라·단면,
  인벤토리·대시보드와 테스트 저장 재개를 포함한 모바일 회귀 31건이 통과하고
  페이지 오류는 없었다. 320×568, 390×844, 667×375에서 단면 선택 패널과
  카메라 바·양쪽 패널 버튼의 겹침과 실제 터치 대상을 별도로 확인했다.
- 실제 관측 기후·극저온 물성·전 해상도의 장기 안정성과 창발 현상은 기존의
  명시된 미검증 범위다.
