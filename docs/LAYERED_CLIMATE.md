# 11층 습윤 대기 모델과 검증

2026-10-11. 현재 기본 대기는 11층·상단 42 km이며 부분 구름량을 계산한다. 새 장기 실행은 [CLIMATE_BENCHMARK_RESULTS.md](CLIMATE_BENCHMARK_RESULTS.md)를 따른다. 대류·복사 개선과 관측 검증 결과는 [CLIMATE_REFERENCE_VALIDATION.md](CLIMATE_REFERENCE_VALIDATION.md)에 기록한다. 이전의 공유 온도와 `지표 −12°C` 구름층을 대체한다. 구현은 `src/sim/layeredAtmosphere.ts`이며 CPU·WebGPU 지표 계산 뒤에 같은 대기 적분기를 사용한다.

## 계산하는 상태와 척도

지표 온도와 대기 11개 층의 온도를 독립적으로 저장한다. 각 대기층은 수증기·질소·메탄·CO₂·구름 액체·구름 얼음의 질량, 구면 접선 속도를 갖는다. 층 사이에는 부력에 의해 변하는 대류 질량 교환 속도가 있다. 기준 중심 높이는 0.5, 1.5, 3, 5.5, 8.5, 12, 16, 20, 25, 31, 38 km이며 중력 배율에 반비례해 늘어난다. 이는 11개 대표 저장층이고 연속적인 고도별 밀도장을 재구성한 결과가 아니다.

기존 물질 인벤토리를 보존하기 위해 명시적인 단위 변환을 사용한다.

- 인벤토리 기체 0.3 단위/기둥 = 기준 중력에서 101325 Pa의 기둥.
- 면적당 질량 변환은 `C = 101325 / (9.81 × 0.3)` kg/m²/인벤토리 단위.
- 대기 역학의 반경은 1000 km, 속도는 m/s, 게임 1초는 대기 물리 60초.
- 에너지는 기존 인벤토리 기준 kJ이며 SI 복사 플럭스는 `dt / (1000 C)`로 변환한다.

구면 격자의 기둥은 같은 대표 면적을 갖는 그래프 유한체적으로 취급한다. 실제 icosphere 쌍대 셀의 서로 다른 면적·모서리 길이를 적분한 비정형 유한체적 격자는 아니다. 지표 물질의 전도·유출·생태와 표층 해류에는 기존 모델이 남아 있다.

## 채택한 물리 관계

| 항목 | 구현 |
| --- | --- |
| 정역학 | 층 중심 기압은 `g × (상부 질량 + 해당 층 질량/2)`로 계산한다. 조성에 따른 기체 상수와 이상기체 포화 혼합비를 사용한다. |
| 수평 운동량 | 압력 경도, 정역학 두께의 온도 차에 대한 선형 보정, Coriolis 회전, 마찰. 압력 항은 `−RT ∇ln p`이고 온도 보정은 `∂z ln p = −g/(R Tv)`의 선형화다. 접선 최소제곱 경도 계산으로 오각형·불규칙 이웃 배치를 처리한다. |
| 운동량 수송 | 같은 경계 유량으로 물질·열·질량 가중 접선 운동량을 운반한다. 구면의 접선 벡터는 이웃으로 평행 이동한다. 혼합·마찰로 잃는 수평 운동에너지는 층의 열에 남긴다. |
| 부력 | 상승한 하층 공기의 가상 온도와 상층 가상 온도 차에서 `b = g(Tv_parcel − Tv_env)/Tv_env`를 계산한다. 수증기 조성과 응축물 하중을 반영한다. |
| 수직 교환 | 양의 부력으로 상승하는 공기와 하강 환경 공기의 건조 공기 질량을 같게 교환한다. 환경 공기·수분·엔탈피 혼합률은 `1−exp(−εΔz)`이며 잠열과 응축물 하중을 반영한다. `dw/dt = b − εw²`, `ε=2×10⁻⁴ m⁻¹`로 속도를 적분한다. 이 계수는 관측에 맞춰 교정한 값이 아니다. 순수 수증기 대기는 총질량 보상으로 전환한다. CAPE·상승류 면적을 예측하는 완전한 질량 플럭스 닫힘은 아니다. |
| 단열 변화 | 이동 물질은 잠열·현열·`gz`·수평 운동에너지를 운반한다. 위층에서 높아진 위치에너지 때문에 온도가 떨어진다. 부력 계산에도 위층 기압에서 포화 평형을 푼 상승 공기를 사용한다. 건조 한계는 `dT/dz = −g/cp`다. |
| 응결·재증발 | 저장된 각 층의 실제 온도와 기압에서 포화 평형을 풀고, 같은 층의 잠열을 포함한 에너지를 유지한다. 0°C 부근은 액체·얼음 혼합 평형이다. 과냉각 핵생성의 별도 미세물리 모델은 없다. |
| 지표 교환 | 지표와 경계층 간 현열·증발/승화 플럭스. 잠열 소비와 지표 냉각을 함께 반영한다. 희박 대기·진공에서는 Hertz–Knudsen 형태의 유한 플럭스와 0.01의 accommodation 계수를 사용한다. |
| 복사 | 원본 ecCKD 32×32 표로 기체 흡수를 계산하고 Mie 액체·Baum 얼음 광학을 사용한다. 장파는 광학 두께에 선형인 층 경계 Planck 방출, 단파는 보존되는 확산 2방향 근사와 반복 반사를 사용한다. 오존·N₂O는 처방한다. |
| 강수 | KK 자가변환·Kessler 수집·Lin 얼음→눈 전환으로 진단적 하강 플럭스를 계산하고 증발·승화·융해를 엔탈피와 함께 적분한다. 남은 작은 얼음은 30 µm Stokes 침강을 쓴다. 지표 도달량만 비·눈 진단에 집계한다. |

모델의 에너지 장부는 지표와 층별 `cp T + 상변화 기준 에너지 + gz + |u|²/2`를 합산한다. 기존의 모든 기체를 지표 온도로 평가하던 `totalEnthalpy(state)`는 층별 에너지 검증에 사용할 수 없다. `totalEnthalpy(state, climate)`를 사용한다. Float32 지표 쓰기와 상평형의 실제 반올림 차이는 수치 채널에 기록한다. 이 장부의 닫힘은 채택한 축약 모델의 보존 검증이며 완전한 압축성 대기의 에너지 방정식을 검증했다는 뜻은 아니다.

공기 수송은 최대 물리 1초와 수평·수직 CFL 조건을 함께 사용한다. 한 기둥에서 유출되는 비율이 0.45를 초과하면 계산을 중단하며, 유출량을 조용히 잘라 안정성을 꾸미지 않는다. 고속·강한 대류에서는 더 작은 소단계가 선택된다.

## 구름 분포와 표시

총수분의 균일한 subgrid PDF를 적분해 층별 면적률과 평균 응축량을
계산한다. 이어진 구름층은 maximum overlap, 맑은 층으로 나뉜 구름은
random overlap을 쓰며, 진단과 복사에 같은 하위기둥 마스크를 적용한다.
11층의 면적 적분은 최대 81개 마스크로 해당 가정에 대해 정확하다.
PDF 폭과 이 중첩 가정은 관측으로 검증된 전체 난류 모형은 아니다.


육지/바다나 태양 방향에 따른 구름 생성 마스크는 없다. 물 공급·증발, 수증기 이동, 층별 냉각과 상승, 포화, 침강이 분포를 결정한다. 조석 고정 행성에서 낮·밤의 구름량이 다르다는 사실만으로 오류라고 판정하지 않는다.

구름량 지도는 물 경로 kg/m²를 사용한다. 표시와 복사는 같은 변환 질량을 사용한다. 복사에는 대표 유효 반경 10 μm 액체·30 μm 얼음의 Mie/Baum 분광 표를 적용하지만 입경 분포 자체를 예측하지 않는다. 구름 표시와 단순 차폐 진단에는 대표 소광 계수 150 m²/kg와 `1/(1 + 0.075 τ)` 근사가 남아 있으며, 전체 복사 플럭스는 분광 대기 흡수와 층·지표의 반복 반사를 계산한다. 입체 구름은 기둥 합계를 표현한 스타일 렌더이고, 모든 대기층의 3차원 구름 모양·고도를 직접 그리는 볼륨 자료는 아니다.

관측 패널의 구름 온도·습도·고도는 응축물이 가장 많은 실제 층을 사용하고, 구름이 없으면 경계층을 보여준다. 지표 복사 평형 수치는 현재 층별 온도를 고정한 순간 평형이며 미래 기후 예측이 아니다.

## 저장과 실행 경로

기후 저장 버전 2에 층별 질량·온도·속도·대류 교환 속도를 저장한다. 이전 버전의 인벤토리와 바람을 층으로 열어 배분하고, 초기 성층과 위치/운동에너지에 필요한 에너지를 지표에서 이동한다. 새 질량이나 열을 공급하지 않는다. 따라서 이전 저장을 처음 실행할 때 지표 온도가 조금 조정될 수 있다. 이 변환을 실제로 존재하지 않았던 과거 수직 기후의 복원이라고 부르지 않는다.

공급·회수·낙하 중 물질을 저장할 때도 층별 상태와 지표 미러를 함께 갱신한다. 저장 검증은 층별 질량 합과 지표 기체/구름 미러의 일치까지 검사한다. 명령 없는 정지 상태는 초기 변환조차 실행하지 않는다. GPU를 사용해도 대기층 계산은 현재 CPU에서 실행하며, GPU와 다른 대기 수식을 쓰지 않는다.

가열 도구의 목표 온도와 운석 충돌은 지표 열용량을 사용하며 기체/구름 미러를 즉시 가열하지 않는다. 적분 실패 시 CPU·GPU는 마지막 완료 상태의 지표와 대기로 돌아간다. 화면을 장시간 막는 연속 계산을 줄이기 위해 기후 모드에서는 프레임당 한 물리 tick을 요청하고, 남은 시간은 기존 clock에 보존한다. 계산이 느리면 요청한 실시간 배속을 따라가지 못할 수 있다.

## 이전 5층 구현의 검증 증거

아래 브라우저 수치와 성능 기록은 대류·복사 계수를 교체하기 전의 검증이다. 현재 모델의 관측 대조와 새 물리 시험은 [후속 보고서](CLIMATE_REFERENCE_VALIDATION.md)를 따른다.

자동 시험: `tests/layered-atmosphere.test.ts`, `tests/layered-resolution.test.ts` 및 기존 기후·에너지·저장 시험.

- 건조 공기 1 km 상승: `cp=1004 J/(kg K)`에서 9.770916°C 냉각. 하강 시 복원되고 `cp T + gz`가 유지된다.
- 부력이 있는 성층에서 대류 증가, 역전층에서는 상승 교환 억제.
- 수평 운동량이 이웃 기둥으로 이동하며, 같은 초기 기둥 질량에서도 온도 차가 순환을 만든다.
- 물 없는 행성에는 구름이 생성되지 않고, 진공의 물은 유한 속도로 증발하며 지표를 냉각한다.
- 42개 셀·120단계 시험과 기본 해상도 2562개 셀·30단계 시험에서 탈출 포함 질량과 모델 에너지 장부가 닫힌다. 후자의 잔차는 질량 약 0.0000945 인벤토리 단위, 에너지 약 −1.21×10⁻⁸ kJ였다.
- 건조 대류의 1/60 → 1/120 → 1/240 게임초 시험에서 대기 온도 RMS 차이가 0.002136 → 0.001414°C로 줄었다. 이는 한 시험의 시간 수렴 증거이며 격자 해상도 수렴 증거는 아니다.
- 매끄러운 기압장의 해석해와 비교: 42 → 162 → 642 → 2562셀에서 압력 경도 가속의 상대 RMS 오차가 5.7477% → 2.0184% → 0.7246% → 0.2585%로 줄었다. 이는 해당 공간 연산자의 수렴이며 전체 기후의 공간 수렴 검증은 아니다.
- 642개 셀·30단계 브라우저 시험: 육지 18, 바다 14, 낮 14, 밤 18곳에 표시 문턱 이상의 구름. 계산과 렌더에 전달된 총 구름 질량 0.0004594594 일치, 평균 응축수 경로 0.02464 kg/m². 초기 습윤·건조 영역을 의도적으로 섞은 통제 시험이며 관측 지구 구름 지도와의 대조가 아니다. 별도의 균일한 습윤 42셀 시험도 육지·바다·낮·밤 모두 구름 생성을 확인했다.
- 실제 WebGPU 162개 셀·180단계 비교: 지표 온도 최대 차이 0.000458°C, 대기층 온도 0.00000200°C, 저장 후 CPU/GPU 전환 온도 0.000294°C. 에너지 상대 잔차는 CPU 6.23×10⁻¹², GPU 4.03×10⁻⁶이었다. 저장·JSON/IndexedDB 왕복도 정확히 일치했다.
- 구면/단면 × 10가지 지도에서 셀 색·단면 색·화살표 투영·셰이더 준비를 검사하고 물리 상태가 바뀌지 않음을 확인했다.

브라우저 실행 기록과 화면은 `artifacts/layered-climate/browser-validation.json`, `cloud-distribution.jpg`에 있다. 최종 자동 시험 수는 작업 완료 보고를 따른다. 기존 문서의 `T −12°C`, 단일 열 저장소, 정해진 낮→밤 바람에 대한 설명은 과거 구현의 기록이다. 기본 해상도의 습윤 1게임초를 계산하는 데 이 기기의 브라우저에서 약 1.34초, 테스트 런타임에서 약 2.3초가 걸렸다. 환경·초기 상태·워밍업에 따라 달라지며 실시간 성능 보장 수치가 아니다.

## 과학적 지위와 남은 작업

이 구현은 **정역학 관계·보존 수송·습윤 열역학에 기반한 축약 기후 모델**이다. 완전한 Navier–Stokes 또는 검증된 대순환모델(GCM)을 구현했다고 주장하지 않는다. 특히 수직 속도는 비정역학 운동량 방정식의 해가 아니라 부력 질량 플럭스 닫힘이고, 그 속도의 운동에너지는 별도 저장하지 않는다. 압력·고도는 대표 층의 축약 관계를 쓰며 연속 정역학/상태방정식과 완전히 결합된 이동 압력 좌표가 아니다. 지형에 의한 강제 상승도 아직 연결되지 않는다.

복사에는 지구형 대기를 대상으로 ecCKD 32×32 원본 분광 표를 사용한다. 기체 흡수와 장파 방출은 독립 Julia 코드와 대조했지만 단파 직접 광선 전달과 장파 구름 산란은 아직 축약되어 있다. 관측 자료 대조에서는 강수·구름 분포가 기준 자료와 맞지 않았다. 단파 직접 광선 복사·난류/경계층 교정·에어로졸·입자 크기 예측과 비·눈 예측변수·심해·외기권 탈출, Held–Suarez/Jablonowski–Williamson 전체 순환 검증, 전체 기후의 공간·수직 해상도 수렴 시험은 남아 있다. 그러므로 실제 행성 온도·강수량을 정량 예측하거나 모든 기후가 과학적으로 검증됐다고 표시하면 안 된다.

참고: [MITgcm 정역학 원시방정식과 열역학](https://mitgcm.readthedocs.io/en/latest/overview/hydro_prim_eqn.html), [NOAA 구름 생성과 단열 냉각](https://www.noaa.gov/jetstream/clouds/how-clouds-form), [ECMWF IFS 동역학과 수치 절차](https://www.ecmwf.int/sites/default/files/elibrary/112024/81625-ifs-documentation-cy49r1-part-iii-dynamics-and-numerical-procedures.pdf). 이 자료는 방정식의 근거이며 이 구현의 교정·성능·관측 일치를 인증하는 자료가 아니다.
