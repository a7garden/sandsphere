# 화성형 CO₂ 얼음·먼지 과정 검증

2026-10-13 · 0.7.0-alpha.3. 관측 화성 날씨를 예측하는 모델이 아닌,
공통 행성 정의의 `thin-co2-grey` 경로에 연결한 보존 과정이다.

## CO₂ 기체 ↔ 지표 얼음

최하층 CO₂의 몰분율과 대기 기둥 무게로 분압을 구한다. 지표 온도에서
포화 압력이 분압보다 낮으면 생성하고, 반대이면 기존 얼음을 승화한다.
포화 곡선은 일정 승화열의 Clausius–Clapeyron 식이다.

`P_sat(T) = 518500 × exp[−26300/R × (1/(T+273.15) − 1/216.58)] Pa`

삼중점 216.58K·5.185bar와 167K에서의 승화열 26.3kJ/mol은
[NIST WebBook](https://webbook.nist.gov/cgi/cbook.cgi?ID=C124389&Mask=4)에
근거한다. 고정 비열과 일정 잠열을 쓰는 저압 근사이며 액체 CO₂나 대기
CO₂ 구름은 계산하지 않는다. 교환 시정수 30초는 감도 입력이다.
교환량은 기체/얼음 재고와 포화 조건·온도 범위에 제한되며 이분법으로
상평형을 지나치지 않게 한다.

기체의 기준 상 에너지는 0, 고체는 −597.591456kJ/kg이다. 둘의 고정 비열은
0.85kJ/(kg·K)다. 생성 시 기체의 현열·위치·운동 에너지를 지표로 옮기며
상 에너지 감소가 잠열로 나타난다. 승화 시 지표가 현열과 상승 위치
에너지를 지불한다. 정지한 기체를 바람과 혼합하면서 운동량을 보존하고
감소한 운동 에너지를 열로 돌린다. 생성량과 기체 감소량은 같은 실제
Float32 표면 변화량을 사용한다.

서리 피복 `1−exp(−ice × COLUMN_KG)`로 표면 반사율을 0.65 쪽으로
혼합한다. 같은 피복을 물질 색에 사용하며 지형에는 고체 재고를 반영한다.

## 유한한 먼지의 발생·수송·침강·복사

지표 바람 응력은 `τ = ρ × 0.003 × U²`, 비산률은
`2×10⁻⁵ × max(0, τ−0.01) × exp(−iceCover)` kg/m²/s다. 지표 먼지를
먼저 사용하고 소진되면 모래를 사용한다. 초기 화성형의 약 0.003kg/셀
먼지도 모래의 실제 감소량에서 옮긴다. 기체·바람·가용 지표 재고가 없으면
먼지를 만들지 않는다. 얼음 피복은 비산을 억제한다.

반지름 1.5μm·밀도 2,500kg/m³의 단일 입자를 가정한다. 침강은 CO₂
기체의 고정 점도 10⁻⁵Pa·s와 Stokes–Cunningham 근사이며 극히 희박한
층의 종단 속도를 200m/s로 제한한다. 이 값들과 응력 임계값·비산률은
관측 자료로 교정한 매개변수가 아닌 공개된 감도 입력이다.

먼지는 별도 11층 Float64 질량 배열에 저장하지만 실제 대기 총 질량과
열용량·운동량에 포함한다. 기존 유한체적 대기 플럭스가 동일한 먼지와
엔탈피를 수평·수직 수송한다. 상승할 때 지표가 위치 에너지를 지불하고,
침강할 때 위치·운동 에너지를 열로 돌린다. 표면의 표현 정밀도보다 작은
비산 요구량을 누적하며, 표현할 수 없는 침강량은 대기에 남겨 질량을
잃지 않는다. 누적값 자체는 물질 재고가 아니다.

같은 먼지 질량으로 단파 소광 600m²/kg, 단일 산란 알베도 0.92,
비대칭 계수 0.65, 장파 흡수 30m²/kg을 적용한다. 두 방향 복사 전달의
흡수·산란으로 지표 햇빛 감소와 대기 가열을 계산하고, 기존 압력·바람
방정식이 열 변화에 반응한다. 강풍을 임의의 이벤트로 생성하지 않는다.
태양 가열과 먼지·바람의 결합 방향은
[NASA 먼지 순환 설명](https://www.nasa.gov/general/dust-cycle/) 및
[JPL 계절 먼지 폭풍 설명](https://www.jpl.nasa.gov/news/nasa-mars-orbiters-reveal-seasonal-dust-storm-pattern/)
을 참조했으며, 여기의 수치는 별도의 관측 적합 결과가 아니다.

지도는 `τ_dust = 600 × dustColumnKg/m²`를 표시하며 0–3 범위로 색을
매긴다. τ≥1을 폭풍 셀로 집계한다. 이 임계값은 앱의 관측 표시 기준이다.
대기 외곽의 먼지색·불투명도는 전체 평균 광학 깊이를 사용하는 시각화다.
지역별 부유 분포는 먼지 지도에서 확인한다. 물 구름·강수와 별도 상태다.

## 저장과 실행 경로

| 상태 | 새 형식 | 이전 형식 처리 |
|---|---|---|
| 행성 | Snapshot 6, 28 Float32 필드 | 1–5, 16/20/24필드는 원래 위치를 보존하며 0 확장 |
| 새 셀 필드 | 24 CO₂ 얼음, 25 지표 먼지, 26 대기 먼지, 27 예약 0 | 자동 재고 추가·모래 전환 없음 |
| 대기 | LayeredSnapshot 3 | 대기 1/2는 먼지 0, 기존 질량·온도·운동 유지 |
| 대기 먼지 상태 | 층별 질량·복사 캐시·소량 비산 누적값 | 저장·체크포인트·Worker 전송 포함 |
| 대시보드 / CSV | 얼음·지표 먼지·대기 먼지 지표 추가 | 이전 측정값 보존, 새 지표는 미관측 null |

GPU Cell은 7개의 vec4로 정렬한다. CPU와 GPU의 지표 커널은 대기 먼지
미러를 분리한 뒤 계산한다. CO₂와 먼지 대기는 두 경로 및 Worker가 같은
호스트 대기 코드를 사용한다. GPU의 수치 검증은 독립 대기 방정식 검증이
아니다. 지표 가열·물 상평형의 열용량에 대기 먼지를 중복 포함하지 않는다.

전체 셀 삭제는 기체·먼지의 11층 재고를 함께 제거한다. 단면 삭제는
CO₂ 얼음·지표 먼지만 포함하고 대기는 보존한다. 삭제와 저장 시 이관된
열은 명령 채널에 기록한다. 실패한 단계의 롤백에도 새 상태가 포함된다.
잘못된 먼지 배열·음수 재고·미러 불일치·예약 값은 저장 검증에서 거부한다.

## 검증 결과

`tests/mars-processes.test.ts`의 16개 시험은 생성·승화·분압·잠열, 유한한
비산·소량 누적·수송·침강·복사, 이전 저장, 정확한 재개·삭제·롤백·배경
계산을 검사한다. 기존 저장·대시보드·CSV·상 모델 회귀 검사도 실행했다.

42셀에서 −140/−60°C 지표와 100m/s 접선 바람을 지정한 결합 시험을
120×0.5행성분, 즉 한 물리 시간 실행했다. 바람 초기화는 명시적 에너지
입력으로 집계했고, 층 초기화의 반올림도 수치 채널에 포함했다.

| 항목 | 결과 |
|---|---|
| `M_final + M_escape − M_initial` | −8.07×10⁻¹⁰kg |
| `H_final − H_initial − Σ(Q환경+Q명령+Q탈출+Q수치)` | −7.78×10⁻⁹kJ |
| 최종 CO₂ 얼음 / 대기 먼지 | 0.034586kg / 0.000016543kg |
| JSON 저장 후 5단계 재개 | 지표와 전체 기후 상태 정확 일치 |

kg와 kJ는 시뮬레이션 재고·열 장부 단위다. 실제 행성 전체의 총량을
뜻하지 않는다. 고체/기체 전환과 수송만 따로 실행한 시험에서는 표면
반올림을 뺀 내부 에너지 변화가 10⁻⁸kJ 이내였다.

실제 브라우저 `/tests/mars-processes-lab.html`은 42셀·−140/−60°C·150m/s
시험을 30×0.1행성분 실행했다. CPU/Worker의 지표와 전체 기후는 정확히
일치했다. WebGPU 최대 상태 차이 0, 질량 잔차 −1.04×10⁻⁹kg,
에너지 장부 잔차 −0.04565kJ, GPU→CPU 재개 최대 상태 차이 0이었다.
GPU 장부는 Float32 연산 오차를 허용하며 에너지 허용값은 0.1kJ다.
저온 지표의 불필요한 현열 재나눗셈을 제거해 누적 온도 편차를 줄였다.

기존 `/tests/reaudit-lab.html`의 냉각·고온 제작·생태·약한 중력·완전 동결
각 300단계 및 정지 명령 1단계를 실제 WebGPU로 비교했다. 6개 경우 모두
CPU/GPU 상태가 유한하고 최종 저장 검증을 통과했다. 최대 온도 차이는
0.00278°C, 질량 상대 차이는 3.2×10⁻⁵, 탈출을 포함한 총 질량의 상대
차이는 1.2×10⁻⁷ 이내였다. GPU 에너지 장부의 최대 상대 잔차는
1.67×10⁻⁵였다. 새로운 지표 계산 방식의 기존 혼합 물질 회귀 검사다.

642셀의 같은 강풍·저온 조건을 3행성분 실행한 렌더 시험에서 CO₂ 얼음
0.3468kg, 대기 먼지 0.000040kg, 최대 광학 깊이 2.03을 확인했다.
실제 앱에서도 새 두 지도·관측 재고와 이전 화성 저장의 0 확장을 확인했다.
전체 테스트 **411개 통과, 조건부 18개 건너뜀**, 버전 검사·TypeScript·
Vite 빌드 통과. 계정 규칙과 장시간 과학 기준 시험 등 조건부 항목의
건너뜀을 통과로 계산하지 않았다.

## 남은 범위

입자 크기 분포·지표 응집력·먼지 악마, 실제 극관 재고·계절 주기·전 행성
폭풍 빈도 교정, 대기 CO₂ 구름·액체 CO₂, 지중 열 확산·압력 좌표는
포함하지 않는다. 통제된 시험의 강풍을 실제 화성 바람 재현으로 해석하지
않는다. 기존 대기 온도 범위를 벗어나는 단계는 실패·롤백하며 관측 자료로
교정하기 전 장기간 기후 수렴을 보장하지 않는다.
