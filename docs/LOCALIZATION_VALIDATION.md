# 한국어·영어 검수 — 0.5.0-alpha.6

2026-10-11, Chrome의 영어 기본 언어와 새 검수용 브라우저 저장소에서 확인했다. 실제 Firebase 로그인과 운영 계정 데이터는 사용하지 않았다.

## 수정한 문제

- MutationObserver가 동적 텍스트의 첫 값만 기억해 최신 관측값을 되돌리던 문제를 고쳤다. 번역기가 쓴 값과 화면 코드가 새로 쓴 값을 구분해 최신 원문을 유지한다.
- 문맥 번역도 접근성 속성을 처리하며, 대시보드의 전체/물질/생태는 인벤토리의 같은 한국어 문구와 구분한다.
- 도움말, 접근성 이름, 연구 출처, 구름·강수, 측정값, 수지식과 단위를 보완했다. 대기층 안내는 현재 11층과 일치하며 온실효과 안내도 기후 모델을 반영한다.
- 언어 전환 시 대시보드를 다시 만들고 자전·브러시·재생 이름·사용자 지정 입력 오류를 갱신한다. 한국어로 돌아갈 때도 선택한 상태를 유지한다.
- 저장한 언어를 우선하고, 저장값이 없으면 브라우저 언어 목록에서 처음 지원하는 언어를 선택한다.
- 행성 선택·항성계·대시보드·구름 비교의 사용자 이름에는 `translate="no"`를 적용한다. 행성 이름 `물`이 영어 화면에서도 그대로 남는 것을 확인했다.
- 긴 영어 재료 이름과 표시 레이어 버튼이 겹치지 않도록 줄바꿈·배치를 바꿨다.

## 자동 검증

`npm run test:i18n`은 실제 DOM 구현에서 동적 텍스트 변경, 신규 노드, 속성 변경, 문맥, 언어 우선순위·저장, 사용자 값 보존과 UI 어휘를 검증한다. 물질·연구·기후 지도·대시보드 측정값·탐사 과제의 이름과 설명에 한국어가 남지 않는지도 확인한다. 6개 통과.

전체 `npm test`는 326개 통과, 조건부 장기·외부 연결 테스트 17개 건너뜀. 기존 기후 정지 상태 검증의 정확한 0 비교는 측정된 약 1.9×10⁻¹⁶의 반올림 잔차를 허용하도록 10⁻¹² 미만 검사로 바꿨다. 기압 차이에 의한 바람과 접선 방향 검사는 유지했다.

`PATH="/opt/homebrew/opt/openjdk@21/bin:$PATH" npm run test:rules`는 Firestore·Storage 보안 규칙 테스트 5개 통과. `npm run check:version`과 `npm run build` 통과. 기존 번들 크기 경고는 남아 있다.

## 브라우저 검수 재현

```sh
npm run dev
node scripts/browser-localization.mjs
```

스크립트는 기존 과학 검수의 `artifacts/science/runtime/browser/node_modules/playwright-core`와 설치된 Chrome을 사용한다. 다른 환경에서는 `PLAYWRIGHT_MODULE`, `CHROME_PATH`, `LOCALIZATION_URL`로 경로와 서버 주소를 지정할 수 있다. 결과와 화면은 무시된 `artifacts/localization/`에 남긴다.

첫 실행과 모드 선택, 추천 행성 생성과 안내, 인벤토리 영어 검색, 언어 전환, 사용자 이름 보존, 대시보드 7개 분류, 연구·계정·알림, 항성계, 행성 조정, 단면 선택, 언어를 저장한 뒤 새로고침, 모바일 화면, 구름 비교를 실제 조작한다. 숨겨진 도움말과 접근성 속성도 검사한다. 한국어 언어 선택지와 의도적으로 보존한 사용자 이름은 번역 누락에서 제외한다. 브라우저 오류도 검사한다.

이 검수는 영어·한국어 UI와 언어 전환 범위다. 조건부 장기 기후 시험, 실제 계정 로그인·클라우드 업로드, 관측 기후와의 정량 일치, 운영 배포는 완료된 검증으로 간주하지 않는다. 이번 발행은 사전 릴리즈이며 운영 배포 워크플로는 실행하지 않는다.
