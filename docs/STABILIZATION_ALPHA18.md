# 공통 법칙 연결부 수정과 검증

2026-10-18. 0.7.0-alpha.18 개발 작업. 사용자 지정 gpt-6.1-sol / xhigh 서브에이전트로 구현과 독립 검토를 완료했다. 아래 결과는 최종 고정 코드로 검증한 범위이며, 모든 가능한 재료·규모·시간에서 무조건 안정하다는 보장은 아니다.

## 완료 조건

- 실행 가능한 재고를 저장 시 임의로 잘라내지 않는다. 실행·저장 지원 범위를 일치시키고 이전 유효 저장을 계속 읽는다.
- 극저온의 합산 대기 초기화는 유한 열·위치에너지에서 허용된 상태를 만든다. 온도 보정이나 설명 없는 에너지 공급을 쓰지 않는다.
- 증발·강수·침강은 질량·엔탈피·운동량을 운반하고 혼합 소산과 지표 반작용을 처리한다.
- 복사 캐시가 기체 조성 변화를 반영하며 저장·Worker·실패 롤백에서 일관된다.
- 관측·과제는 같은 완료 시점의 정본 재고를 읽고, 카메라 드래그가 계산 시계를 멈추거나 누적 시간을 버리지 않는다.
- 기존 최소 실패 재현을 정상 회귀로 전환하고, 질량·원소·에너지·필요한 운동량, 장시간 실행·JSON 재개, 실제 브라우저 재개와 카메라 조작을 검증한다. 기존 물리 허용치를 완화하지 않는다.

## 변경 계약과 모델 범위

저장 전용 100,000/200,000 질량 상한을 제거하고 유한한 Float32 표시가 가능한 Float64 재고를 실행·저장에 함께 적용한다. 표현할 수 없는 상태·진단 장부는 공급량이나 온도를 잘라 맞추지 않고 해당 단계 전체를 되돌린다. 깊은 대기의 기존 3,000 km 격자 지원 범위는 생성 전에 검사하며, 이전 저장의 유효한 실제 격자는 새 초기 프로필로 교체하지 않는다. 해결된 저장 제한과 모델 자체의 깊은 대기 지원 범위는 다르다.

일반 대기 저장은 v9다. 이전 v1–v8은 기존 높이 배율 1과 경계 충격량 0으로 읽고, 조성 정보가 없는 복사 캐시만 무효화한다. 극저온 합산 상태를 최초 층상 상태로 옮길 때 표준 초기 프로필의 에너지 지불 가능성을 먼저 확인한다. 부족하면 기존 열로 지불 가능한 격자 높이와 등온 초기 분포를 선택한다. 이 배율은 최초 격자 설정이며 실행 중 전체 온도를 보정하는 장치가 아니다. 물질량과 기존 총 에너지를 유지하고 위치에너지·기존 바람 운동에너지를 같은 예산에서 지불한다. 양의 높이에 배치할 에너지 자체가 없는 입력은 상태를 보존한 채 거절한다.

증발·승화·강수·입자 침강은 운반 질량의 엔탈피·위치에너지·운동량·운동에너지를 전달한다. 움직이는 물은 실제 해류 속도를 제공하고, 수면으로 들어온 물은 기존 물과 혼합한다. 혼합으로 잃는 운동에너지는 열로 남으며 고정 지표가 받은 운동량은 경계 충격량에 기록한다. 고정 지표 전체의 유한 관성이나 자전 변화를 새로 구현한 것은 아니다.

복사 캐시는 기체별 재고 변화도 검사한다. 새 흡수 기체가 들어오거나 마지막 계산 대비 어느 성분이 1%를 초과해 변하면 다시 계산한다. 기존 온도·구름·먼지 기준과 최대 300초 갱신 간격도 유지한다. 이는 성분 변화에 반응하는 명시적인 캐시 근사이며 모든 순간의 분광 계산과 동일하다는 주장은 아니다.

과제·재고·압력 관측은 완료된 상태의 정본 재고를 읽는다. 대용량 저장 스냅샷을 매 프레임 복제하지 않고 관측용 합계만 복사한다. 카메라 드래그는 화면 갱신 비용만 조절하며 활성·배경 행성의 계산 단계나 누적 시간, 궤도 표시의 실행 여부를 바꾸지 않는다. 사용자의 일시정지와 숨김 탭 정책은 그대로 별도 실행 조건이다.

극저온 혼합물의 후속 단계에서 추가로 발견한 경계 실패는 3.64e-12 kJ(해당 값의 Float64 1 ULP)였다. 열에 위치에너지를 더했다 다시 빼는 계산을 에너지 차이로 바꾸고, 중첩 반응의 허용 불가 시험 상태는 그 반응을 소유한 국소 변환이 더 작은 실제 반응량으로 재시도하도록 했다. 일반 프로그램 오류는 그대로 전달하며, 실제 시작 재고가 유효하지 않으면 단계 전체가 실패한다. 허용 오차 확대·온도 클램프·보충 열은 추가하지 않았다. 회귀 검사에는 중첩 재시도, 무변화 상태의 큰 위치에너지, 오류 전파를 포함한다.

장시간 추가 검사에서 두 경로를 더 수정했다. 첫째, 낮은 중력에서 표시용 바람이 Float32로 투영되며 생긴 `-0`을 일반 0으로 기록한다. JSON 왕복의 부호 없는 0과 같은 표현이며 실제 바람·운동량을 바꾸지 않는다. 둘째, 극저온 복사는 분광 표 아래에서 복사원이 온도에 선형 비례하던 외삽과 인터페이스의 인위적인 1 K 하한 때문에 미소한 열 재고를 과하게 내보냈다. 표 밖 저온 복사원은 표 경계의 분광 비중을 유지하는 T⁴ 근사로 바꾸고, 인터페이스 복사원 계산의 1 K 하한을 제거했다. 물질의 온도나 에너지를 올려 맞추는 보정은 하지 않는다. 표 밖의 실제 분광 스펙트럼·극저온 기체 상전이까지 재현한 것은 아니다. 이 후속 수정의 장시간 결과는 아래 최종 검증에 별도로 기록한다.

극저온 장시간 수송 검사에서는 해류가 물을 옮긴 뒤 열량을 복원하는 계산도 수정했다. 떠나는 물은 같은 온도의 열용량·상 에너지를 운반하고, 받는 곳은 유입 물과의 온도 차이 및 운동에너지 차이로 열을 갱신한다. 대기가 설치한 지표 열 인터페이스의 정본 열용량·상 에너지를 사용해, 큰 대기 표시 재고를 빼면서 생기는 상쇄 오차를 피한다. 실제 산술 오차는 수치 장부에 기록하며 Float32 표시 투영 오차와 중복 집계하지 않는다. 기체가 전혀 바뀌지 않은 지표 반응은 기존 대기의 온도를 다시 역산하지 않아 무변화 상태를 그대로 보존한다.

대기 이류도 같은 원칙으로 계산한다. 물질 재고가 열용량·상 에너지 기준값을 운반하고, 받는 층의 온도 변화는 유입 기체와의 온도 차이, 실제 높이 이동의 위치에너지 차이, 운동에너지 변화에서 계산한다. 등온 수평 수송이 큰 절대 엔탈피의 역산 때문에 냉각되지 않도록 했다. 기존 절대 에너지 수송값과 실제 결과의 차이는 수치 장부로 따로 측정한다.

질량이 고정된 복사·전도·운동량 교환은 실제 에너지 변화/열용량으로 온도를 갱신한다. 유출만 있는 대기층의 속도는 유지하고, 유입 혼합열은 질량 가중 상대속도 분산으로 계산해 큰 운동에너지끼리의 차감 오차를 피한다. 표시·연산의 해상도 아래 변화는 측정된 수치 오차로 구분한다.

물의 상평형 계산은 저장 검사와 같은 Float32 양의 켈빈 경계를 사용한다. 평형 근 찾기의 허용 오차가 열을 제공하지 않도록, 제안된 변환을 실제 재고 변화와 가용 현열로 다시 심사한다. 비용을 지불할 수 없는 변환은 그 국소 변환량만 줄인다. 온도·수치 허용치를 바꿔 성공시키는 방식은 사용하지 않는다. 압력 가속도 같은 현열 예산을 사용하며, 요구 운동에너지를 지불할 수 없으면 실제 압력 충격량의 적용 비율을 줄인다. 기존 속도를 임의 비율로 지우거나 열을 보충하지 않는다.

## 검사 해석

전체 검사를 한 번 실행한 뒤 실패를 수정한 이력도 보존한다. `npm-test-before-longrun-fixes.log`의 실패 5건은 표시 바람의 부호 있는 0 재개 차이, 세 개의 구버전 검사 데이터 구성/현재 버전 기대값, 실행 도중 구 코드가 이미 적재된 분광 검사였다. 구버전 검사에서는 실제 옛 저장에 존재하지 않았던 v9 전용 메타데이터를 제거해 원래 호환성 조건을 유지했다. 표 밖 분광원은 새 근사를 별도로 검사하며 기존 독립 기준의 표 범위 내 결과는 유지한다. 이 중간 실행을 최종 통과로 집계하지 않는다.
