# 펼친 국소 단면 검증 (2026-10-10)

기본 단면은 선택 지점 주변 셀을 가로로 펼친다. 관찰 범위는 약 6–36셀이다. 구면 격자의 평균 간격 기준이므로 실제 교차 셀 수는 방향과 띠 폭에 따라 달라진다. 회전은 실제 절단 방향을 바꾸고, 이동은 화면만 옮긴다. 고정 지형 기반과 편집 가능한 기반암은 표시·선택에서 숨긴다. 모래·토양 등 위에 쌓인 혼합물, 물·얼음·강수·구름·입자는 같은 시뮬레이션 패널에서 실시간 표시한다.

표시는 원통 좌표를 펼치고 기반 높이를 빼는 가역 변환이다. 물리 격자, 중력, 저장 상태는 원래 구면에 유지한다. 기반암 침식·열용량·재료량은 그대로 계산한다. 현재 셀의 혼합물을 보여주며 퇴적 순서에 따른 역사적 층을 생성하지 않는다. ShaderMaterial, GLSL StandardMaterial, 선, 인스턴스와 입자에 동일 변환을 적용한다. 체적 렌더의 깊이 광선은 물리 좌표로 역변환한다.

## 검증

- Vitest 29 파일, 186 테스트 통과. 기본 5초 제한에서 열 수렴 테스트가 한 번 초과해 `npm test -- --testTimeout=20000`으로 재검증했다. 모델 수치 실패는 없었다.
- `npm run build` 통과. 기존 번들 크기 경고는 남는다.
- WebGPU: 단면 선택 71/71, 회전 뒤 129/129. WebGL: 69/69, 회전 뒤 129/129. 화면상 최소 높이 3px 이상인 삼각형 중심만 명확한 포인터 대상으로 검사한다.
- 범위·회전·이동·구면 복귀·재진입 후 정지 상태, 전체 질량, 엔탈피 모두 정확히 동일하다. 기반과 범위 밖 선택은 거부한다. 공중 붓기는 구면 물리 좌표로 역변환한다.
- GPU 경계 20개 및 300스텝 혼합 실험/150스텝 저장 후 CPU↔GPU 재개 통과. 최대 기온 차이는 약 0.00214°C였다.
- 실제 게임 UI에서 모래·물 약 393.33kg 공급 후 입자가 모두 착지하고 질량 증가가 공급량과 일치했다. 정지 저장/페이지 재로드 후 셀 배열, 시간 238.999999999989초, 정지 상태가 정확히 유지됐다.
- 펼친 단면 강수 테스트: 비 564개 정점, 눈 762개 정점, 정지 유지·삭제·숨김 중 삭제·카메라 재진입 모두 통과.
- 실제 320/375/414/768px 뷰포트에서 가로 넘침 없음. 범위 슬라이더 높이 44px, 단면 컨트롤 표시 유지. 실제 모바일 하드웨어 입력은 이 검사에 포함되지 않는다.

증거: `artifacts/flat-section-product.png`, `flat-section-mobile-320.png`, `flat-section-responsive.json`, `flat-section-gpu-regressions.json`, `flat-section-save-precipitation.json`.

이 설계는 행성 내부의 3D 물리 해석을 추가하지 않는다. 기반암을 숨기면 처음부터 기반암만 있는 지점에는 기준선만 보이며 재료를 쌓으면 위의 실제 두께가 나타난다.
