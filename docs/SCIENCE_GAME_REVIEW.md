2026년 10월 10일 기준. 다음 개발의 중심은 재현 가능한 물질 실험과 실시간 단면 카메라다. 구면의 물질 기둥 모델은 유지하고, 시간·에너지·입력·관측의 규칙을 일치시킨다. 사용자 요구에 따라 단면은 같은 시뮬레이션 패널에서 연속 전환하며, 첫 출시부터 기존 파우더토이 렌더와 모든 도구를 실시간으로 지원한다. 수치 그래프는 보조 관측 기능이다.

현재 기능은 행성 생성, 물질 공급, 광물 변환, 물 순환, 생물량 먹이망, 회수와 공유 보관함, 탐사 과제까지 연결되어 있다. 게임의 주요 부족함은 재료 개수보다 결과를 재현하고 배치의 효과를 이해하며 실패에서 복구하는 능력에 있다.

전체 구현 전 셀의 모든 이동·반응 조건을 다시 확인한 [셀 상태 변화 감사](CELL_STATE_SCIENCE_AUDIT.md)를 추가했다. 신규 점토의 소성 이력 상속, 염수 열 잔차, 증발 경계와 강수 착지 상의 불일치를 재현했고, 이동의 잠열 전달·기체 탈출의 평균 엔탈피 제거는 기존 방식에서도 보존 가능함을 확인했다. 다음 구현의 물리 계약은 이 후속 검토를 함께 따른다.

P1은 공통 규칙의 일관성, P2는 실험 기능과 플레이 깊이, P3는 모델의 적용 범위다. 아래의 현상 확인과 구현 제안은 구분한다. 수치 실험은 CPU 경로이며 일반 플레이의 발생 빈도를 측정한 자료는 아니다.

## 재현 근거

`node design/reproduce-audit.mjs`는 현재 소스에서 이전의 진단을 다시 실행하고 소스 해시와 조건을 기록한다. `design/audit-evidence.json`은 실행 결과다. 열 반응 실험의 높은 ambient 값은 외부 열교환을 제거하기 위한 solver 수준의 격리 조건이며, 행성 생성 UI의 입력 범위를 나타내지 않는다. kg은 현재 게임 물질량 단위다.

마지막 검증에서 자동 테스트 67개가 모두 통과했고 앱 빌드도 성공했다. 기존 구름 테스트에는 물의 일부 상변화 에너지 검증이 있다. 열 검증이 전혀 없다는 표현은 부정확하다. 추가로 필요한 것은 광물 반응, 염수 상변화, 외부 공급·회수, 여러 시간 간격, CPU와 WGSL의 공통 기준 검증이다.

현재 강수 지역 레이어는 비·눈이 발생한 셀을 구별해 보여주며 표시가 solver 데이터를 바꾸지 않는 테스트가 있다. 원인 관측의 확장은 이 기능을 포함한다. 단면에서도 같은 커밋의 `precipitatedCells`와 해당 dt를 읽어 kg/단계와 kg/게임초를 구별해야 한다. 위치 표시가 곧 유량이나 강수 강도의 검증을 뜻하지는 않는다.

## 단면 설계에서 추가로 드러난 문제

### 형상과 낙하 접촉

`PlanetView.update()`는 얼음 기여를 뺀 높이와 토양의 보유수를 제외한 수심으로 표시 지형을 만들고, 해안을 보정한 뒤 로그 함수로 높이를 압축한다. 낙하 입자도 이 표시 높이를 접촉 판정에 사용한다. 현재 표시는 장식만으로 물리와 완전히 분리된 구조가 아니다.

단면은 `solidHeight()`와 원래 셀량에서 읽는다. 표시용 보간·해안 보정·로그 압축으로 단면 수치를 만들지 않는다. 물리 접촉 높이도 계산 경계에서 정의하고, 보간된 시각 형상과의 차이는 투영으로 처리한다. 현재는 얼음이 유출을 위한 고체 높이에 포함되고 표시에서는 물과 함께 표현된다. 부유 해빙과 지지 얼음층을 구별하지 않으므로 단면에 부유 얼음판을 임의로 그리지 않는다.

### 저장 중 낙하 물질

`snapshotSurface()`는 낙하 입자의 질량을 현재 대응 셀에 합쳐 저장한다. 질량은 보존하지만 위치·속도·향후 착지 경로는 보존하지 않는다. 정밀한 체크포인트와 재현 기능은 ‘질량이 이어진다’보다 강한 조건이 필요하다.

체크포인트는 낙하 위치·속도·난수 상태·명령 순서를 저장한다. 구형과 단면은 하나의 체크포인트를 공유한다. 이전 형식의 저장은 이미 합쳐진 표면 상태로 읽으며 과거의 입자 궤적을 복원했다고 표시하지 않는다.

### 관측량의 의미

현재 온도는 지표·기체·구름을 포함한 한 열기둥의 대표 온도다. 구름 상층의 온도는 이 값에서 12°C를 뺀 근사다. 단면에 깊이에 따라 달라지는 지하 온도 색을 그리면 없는 상태 변수를 만들어 보이는 셈이다. 물질의 층 순서, 지하 공동, 맨틀, 핵도 저장되지 않는다.

단면에서는 같은 셀의 물질 기둥을 현재 재질·조성과 온도로 렌더하고 물·입자·구름·비·눈·생태 효과도 계속 보여준다. 조성과 온도의 그래프·목록은 보조 관측이다. 현재 없는 층 순서와 깊이별 온도를 만드는 대신 혼합 물질과 대표 온도로 표현한다. 실제 내부 물리·지층은 체적·층 순서 모델을 추가하는 개발 범위다.

### 카메라 전환이 요구하는 렌더 계약

현재 지형·물·대기·구름은 custom shader 경로, 낙하·비·눈·증기·생태는 메시·인스턴스·입자 경로로 나뉜다. 화면을 바꾸는 카메라만 추가하면 표면 내부가 비어 보이고, 원근 시선으로 계산한 대기·구름이 직교 시선에서 어긋날 수 있다. 절단 면 생성과 모든 레이어의 공통 clip·시선 계산이 필요하다.

`PlanetView.emit()`는 공급 접선에 camera.upVector를 사용한다. 공급 위치·속도는 명령 생성 시 로컬 좌표로 확정하고, 전환이 낙하 상태를 바꾸지 않게 해야 한다. 상세 렌더 연결과 검증 장면은 [단면 카메라 렌더 명세](SECTION_CAMERA_RENDERING.md)에 정의한다.

| E=C T+Σ m ell | 공통 에너지 장부 | 기준 온도·물질별 기준 엔탈피·반응 교환을 명시. |
| 포화 증기압과 압력별 끓는점 | 물의 상 안정성 | 게임 압력을 Pa로 대응하는 보정, 대표 공기 부피, 상태표의 적용 범위를 함께 정의. |
| 복사 방출∝T_K⁴ | 거리·반사율·대기의 기후 효과 | 게임 시간 보정은 모든 열 교환에 일관되게 적용. 기존 kg을 실제 행성의 면적당 질량으로 소급 해석하지 않음. |

물의 상태 경계는 [IAPWS 포화 물성](https://iapws.org/technical-guidance/release/Supp-sat)과 [NIST 물 열역학 자료](https://www.nist.gov/publications/thermodynamic-properties-water-tabulation-iapws-formulation-1995-thermodynamic)를 기준으로 한다. 복사 가열·냉각과 온실효과의 현상 방향은 [NASA 에너지 수지](https://science.nasa.gov/earth/earth-observatory/climate-and-earths-energy-budget/)를 참고한다. 이 근거는 게임 반응 시간, 토양 영양분량, 용융 이동률의 보정값을 검증해 주지 않는다.

## 게임으로서의 설계 목표

플레이어는 ‘조건 설정 → 물질 배치 → 변화 관측 → 원인 확인 → 복원 또는 재배치’를 반복한다. 단면은 관측을 쉽게 하고 다음 행동의 근거를 제공한다. 첫 번째 실험은 둑 양쪽의 수두와 유출, 두 번째는 젖은 모래의 안정성, 세 번째는 점토 소성의 열 이력, 네 번째는 식생과 토양 보유수로 구성한다.

기본 공급과 가열 도구를 무제한으로 유지한다. 자유 실험에 자원 부족을 강제하지 않는다. 제작물의 의미는 수량 희소성보다 성질의 차이에서 얻는다. 한 셀의 대표 온도 모델에서도 운철의 빠른 열전도, 도자기의 낮은 열전도, 유리의 재용융과 온도에 따른 점성 변화는 비교할 수 있다. 유리 덮개의 광투과와 온실 기능은 덮개 위치·포개기 상태를 추가한 뒤 구현한다.

즉시 종료 조건이나 별도 스토리 캠페인을 추가하지 않는다. 탐사 과제는 원인과 결과를 익히는 선택적 안내이며 총량 달성뿐 아니라 해당 과정이 실제로 일어났는지 확인한다. 기존에 완료한 과제를 취소하지 않는다.

## 개발 순서와 완료 기준

| 단계 | 결과 | 완료 기준 |
| --- | --- | --- |
| D0 이번 설계 | 감사 재판정, 실시간 카메라·렌더·도구·계산 계약 | 같은 패널·같은 상태·모든 렌더 경로를 명시. 이전 그래프 시안은 수치 자료로 보존. |
| D1 공통 진행 | 시계·명령·입자·저장 커밋 경계, 한 단계 진행 | 같은 명령열·게임 시간에서 활성 전환과 1/2/4배속이 허용 오차 내 같은 결과. 정지 시 입력 없는 상태 불변. |
| D2 실시간 단면 | 연속 카메라·절단 면·모든 기존 렌더와 도구·셀 관측 | 같은 canvas에서 공급 입자·반응·기후·생태가 이어지고 입력 가능. 반복 전환으로 state·착지·재고 불변. 모든 레이어 검증. |
| D3 열과 이동 | 엔탈피 장부, 점성 용융, 재용융, 열전도 역할 | 반응과 이동의 내부 질량·에너지 잔차 검사. CPU/WGSL 비교. |
| D4 복원과 반복 실험 | 항성계 체크포인트·실험 슬롯 | 재고·보상·낙하 질량을 함께 복원. 복원 전후 난수·착지·진행 재현. 단면 편집은 이미 D2 범위. |
| D5 환경과 진행 | 압력 상변화, 복사 수지, 생태 제약, 과제 사건 | 각 변경은 독립 실험·기존 저장 호환성·원인 표시와 함께 도입. |

실시간 단면 D2는 D1 이후 첫 사용자 기능으로 둔다. 첫 출시에서 현재 렌더와 도구를 전부 지원한다. 열 이동 화살표는 진단이 준비된 뒤 더하며 압력·온실효과·행성 내부 확장은 D2의 선행 조건으로 두지 않는다.
