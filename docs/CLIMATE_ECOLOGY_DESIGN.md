# 기후와 선구 식생: 과학 근거·게임 모델 (2026-10-10)

2026-10-11 후속: 현재 대기는 지표와 5개 대기층을 분리합니다. 아래 단일 열기둥·고정 구름 온도 설명은 이전 구현의 기록입니다. 현재 방정식·검증·한계는 [5층 기후 모델](LAYERED_CLIMATE.md)을 따릅니다.

## 구현 범위

기본 게임 행성은 이제 복사 에너지 수지, 지속되는 기류·표층 해류, 기압과 습도, 이류하는 구름과 수증기, 수렴·지형 상승에 따른 응결을 계산한다. 관찰 지도에서 기온, 기압, 기류, 해류, 습도, 기단, 구름량, 식생용 수분, 씨앗을 선택한다. 구면과 펼친 단면은 같은 셀 상태와 속도를 표시한다. 기후 지도와 화살표는 시뮬레이션 상태를 바꾸지 않는다. 이후 연결 감사와 관측 보완은 [완성 검증](CLIMATE_SYSTEM_COMPLETION.md)에 기록했다.

기존 24개 셀 슬롯 가운데 예약 슬롯 23을 휴면 씨앗 질량에 사용한다. 전체 질량과 열용량, 붓기·깎기 장부에 씨앗을 포함한다. 추가 저장 상태는 기류 3성분, 해류 3성분, 씨앗 분포 지수다. 새 저장은 Snapshot 4이며 이전 16/20/24필드 저장을 읽는다. 기존 물질을 변환하거나 자동으로 생명을 부여하지 않는다. 과거 열욕조 모델은 기후 플래그 없는 물리 경계 실험의 비교 기준으로 남는다. 실제 게임은 기후를 켠다.

## 조사한 근거와 채택 판단

- [NASA 에너지 수지](https://science.nasa.gov/earth/earth-observatory/climate-and-earths-energy-budget/): 입사 태양 에너지와 적외선 방출의 차이가 열 저장량을 바꾸며, 물의 열용량은 반응을 늦춘다. 반사율·구름 차폐·네제곱 방출을 사용한다. 위성으로 보정한 지구 기후 모형은 아니다.
- [NOAA 바람의 원인](https://www.noaa.gov/jetstream/synoptic/origin-of-wind), [코리올리 효과](https://oceanservice.noaa.gov/education/tutorial_currents/04currents1.html): 기압차에 따른 가속, 회전에 의한 편향, 마찰에 따른 감쇠를 사용한다.
- [MIT 회전 얕은 유체 모형](https://ocw.mit.edu/courses/res-12-001-topics-in-fluid-dynamics-fall-2024/pages/essay-3-a-coriolis-tutorial/): 단일 유체층과 접선 속도로 규모를 줄인다. 실제 얕은 물 방정식 전체를 푸는 구현이라고 주장하지 않는다.
- [NOAA 해류](https://oceanexplorer.noaa.gov/ocean-fact/currents/): 바람·높이·온도·염분 차이를 표층 흐름에 연결한다. 깊이에 따른 밀도 분포와 심해의 열염 순환은 제외한다.
- [NOAA 기단](https://www.noaa.gov/jetstream/synoptic/air-masses): 온도와 습도가 비슷한 공기 영역을 기단으로 분류한다. 네 가지 색은 현재 상태의 진단이며, 정해진 지리적 구역이나 별도 물질이 아니다.
- [USDA sand dropseed](https://research.fs.usda.gov/feis/species-reviews/spocry): 모래에서도 정착하는 식생, 씨앗 저장과 바람 분산, 수분·온도에 따른 발아를 근거로 유기물 필수 조건을 없앤다.
- [FAO 모래 토양 관리](https://www.fao.org/4/ag125e/AG125E23.htm): 유기물과 점토는 보수력·양분 가용성을 개선한다. 모래 전체를 유기물로 교체하는 규칙 대신, 기본 선구 식생 생산성과 유기물에 따른 개선을 사용한다.

## 수식과 수치 처리

### 열

각 셀의 공유 엔탈피는 `H = C T + Σ(m L)`이다. 기체·지표·구름이 같은 열 저장층을 쓰며 별도 2m 기온이나 대기 수직 온도장을 만들지 않는다. 기온 지도 범례에 이 한계를 표시한다.

`C (T_new − T_old) = Δt A_game [1361 S μ (1−α) transmission − σ (T_new+273.15)^4 / (1+0.75 τ)]`

`S`는 궤도 거리의 역제곱, `μ`는 낮면 태양 입사각, `α`는 현재 재질의 반사율이다. `σ=5.670374419×10⁻⁸`이다. `A_game=.004`는 시간·에너지 보정 계수다. 암시적 방출항을 단조 이분법으로 풀어 고온에서도 명시적 냉각 폭주를 막는다. 복사에 의한 에너지는 외부 열 장부에 기록한다. Float32 전환 오차는 수치 장부에 기록한다.

회색 대기 광학 깊이는 CO₂·수증기·메탄의 `log(1+m/m_ref)`와 구름량으로 근사한다. CO₂ 참조량 `.003 kg/셀`과 계수는 게임 보정값이며 실제 ppm별 복사 강제력을 예측하지 않는다. 질소 자체를 강한 온실 기체로 취급하지 않는다. 압력 넓어짐, 복사 스펙트럼, 화학·산소 순환은 제외한다.

### 기압과 기류

지표 기압은 기존 수문 모델과 동일한 `p = (m_gas/.3) g ×101325 Pa`이다. 셀을 같은 대표 체적의 기둥으로 취급하므로 구면 격자 면적의 작은 차이는 계산하지 않는다.

수평 가속에는 `−k ∇[ln p + .003 T]`, 마찰 `−r u`를 쓴다. 온도항은 해석하지 않는 수직 열팽창과 두께 차이의 폐쇄 관계다. 이 항을 지표 기압이라고 표시하지 않는다. 압력이 같은 초기 행성도 가열 차이로 순환을 시작할 수 있다. 3차원 대류·정역학 원시 방정식, 예측 가능한 해들리 셀·제트기류를 구현한 것은 아니다.

코리올리 매개변수는 `f=2 Ω sin(latitude)`. 법선 주위의 정확한 회전으로 속도 크기를 보존한다. 속도를 접선 평면으로 투영하고 최대 기류 `.12 rad/게임초`, 해류 `.035 rad/게임초`로 제한한다. 마찰과 제한은 운동 에너지를 열로 되돌리지 않는다. 따라서 이 구현은 물질·엔탈피 장부를 가진 감쇠된 흐름 모형이며 총 운동 에너지 보존 솔버가 아니다.

### 해류와 수송

해류 가속은 바람 응력, 표면 수두 차이, 선형 온도·염분 밀도 차이, 회전·마찰로 근사한다. 연결된 양쪽 셀의 자유 표층수가 `.2kg` 이상일 때만 흐른다. 유기물에 붙잡힌 모세관 수분과 그에 비례하는 용질은 표층 수송에서 남겨둔다. 기존 중력 유출과 새 해류의 이류는 서로 다른 항이며 같은 물을 중복 생성하지 않는다.

공유 경계의 평균 접선 속도와 각거리에서 upwind 흐름 비율을 계산한다. 각 출발 셀의 총 유출을 한 소단계에 최대 25%로 제한한다. 같은 경계에서 빼고 더하는 질량은 동일하며, 출발 재료의 `c_p T+L`을 함께 옮긴다. 기류는 기체·수증기·구름과 일부 씨앗을 운반한다. 해류는 물과 용존 염분을 운반한다. 격자 경계에는 극·경도 이음새가 없다.

기류·해류 속도는 독립적인 감쇠 상태다. 이류에 따른 운동량 보존, 에크만 수직 구조, 해저 마찰층과 깊은 해류는 풀지 않는다. 화면 속도는 평균 셀 간격에 따른 약 `셀/게임초`로 표시한다.

### 구름·강수·기단

바람 수렴과 `u·∇terrain`에서 상승 지수를 구한다. 응결용 공기 온도는 `T−12°C−clamp(60 lift,−8,12)`. 고정된 12°C 차와 상승 보정은 대기 수직 해석을 대신하는 게임 폐쇄 관계이며 보정 계수를 실제 단열감률로 해석하지 않는다. 상승은 응결을, 하강은 구름 증발을 바꾼다. 포화량 계산은 기존 IAPWS/Murphy–Koop 수증기 압력식과 기체 조성을 사용한다.

수증기↔물방울↔구름 얼음 전환은 선언한 잠열과 총 엔탈피를 보존한다. 강수는 기존 축적 임계와 유한 속도를 사용하고, 낙하 중 재증발과 지표의 물·얼음 평형을 유지한다. 새로 형성된 구름은 다음 물리 소단계부터 강수에 참여한다. 구름 덩어리의 중심은 실제 물방울·얼음 질량의 가중 중심을 따라 변한다. 화면 장식만 임의로 움직이지 않는다.

기단은 현재 온도 15°C와 구름층 상대습도 60%를 기준으로 차고/따뜻하고 건조/습한 네 상태를 구분한다. 경계는 상태가 수송되면서 변한다. 전선 기상학이나 종관 일기예보는 아니다.

## 식생·유기물

씨앗이 있는 행성을 생성하면 휴면 씨앗 `.08kg/셀`과 탄소원 `.003kg/셀`을 초기 질량에 포함한다. 기존 무생명 행성에는 이를 자동 추가하지 않는다. 사용자가 도입한 식생은 씨앗을 생산하고 이웃과 바람을 통해 분산한다. 씨앗 질량은 발아로 식생으로, 쇠퇴로 유기물로 이동한다. 모든 씨앗과 식생을 제거하면 씨앗 분포 지수도 사라져 생명이 저절로 재생되지 않는다.

정착은 모래·점토·유기물 기질과 액체 수분·빛·온도·낮은 염분 조건에 따르며 유기물 양이 0이어도 가능하다. 유기물은 생산성을 높이고 기존 모세관 보수력을 제공한다. 모래의 기본 양분 가용성은 0.25라는 넓은 선구 식생 계수로 근사한다. 질소·인·미생물·종별 뿌리 구조는 풀지 않는다.

탄소원과 재활용 유기물은 게임의 생물량 자원으로 1:1 질량 이동한다. 실제 광합성의 CO₂·물·산소 화학양론과 건조 생물량 관계를 재현하지 않는다. 이를 화학적으로 닫힌 탄소 순환이라고 부르지 않는다. 다만 게임 자원 질량과 선언한 열 장부는 보존한다. 식생·초식·포식 생물의 먹이망과 불리한 환경에서의 쇠퇴는 기존 규칙을 유지한다.

## CPU/GPU·저장

기본 재료·중력 유출·상변화는 기존 CPU/WGSL 경로를 유지한다. 기후·씨앗 결합은 두 솔버가 같은 TypeScript 함수를 각 물리 소단계 뒤 실행한다. GPU 결과를 읽은 뒤 결합된 셀을 다음 GPU 입력 버퍼에 다시 기록한다. 기후를 별도 GPU 물리로 중복 구현하지 않아 분기 회귀를 줄인다. GPU 실패 시 셀과 속도·씨앗 지수를 함께 마지막 완료 상태로 되돌린다.

활성 행성·배경 행성 모두 같은 소단계를 사용한다. 저장은 셀 배열과 속도·씨앗 지수를 함께 보존한다. 정지 중 관찰 지도·카메라 변경은 이를 갱신하지 않는다. 폐쇄된 앱의 실제 경과 시간을 임의로 따라잡지 않는다.
