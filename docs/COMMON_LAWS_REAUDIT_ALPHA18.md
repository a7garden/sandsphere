# Alpha.18 공통 법칙 재감사

2026-10-19. 대상은 0.7.0-alpha.18의 현재 작업 트리다. 구현을 바꾸지 않고 공통 법칙 위반과 장시간 안정성 문제를 점검한다. 구형 파우더 토이의 재료·열·흐름 조합을 기준으로 삼고, 실제로 재현한 결함·명시된 모델 근사·미검증 영역을 구분한다.

## 판정 계약

- 유효한 시작 상태와 지원 조건에서 생산 모듈을 실행한다. 의도적으로 잘못된 상태의 거절은 결함으로 분류하지 않는다.
- 질량·원소·물리 에너지 출입·수치 장부를 각각 기록한다. 재고 보정이나 허용치 확대 없이 기존 기준과 비교한다.
- 무변화·평형·유한 반응물·이동 방향·후속 반응의 연결을 보존 수지와 함께 확인한다.
- 장시간·저장 재개는 같은 초기 상태의 연속 실행과 비교하고, 소스 해시로 검사 대상을 고정한다.
- 발견에는 최소 재현·실제 수치·절대 파일 위치·실행 명령을 남긴다. 발견하지 못한 범위를 완전 안정으로 일반화하지 않는다.
- 완료 조건은 네 영역의 독립 감사와 주 에이전트 확인, 필요한 집중 재현 및 결과 문서다. 이번 요청에서는 생산 동작을 바꾸지 않는다.

## 낮은 우선순위의 추가 확인

- **T2 / P3, 거친 격자의 운석 누락:** `meteor.ts:27–35`의 충돌 각도 안에 셀이 없으면 36 kg 운석이 실제로는 0 kg 들어오고 외부 +64800과 수치 −64800만 기록된다. `createSphere(0)`, 방향 `[1,0,0]`에서 재현된다. 현재 앱은 `createSphere(4)`를 사용하므로 일반 앱의 충돌 누락으로 일반화하지 않는다. 근거: `tools/meteor-footprint.json`.
- **A5 / P3, 미소 재고의 무변화 온도 재설정:** N₂=10⁻²⁰ kg의 영 수송 커밋에서 20°C→0°C, 열 변화 −2.08×10⁻¹⁹가 수치 장부에 기록된다. 재고는 보존되지만 작은 열용량을 빈 셀로 취급하는 경로가 유한 재고의 온도를 바꾼다. 모델의 명시적인 최소 해상도 계약이 필요하다. 근거: `air/probes.json`의 `trace-zero-flux`.

## 통과한 범위와 검증 해석

- 기존 생산 법칙 회귀 6개 파일 **81/81 통과**: 공통 법칙, 생태 화학, 연소 상승기류, 연기, 해류 에너지, 국소 역학 경계. 일사 제거 대조군과 재료·후속 반응 연결을 포함한다. 명령: `npx vitest run tests/common-laws.test.ts tests/ecochemical-laws.test.ts tests/plume-laws.test.ts tests/smoke-laws.test.ts tests/ocean-energy.test.ts tests/mechanical-boundary.test.ts --maxWorkers=2 --testTimeout=20000`. 첫 실행은 저장소 기본값과 다른 Vitest 5초 기본 제한으로 시간 초과했으며, 저장소의 원래 20초 설정으로 재실행했다. 물리 허용치는 바꾸지 않았다.
- 지표의 등록 반응 32경로에서 유한 반응량·원소 수지를 확인했다. 보통 혼합 재료의 단순/층상 600단계와 네 번 저장 체크포인트 이후 상태·기후가 일치했다. 단일 수로의 방향·질량·운동량·열 수지도 통과했다.
- 깊은 대기의 물 10% 조성과 뜨거운 순수 헬륨 각각 1500단계·5회 정확한 JSON 재개가 통과했다. 72개 기체/응결물 재고·온도 조합, 침강 에너지/운동량, 실제 시간 간격 축소, 프리셋 이름만 다른 같은 상태의 진화도 통과했다.
- 통제된 메시지 전달과 생산 CPU로 실행한 Worker 경로 12단계에서 정본 상태·기후·에너지 장부가 정확히 일치했다. 카메라 홀드, 저장 프리뷰의 비변이, JSON 재개와 중력 편집의 외부 일도 확인했다. 브라우저의 실제 Worker 스케줄링·GPU 하드웨어 검증으로 일반화하지 않는다.
- 주 에이전트는 순수 수증기 엔탈피, 극저온 결합값, 운석 두 조건을 직접 생산 함수로 재현했다. 정답 불변식을 검사하는 `tools.log`의 4건 실패는 확인된 미수정 결함이다. 일부 서브에이전트의 진단 검사는 **현재 결함이 재현되는지**를 양성 검사해 통과하므로, 진단 검사의 통과 수를 제품 결함 0건으로 읽지 않는다.

## 명시된 한계·미확인 사항

- 정확한 수치 최저 온도의 합산 기체 상태는 저장 검사에 통과하지만 대기를 높이에 배치할 열이 없어 초기화가 거절될 수 있다. Alpha.18에서 이미 명시한 모델 한계다. 이번에 +10⁶ 가열 명령도 초기화보다 나중에 적용되어 거절됨을 확인했다. 새로 숨겨진 결함으로 집계하지 않는다.
- 반경 1000 m의 습한 깊은 대기는 29단계 뒤 명시된 −250°C 적용 범위를 벗어났다. 그전 수지와 저장 재개는 유효했고, 유한 온도 범위를 영원히 유지한다고 검증하지 않았다.
- `main.ts:354`의 궤도/자전/낙하 입력 선반영과 `:416`의 비동기 계산 중 저장 조합에는 정적 검토상 우려가 있다. 실제 앱의 수명주기/실패 주입 재현을 수행하지 않아 **미확인**으로 남긴다. 확인된 오프라인 E2와 혼동하지 않는다.
- 깊은 대기의 전체 각운동량·압력/Coriolis 반작용, 모든 해상도의 공간 수렴, 임의의 장시간 창발 무늬, 실제 행성 관측 정확도는 이번 검사로 증명하지 않는다. 핵반응·플라스마·자기장·자기중력은 기존 미구현 범위다.

## 수정 순서 제안

1. A1 순수 물질의 상평형과 A2/A3의 극저온 수송·상평형 허용을 먼저 바로잡는다. 반응·온도 결과를 사후 보정하지 않고 상 공존 구간과 실제 유한 교환량을 다룬다.
2. A4 탈출·E1 관측의 남은 1 K 가정을 실제 정본 온도/명시된 모델 범위와 일치시킨다.
3. D1 생성·실행·저장 범위를 통일하고 D2 분배에서 없는 원소가 생기지 않도록 정확한 재고 분할을 사용한다.
4. T1 운석에 정본 열용량을 연결하고 E2 실패의 시간/궤도 커밋을 원자화한다. T2/A5는 격자/최소 수치 해상도 계약과 함께 정리한다.

이 순서는 재료를 자유롭게 조합하는 구형 파우더 토이의 기본 동작을 우선한다. 이번 감사는 결함 수정 작업이 아니며, 위 미수정 재현과 그 근거를 다음 구현의 수용 조건으로 남긴다.
