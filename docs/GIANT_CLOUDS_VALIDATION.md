# 거대행성의 암모니아·물 구름과 띠·제트 검증

2026-10-14, `0.7.0-alpha.5`. 목성형과 토성형이 같은 12층 계산기를 사용한다.
기존의 깊은 경계·H₂/He 구현 기록은 [초기 거대행성 검증](GIANT_PLANETS_VALIDATION.md)이다.

## 성분과 상변화

각 층은 H₂, He, NH₃ 기체·액체·얼음, H₂O 기체·액체·얼음의 8개 질량을
저장한다. 구름은 이 액체와 얼음 재고이며 표시용으로 별도 물질을 만들지
않는다. 이상기체 분압은 응결되지 않은 분자 수로 구하고, 정역학 압력은
구름 입자를 포함한 전체 기둥 무게로 구한다.

NH₃와 H₂O의 포화 조건을 함께 풀며, 두 성분의 기체 분율 변화가 서로의
분압에 반영된다. 기체→구름 전환은 잠열로 온도를 높이고 역전환은 온도를
낮춘다. 액체/얼음 전환의 엔탈피 구간에서는 융점 온도를 유지하면서 두
상의 질량을 나눈다. 최종 온도는 같은 층의 원래 에너지를 정확히 만족하게
복구하며, 질량이나 열을 클램프로 없애지 않는다.

고정 비열과 0°C 기준 상 에너지로 다음 식을 사용한다.

```text
Hlayer = Σspecies m [Cp TC + phase] + mtotal (g z + |v|² / 2) / 1000
ln(psat / pref) = [(Lref − ΔCp Tref)(1/Tref − 1/T) + ΔCp ln(T/Tref)] / Rspecies
```

비열은 H₂ 14.3, He 5.193, NH₃ 기체/액체/얼음 2.06/4.7/2.1,
H₂O 기체/액체/얼음 2/4.18/2.1kJ/(모델 kg·K)이다. 물의 상 에너지
0/−334/+2475kJ/kg는 기존 앱 규칙과 같다. NH₃는 194.95K·6060Pa와
승화열 31.2kJ/mol을 기준으로 한다.
[NIST NH₃ 상 자료](https://webbook.nist.gov/cgi/cbook.cgi?ID=C7664417&Mask=4).
NH₃의 융해열 333kJ/kg 및 고정 비열은 모델 근사이며, 그 융점에서 에너지
차이가 맞도록 상 에너지의 기준 오프셋을 정한다. 액체와 얼음 가지는
같은 기준점에서 이어진다. 물은 273.15K·611.657Pa를 기준으로 하는 기존
비열·상 에너지 근사를 사용한다. 임계 온도 이상의 상태는 모두 기체로
처리한다. 용액·혼합 얼음·고압 상태방정식은 포함하지 않는다.

포화 평형은 즉시 이루어지는 벌크 근사다. 핵생성 장벽, 입자 수·크기 분포,
NH₄SH 및 NH₃/H₂O 용액은 아직 없다. 실제 구름 층의 전체 화학이나 실측
포화 곡선을 모든 온도·압력에서 재현한 모델은 아니다.

## 유한한 수송·침강과 복사

셀 사이 및 층 사이의 혼합은 8개 성분, 상 에너지를 포함한 열과 접선
운동량을 같은 플럭스로 운반한다. 낙하하는 응결물도 자신의 현열·상
에너지·위치·운동 에너지를 아래 층에 전달한다. 감소한 위치에너지 및
혼합·감쇠의 운동에너지 손실은 열로 돌아간다. NH₃ 액체/얼음의 낙하
속도는 0.15/0.06m/s, 물 액체/얼음은 0.3/0.1m/s의 감도 입력이다.
따뜻한 층에 도착하면 같은 포화 계산으로 다시 증발한다. 하단 밖으로
응결물을 제거하지 않으며 지표 비·바다·재공급 저장소는 없다.

실제 층별 응결물 질량에 고정 소광 계수를 곱해 단파 산란과 장파 흡수를
계산한다. NH₃ 액체/얼음의 단파 운송 소광은 8/12, 장파 흡수는
12/16m²/kg, 물 액체/얼음은 각각 10/14와 18/22m²/kg이다. 기체 NH₃와
H₂O에도 회색 장파 항을 더한다. 이 값은 입자 크기 감도 근사이며 분광
구름 광학 표나 관측 교정 결과가 아니다.

상·하단 물질 경계는 밀폐한다. 하단 장파는 `up = down + intrinsic`으로
유지하고 하단까지 내려온 단파는 마지막 층에 흡수한다. 전체 에너지의
변화는 상단 순 복사 + 지정한 내부 열 + 도구 열이며, 응결·증발·침강은
내부 교환이다. 외부 열을 뺀 질량·에너지 잔차를 검사한다. 단위는 기존
모델 kg/kJ이며 실제 행성 전체의 관측 질량·에너지 수지를 뜻하지 않는다.

## 띠·제트와 표시

빠른 자전과 층별 바람을 같은 운동량 방정식에서 적분한다. 초기 동서
제트는 `U0 cos(8 latitude) cos(latitude)`에 압력별 전단을 곱하며 진폭은
목성형 100, 토성형 180m/s다. 초기 온도에도 위도·경도별 작은 변동을
지정한다. 이는 관측 바람을 맞춘 초기 자료나 자발적인 제트 형성 검증이
아닌 실험 초기 조건이다.

처음 생성할 때 1bar 위의 NH₃와 10bar 위의 물을 동서풍에 따라 일부
심부층으로 옮기고 같은 질량의 H₂/He 혼합물을 위로 옮긴다. 각 성분의
총량, 층별 총 에너지와 기둥 무게를 보존하는 교환이다. 이후에는 이
초기화 함수를 호출하지 않는다. 띠는 실제 성분·구름 상태로 남아 기류와
함께 이동하고, 압력·열 구배, 코리올리 회전, 혼합, 복사와 상변화에 따라
변한다. 위도 무늬를 매 단계 다시 그리거나 바람을 원래 값으로 되돌리지
않는다.

물질 화면은 실제 NH₃ 구름 광학 깊이, 위에서 본 물 구름의 기여와 구름
압력을 기준 압력 구면에 압축해 표시한다. 별도의 이동하는 띠 텍스처는
없다. 색은 구름이 많은/적은 기둥을 구분하는 정성 표현이다. 실제 목성의
착색 물질이나 사진 색을 재현하지 않는다. 초기 구름 층과 띠·제트를 다루는
배경은 [NASA 목성 설명](https://science.nasa.gov/jupiter/jupiter-facts/)과
[NASA 제트 설명](https://science.nasa.gov/photojournal/jets-at-jupiter/)을
참조했다. 황수소암모늄 층과 착색 화학은 이번 모델의 범위 밖이다.

관측 화면은 NH₃/물 구름 재고, 관측 층의 동서풍, 기둥 구름 광학 깊이,
층별 압력·온도·구름량·동서풍과 15° 위도 구간 평균을 표시한다. **동서
제트** 지도는 부호가 있는 m/s와 실제 바람 방향 화살표를, **암모니아
구름** 지도는 액체+얼음 질량을 표시한다. 구름 표시를 꺼도 물리 상태는
유지된다.

새 프리셋의 초기 전체 성분 재고는 다음과 같다. H₂/He의 건조 몰분율
89.8/10.2%, 96.7/3.3%를 각각 유지하고 미량 성분의 몫만큼 줄인다.

| 초기 재고 입력 | 목성형 | 토성형 |
|---|---:|---:|
| NH₃ | 300ppm | 200ppm |
| H₂O | 3,000ppm | 2,000ppm |
| 하단 기압 / 내부 열 | 30bar / 5.4W/m² | 30bar / 2.0W/m² |

미량 성분·제트·초기 띠 및 고정 광학 계수는 감도 실험 입력이다. 현재
상층의 기체 조성은 응결과 수송을 반영한 값이므로 이 전체 재고 입력과
다를 수 있다. 토성형은 입력 값이 달라지고 물리·저장 코드는 같다.

## 저장 호환

- 행성 스냅샷 버전 8, 셀 36필드다. 0–29의 기존 위치를 유지하고 30/31/32에
  NH₃ 기체/액체 구름/얼음을 넣는다. 27과 33/34/35는 예약 0이다. 물 구름은
  기존 수증기·구름 물·구름 얼음 위치를 사용한다. WGSL 배열도 36필드다.
- 가스형 기후 봉투 버전 3은 유지하고 심부 상태는 버전 2로 확장한다.
  층별 8성분 질량·온도·속도·기준 높이가 Float64 정본이며 셀은 질량·
  열평균 온도의 Float32 표시 합계다. 체크포인트와 Worker는 전체 버퍼를
  전달한다. 합계 불일치·손상된 구름 질량·미지원 고체·예약 필드는 거부한다.
- 이전 1–7 버전과 16/20/24/28/32필드 저장을 읽는다. H₂/He만 있는 심부
  버전 1은 두 질량을 8성분 배열에 복사하고 새 성분을 0으로 채운다.
  재고·온도·바람·높이·시간·정의와 원본을 보존하며, 새 프리셋 조성이나
  띠 초기화를 적용하지 않는다. 이전 거대행성에는 구름을 새로 공급하지
  않는다. 관측 패널에 이 차이를 안내한다.
- 항성계 봉투 버전 3과 계정 저장 크기·권한 규칙은 유지한다. 기존 대시보드와
  CSV의 미기록 NH₃·제트 지표는 `null`인 미관측 값으로 읽는다. 부호 있는
  동서풍은 관측 당시의 바람과 격자 방향에서 계산하며 옛 기록을 추정하지
  않는다.

## 검증

`tests/giant-clouds.test.ts`는 두 성분의 응결/증발 왕복, 융점 혼합상,
동시 분압·압력 반응, 공통/층별 비열·상 에너지 일치, 두 프리셋의 구름과
전단 제트, 유한한 띠 초기화의 성분·층별 에너지·기둥 무게 보존, 침강과
재증발, 실제 구름의 단파 반사·장파 흡수, 광학 깊이에 따른 표시, 부호
있는 관측 제트, 손상 저장과 이전 H₂/He 저장의 무보충 변환을 검사한다.
기존 깊은 대기 테스트와 함께 정확 재개·정지 가열·롤백·배경 계산도 유지한다.
편집 없는 정지 저장이 상 평형을 재계산하지 않는 것도 검사한다. 반복해서
실패한 비활성 행성은 마지막 완료 상태와 시각을 보존하고 일시정지하며,
나머지 행성의 계산과 저장은 계속한다. 실제 혼합 항성계에서 오래 실행된
암석형 대기의 범위 이탈이 자동 저장까지 막던 경우도 이 경로로 복구했다.

42셀에서 120 × 0.5게임초, 물리 한 시간을 적분한다. H₂·He·NH₃ 전체·
H₂O 전체를 각각 보존하는지 검사하며 질량 허용값은 10⁻⁹kg, 에너지
허용값은 외부 열을 뺀 10⁻⁵kJ다. 최종 코드에서 성분별 잔차는 대략
10⁻¹²kg 이하, 에너지 잔차는 수×10⁻⁹kJ 이하였다. JSON 복원 뒤 상태와
전체 기후는 같은 입력의 원래 실행과 일치한다.

`tests/telemetry-csv-import.test.ts`는 직전 거대행성 대시보드·CSV에서 새
관측값을 만들지 않는 것을 검사한다. `tests/giant-save-size.test.ts`는
2,562셀 거대행성 4개씩 두 모드, 총 8개의 전체 상태를 기존 gzip 저장
코드로 인코딩·디코딩한다. 원본 64MiB / 압축 20MiB 한도 안에서 모든
층을 포함한 JSON 표현이 그대로 복원된다. 초기 상태 시험이며 장기
시계열이 더해진 모든 저장의 크기를 보장하는 결과는 아니다.

브라우저 `/tests/deep-atmosphere-lab.html`에서 두 프리셋 × Worker CPU /
WebGPU / Worker WebGPU, 6가지 조합을 42셀·30단계로 비교했다. 상태
차이 0, 전체 기후 일치, 성분별 보존 및 JSON 재개 일치를 통과했다.
가스형은 GPU 선택에서도 같은 호스트/Worker 물리를 사용한다. 독립
GPU 구름 방정식의 검증은 아니다. 기존 화성 검증 화면도 실제 WebGPU의
36필드 구조에서 보존·상태·저장 재개 검사를 통과했다.

최종 브라우저 30단계 시험의 총질량/외부 열을 뺀 에너지 잔차는 목성형
−1.14×10⁻¹³kg / +1.10×10⁻⁹kJ, 토성형 −7.96×10⁻¹³kg /
−6.77×10⁻¹⁰kJ였다. 각 성분의 잔차는 4.55×10⁻¹³kg 이하였다.
이 값은 위의 한 물리 시간 테스트와 별개인 실행 경로 비교 결과다.

실제 앱에서 목성형·토성형 생성·실행·일시정지, 구름 띠·동서 제트 지도,
구름 표시 토글·층별 표, 자동 저장 후 복원과 이전 거대행성의 무보충
관측을 확인했다. 전체 테스트 444개 통과, 조건부 18개 건너뜀.
버전 검사·TypeScript/Vite 빌드 결과는 `CHANGELOG.md`의 Unreleased를
따른다. 화면과 브라우저 수지는 `artifacts/giant-clouds/`에 남겼다.
`browser-verification.json`은 6가지 실행 결과, `mars-regression.json`은
화성 WebGPU 회귀, `ui-verification.json`은 기존 건조 저장과 토성 복원,
구름 표시 토글, 제트 표, 배경 행성 오류 격리 결과를 담는다.

고정 기준 높이·구면·회색 복사·고정 비열·벌크 포화/침강 모델이다. 움직이는
압력 좌표, 비정역학 대류, 관측 폭풍·제트의 정량 교정, 착색 화학·NH₄SH,
헬륨 비·금속수소·내부 구조, 고리·편평도·자기장까지 확장하지는 않았다.
