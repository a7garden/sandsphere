# 대류·복사 개선과 관측 기후 검증

2026-10-11 초기 5층 모델의 관측 실패 기록이다. 11층·부분 구름량·분광 참조 솔버와 실제 장기 실행 결과는 [CLIMATE_BENCHMARK_RESULTS.md](CLIMATE_BENCHMARK_RESULTS.md)를 따른다.

**물리 계산은 개선했지만, 관측 지구 기후를 재현하는 모델이라는 검증은 미통과다.** 자동 시험의 성공은 계산식·보존·저장이 동작한다는 뜻이다. 관측 오차가 허용 범위에 들어왔다는 뜻으로 사용하지 않는다.

## 바뀐 계산

구현은 `src/sim/climatePhysics.ts`, 연결은 `src/sim/layeredAtmosphere.ts`다. CPU와 WebGPU 경로는 같은 대기 적분기를 사용한다.

- **습윤 상승 공기:** 위층의 실제 기압과 높이에서 `cp T + 잠열 + gz`를 유지하면서 수증기·액체·얼음 평형을 푼다. 응축 잠열과 응축물 하중을 포함한 가상 온도로 부력을 계산한다. 건조 상승만으로는 안정하다고 판단되는 습윤 성층의 상승도 시험했다.
- **대류 닫힘:** 부력 차에 `exp(−ε Δz)` 혼입 보정을 적용하고 `dw/dt = b − ε w²`를 적분한다. `ε=2×10⁻⁴ m⁻¹`는 명시적인 모델 설정이며 관측 교정값이 아니다. 같은 질량의 상승·환경 하강 교환으로 물질·엔탈피·수평 운동량을 수송한다. 독립 상승 기둥의 모든 혼입 물질·수직 운동에너지를 풀어내는 완전한 plume 모델은 아니다.
- **장파:** Isca GEEN의 공개 SBDART 기반 광학 두께 계수를 사용한다. 8–14 μm 적외선 창과 나머지 장파를 구분하고 방출 가중치는 0.3732, 0.6268이다. 각 등온 층은 `I_out = I_in exp(−Δτ) + B(T)(1−exp(−Δτ))`로 적분한다. 수증기 비습·CO₂ 몰 농도·기압 두께를 사용하며 이전 인벤토리 로그 계수를 제거했다.
- **단파:** GEEN의 단파 흡수식을 위에서 아래로 적응 RK4로 적분한다. 흡수 에너지는 해당 대기층의 열에 들어간다. 광학 두께 25 이상은 투과율 1.4×10⁻¹¹ 미만인 불투명 한계로 처리한다.
- **구름·지표 반사:** 대표 입경으로 구름 광학 두께를 계산하고 보존적인 2방향 산란의 adding 계산으로 층 사이·지표 사이 반복 반사를 합산한다. 액체 유효 반경 10 μm, 얼음 30 μm, 산란 비대칭 계수 0.85를 가정한다. 실제 입경 분포나 분광 미세물리는 아니다. 식생과 관측 패널의 햇빛도 같은 대기 복사 전달을 사용한다.
- **실험 경계:** 별도 RCE 실행에서 고정 SST와 알베도를 지정할 수 있다. SST 유지에 필요한 외부 열은 에너지 장부의 명령 채널에 기록한다. 일반 행성 실행에는 이 경계를 적용하지 않는다.

이 계수는 지구형 기체의 축약 복사 모델이다. CH₄·O₃·N₂O의 분광 흡수, CO₂가 주성분인 대기, 극단적인 고압·고온 기후를 검증한 모델이 아니다. CO₂가 거의 없는 경우 로그 계수를 비음수 광학 두께로 연장하지만 이 영역의 분광 정확도는 검증하지 않았다. Isca 문서도 GEEN의 slab-ocean 안정성 제한을 명시한다. 이 구현은 별도 보존 적분과 짧은 소단계를 쓰지만 장기 결합 기후의 안정성·정확도를 그 문서에서 인증받은 것으로 취급하지 않는다.

## 자료와 재현성

NASA POWER API에서 **2001–2020년, 24개 위치의 월별 기후값 288개**를 내려받았다. 위도 ±15°, ±45°, ±75°와 경도 ±45°, ±135°를 조합했다. 전체 관측 지구 격자가 아니며 수치도 **표본 가중평균**으로 표시한다.

| 값 | 원 자료·의미 | 단위 |
| --- | --- | --- |
| TS, T2M | MERRA-2 재분석의 지표 피부 온도·2 m 온도 | °C |
| PRECTOTCORR | MERRA-2 보정 강수량 | mm/day |
| CLOUD_AMT | CERES SYN1deg 위성에서 산출한 구름 면적 비율 | % |
| RH2M, PS | MERRA-2 지표 상대습도·기압 | %, kPa |
| 지표 SW/LW | CERES SYN1deg의 복사 전달 산출 플럭스 | kWh/m²/day → 평균 W/m² |

재분석은 실제 관측을 동화한 모델 산출물이며 순수한 지상 실측 자료라고 부르지 않는다. 구름은 위성 산출 자료다. API의 자료 기간·출처·버전·결측값·단위, 각 요청 URL 및 원 응답 SHA-256을 `tests/fixtures/nasa-power-climatology.json`에 보존했다. 내려받기 실패·결측·단위 변경 시 기존 fixture를 덮어쓰지 않는다.

```sh
python3 scripts/fetch-climate-reference.py
npm run test:climate-reference
npm run test:climate-rce
python3 scripts/plot-climate-reference.py  # matplotlib 필요
```

가중치는 위도 `cos(φ)`와 월 길이를 사용한다. 어느 관측 값도 복사 계수·혼입 계수에 맞춰 fit하지 않았다. 위도 6개·경도 4개의 희소 표본으로 전 지구 지도 정확도나 대륙별 정확도를 주장하지 않는다.

## 관측 비교 결과

월별 지표 관측 값으로 5층의 합성 성층을 구성한 **조건부 복사 진단**이다. 실제 상층 관측 프로파일을 받았다는 뜻은 아니다. 기준은 6.5 K/km·고도에 일정한 상대습도이며 4, 9 K/km도 함께 검사했다.

| 진단 | 결과 | 판정 |
| --- | --- | --- |
| 맑은 하늘 하향 장파 RMSE | 기존 공개 Byrne 회색 비교 49.51 → GEEN 2밴드 26.87 W/m² | 개선되었지만 오차가 남음 |
| 하향 장파 편향·상관 | −5.35 W/m², 0.9898 | 합성 프로파일을 전제로 한 진단 |
| 성층 민감도: 4 / 6.5 / 9 K/km | 장파 RMSE 35.63 / 26.87 / 34.14 W/m² | 프로파일 불확실성에 민감 |
| 조건부 지표 복사 평형 온도 RMSE | 24.20°C | 현열·잠열·지표/해양 열 수송을 뺀 진단; 기후 예측으로 사용 불가 |

24개 독립적인 젖은 기둥에 실제 대기 적분기를 하루 실행했다. 연평균 관측 지표 온도로 초기화하고, 합성 습도 성층과 Frierson형 연평균 TOA 일사 분포를 사용했다. 지표는 기존 행성 열용량을 유지한다. 실제 육지/해양·지형·수평 순환을 구성한 지구 hindcast가 아니다.

| 항목 | 관측 표본 평균 | 하루 모델 평균 | RMSE |
| --- | ---: | ---: | ---: |
| 지표 온도 | 13.89°C | 13.78°C | 0.124°C |
| 강수 | 2.280 mm/day | 0.0167 mm/day | 2.617 mm/day |
| 구름 면적 / 모델 구름 출현 | 62.66% | 30.65% | 52.85 percentage points |

**작은 온도 오차는 관측값으로 시작한 큰 열용량의 하루 실행 결과이므로 기후 정확도 증거가 아니다.** 강수는 크게 과소하고 구름의 공간 패턴도 맞지 않는다. 모델은 광학 문턱 이상의 구름 유무를 시간 집계했으며, 위성의 subgrid 면적 비율과 정의가 다르다. 이 차이까지 포함해 구름 비교를 미통과로 판단한다. 관측 구름을 모델에 심거나 지역별 구름 마스크를 추가하여 수치를 맞추지 않았다.

원 결과·분포 그림은 `artifacts/climate-reference/column-observations.json`, `radiation-observations.json`, `sampled-distributions.png`, `radiation-comparison.png`에 생성된다. 잠정 프로젝트 목표(지표 RMSE 3°C, 강수 1 mm/day, 구름 15 percentage points)는 출판된 표준 벤치마크 허용 오차가 아니며, 기간·비교 변수·경계 조건이 적절할 때만 쓸 수 있다. 현재는 이 선행 조건부터 충족하지 않는다.

## 물리 한계 시험과 표준 벤치마크

| 시험 | 실행·판정 |
| --- | --- |
| Schwarzschild 등온 대기 해석해 | 1·5·20·80층에서 상하 장파가 해석해와 일치; 층 수 변경으로 총 광학 두께가 달라지지 않음 |
| 2방향 복사 수지 | 투과·반사·대기 흡수·지표 흡수의 합과 TOA 순 플럭스 일치; 복수 반사와 2밴드에서도 검사 |
| 건조·습윤 상승, 혼합상 | 건조 `g/cp` 한계, 습윤 잠열로 냉각 감소, 0°C 액체/얼음 평형, 물·모델 엔탈피 보존 검사 |
| Frierson 처방 광학 두께 | 적도 6 / 극 1.5, 선형+4차 기압 분포의 함수·경계값 검사; 전체 GCM 기후를 통과했다는 뜻은 아님 |
| RCEMIP 경계의 개발 RCE 기둥 | SST 300 K, 입사 일사 약 409.6 W/m², 알베도 0.07, CO₂ 348 ppm, 공개 초기 성층으로 100일 실행. 상세 결과는 `rce-100day.json` |
| 정식 RCEMIP SCM | **미통과/불충족.** SCM 권장 실행은 약 1000일이며 100일은 이에 미달. 상층·trace-gas 복사·EOS·수직 해상도·다중 SST·다른 모델 출력과의 비교도 부족 |
| Held–Suarez / Jablonowski–Williamson | **미실행.** 실제 원시방정식 코어, 지구 반경·회전·좌표·처방 forcing을 구성한 전체 순환 장기 검증이 필요. 광학/기울기 단위 시험을 이 벤치마크 통과로 표시하지 않음 |

100일 기둥의 에너지 잔차는 1.96×10⁻⁵ kJ(인벤토리 에너지 기준), 마지막 날 최대 층 온도 변화는 0.406 K였다. 61–80일과 81–100일의 평균 층 온도 차이는 0.48–1.18 K로, 상층의 장기 변화도 남았다. 마지막 20일 평균 강수는 1.86 mm/day였지만 열대 고정 SST 기둥 값을 지구 전체 관측 평균에 맞았다는 증거로 쓰지 않는다.

하루 온도 변화는 개발용 진단이다. 실제 대류는 시간 변동이 가능하므로 하루 변화가 작다는 조건만으로 통계적 RCE를 판정할 수 없다. 정식 판정에는 spin-up 이후 충분한 평균 기간, 대기 에너지·물 수지, 연속 평균 구간의 비교가 필요하다. RCEMIP 정오표에 따라 frozen moist static energy의 얼음 잠열은 음의 부호로 취급한다.

전체 회귀 시험은 292개 통과·15개 건너뜀(43.1초), 별도로 opt-in 100일 기둥 시험 1개를 실행해 통과했다(199.1초). 이 시험의 통과는 유한 상태·고정 SST 유지 검사이며 기후/RCEMIP 인증이 아니다. TypeScript/Vite 빌드와 `git diff --check`도 통과했다. 새 계수로 실제 WebGPU 브라우저 비교를 다시 실행하지 않았으며, 이전 GPU 수치는 이전 보고서의 실행을 따른다.

관측 기후 재현을 위해서는 상층을 포함한 압력 좌표와 수직 해상도, 실제 지구 지표·열용량, 경계층 난류·부분 구름량, 수평 순환 및 장기 평균 검증이 필요하다. 현재 코드는 보존 법칙과 공개 물리 매개변수화에 기반한 축약 모델이며, 관측에 검증된 GCM으로 표시하면 안 된다.
